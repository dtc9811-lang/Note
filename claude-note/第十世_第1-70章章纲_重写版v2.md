# 《百世飞升》第十世·第1—70章章纲 重写版 v2

> 替换旧版 v1。
> 三条改动原则：
> 1. **修炼可见**：前70章安排四次解封（一重·醒魂 / 二重·纳炁 / 三重·炼体 / 四重·开府），每一次都有突破戏、当场用出来、标明代价与数值。
> 2. **旗舰换链**：《来路》→《余烬》，核心引擎从"看懂规则"换成"温石＝修为"，天然长出抢资源—升级—碾压的循环。
> 3. **去流水账**：流程一句带过，冲突展开成场景；每章至少一场有来回的对话；章末钩子换类型，不再只有"细节＋留白"。
>
> 配套文件：`第十世_修炼阶梯与进度表_v1.md`、`第十世_新旗舰事件链_余烬_v1.md`。

## 九、四处最容易写坏的地方

1. **不要把《余烬》写成单关副本。** 四层危险必须同源：都是由"炉心在复燃"驱动，每一层因为上一层的行动而更严重。取走温石 → 炉心更急；抹掉印记 → 它从别处呼吸；洞开自己的洞天 → 它开始认他。
2. **不要把修为增长写成白拿。** 每次吸温石、每次解封，都要有具体的伤、痛、后遗症。
3. **不要在62章开无理由的挂。** 那一次碾压，靠的是前面62章全部铺垫的总和。
4. **不要把69章写成旁白讲设定。** 揭底必须由手里的实物推出来：殓单、过客册、脚印、洞天记下的那个动作。
