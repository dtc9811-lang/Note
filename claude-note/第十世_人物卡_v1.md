## 一、主角

### 赵升

- **身份**【设定】百世书第十世主角；转生为鸿运子一脉后裔，公开姓赵，户籍编为"仙墟劫户"。九世积累，第十世以新肉身逐步解封上一世的真仙底蕴。
- **本世底牌**【设定】一宙三洪：
  - 宙级【无限宇空之门】——以仙墟遗物为坐标，开启已死仙天不同历史阶段的"宙光层"。
  - 洪级【混元仙体】、【长生不死】、指定转生法宝【生死断笔】。
  - 【不朽仙魂】不占权限，仙魂层次延续，但肉身承载不足。
- **缺口**【设定】轮回大道烙印在道祖注视下崩溃，断口平整、无痛无回音，没有稳定大道归属。五方镜与上一世洞天留在陨落处，带不走（后续主线回收）。
- **境界与位置**【设定】生命本质已是长生真仙，本世不是凡人从头修炼，而是解封＋重新统合。
- **修为行为底色**【设定】先活下来 → 观察规则 → 建模验证 → 重复试验 → 把灾难变资源 → 把资源变家族／跨世资产。工程师式修仙，不是热血莽夫。
- **辨识度**【正文】站在人群靠后的位置，先看别人怎么数东西；说话短，常常用陈述句代替问句（"你注意到了吗。"没有问号）。
- **能力使用纪律**【正文／设定】
  - 宙级能力代价明确可见，越用越不能变便宜（第12章第一次动用，之后每次都要重复付出）。
  - 前期靠看懂规则取胜，不靠越级硬杀。第13章半步之差、第61章让路网自己转向，都是这个路子。
- **修炼轴**【正文进度线】
  | 节点 | 状态 |
  |---|---|
  | 第4章 | 仙魂完整，肉身承载不足，战力≈寻常仙墟客 |
  | 第15章 | 能有限动用宙级能力，每次代价明显 |
  | 第25章 | 混元仙体初步苏醒，可越阶自保，不可越阶硬杀 |
  | 第49章 | 仙体局部苏醒，长途、连战仍受限 |
  | 第62章 | 可短时爆发至高阶真仙水准，事后需长时间恢复 |
  | 第70章 | 稳定恢复到高阶真仙，距真仙圆满仍远 |
- **性格与软肋**【正文／设定】不解释、不争口舌、认输认得干脆（第54章退回无归渡、第56章自我注销）；软肋是对"人能不能到家"这件事有执念，容易被这类事情牵住。
- **弧光**【设定】经营墟路 → 修复残天 → 发现轮回缺环 → 重构轮回道 → 经自己打开的轮回道进入第十一世。
- **待定**：宙级能力正式名称、精确消耗、能否携物；本命洞天升格仙天的阶段划分。

## 二、旧人线（同世存活，非开局核心）【设定/正文】

### 赵玄靖

- **身份**：第十世时间点上赵氏旧人，与混沌、先天神州深度绑定。
- **战力**：本土近似金仙，但无法轻易离开、不能公开出手。
- **与赵升**：旧人重逢线在106—140章，赵升被路网记住、行踪难隐，构成真实障碍。
- **修炼轴**：未成金仙，是赵氏最强的"不能动"底牌。
- **待定**：重逢方式与他在第十世的主线功能。

### 鸿运子（赵宏运）

- **身份**：赵升本世血脉来源一脉的祖上；长生真仙后期，积累巨量功德，被绑定在量劫战场。
- **约束**：擅离会让赵氏承担更严重后果，所以不能出手护短。
- **与赵升**：血缘祖上，但前期不担任引路人。
- **修炼轴**：长生真仙后期，未成金仙。

### 天运子

- **身份**：斩断公开名号与因果，在暗处保留一线联系。
- **功能**：赵氏旧人的"暗线"，可用于中后期信息与资源渠道。
- **修炼轴**：未成金仙。
- **待定**：第十世是否正面登场。

### 石灵

- **身份**：可存活，留在赵玄靖一线。
- **禁区**【设定】不担任前期保姆、引路人或主线核心。
- **修炼轴**：非本卷重点，不参与前70章修炼体系。

## 三、赵家坳（前70章主场人物）【正文】

### 赵长庚

- **身份**：赵家坳辈分最高的族老，保姓一边的掌事人；拄一根铁尺杖。
- **能力**：老练、稳、能压场，但战力不敌监墟使随从（第8章铁尺杖被岑固一把扳弯，捏不直）。
- **性格与行为逻辑**：先算账再表态，讲旧例、讲规矩；分东西时给"保四改三"，把矛盾压到下一趟折抵。
- **与赵升**：第一个把赵升的判断当回事的人，探路队里走在赵升旁边、不质疑；赵升也只对他一个小幅摇头传递否定。
- **秘密 / 私心**：明知改姓派与监墟使有往来，为了四十一个劫户还能进同一张墟图，选择不摊牌。
- **弧光**：从"守旧例的老族老"到把方向交给赵升。
- **修炼轴**：劫户级，凡人—炼气层次的执行者，不承担修炼爽点。
- **待定**：年龄、寿数、是否有一手压箱底的旧功。

### 赵九满

- **身份**：保姓一边的刺头、探路队主力，身量高、嗓门大，使铁钎。
- **性格与行为逻辑**：当面顶、张口就问"是谁传的信"；不服就骂，骂完还是跟着走。
- **与赵升**：从质疑到跟从的第一批人；第6章被赵升叫住听判断，嘴上不服、脚跟上。
- **功能**：赵氏动作线、体力线、生死场的具体执行者；也是"普通人视角"看赵升的镜子。
- **修炼轴**：劫户级战力，靠体魄和墟内经验。
- **待定**：是否在归潮一段有折损。

### 赵素

- **身份**：赵家坳的账房／记录者，随身的破账册是全书最重要的"可见证据库"。
- **能力**：记性好、笔快、会核对；第3章就能发现改姓派报的出墟数目对不上。
- **性格与行为逻辑**：话少、问得准，问不到就不问；赵升不解释，她就记下来、折角、等着。
- **与赵升**：最稳定的工作搭档，也是"赵升不在场时替他接文书"的人；探路四人组之一。
- **功能**：作者用来落地数据与伏笔的载体（三里零七丈、废物登记括号里的"长照渡收"、人数伤势来处）。
- **弧光**：从家族账房变成无归渡的"渡口记录官"。
- **修炼轴**：非战斗线，但她是"经营＝修炼"这条主线的具体体现者。
- **待定**：与赵升是否有明确的私人情感线（目前正文只写到工作默契）。

### 赵茂

- **身份**：保姓最年轻的一个，十九岁，第一次点卯。
- **性格与行为逻辑**：一脸茫然但不开口问，翻东西翻得很仔细，第一次见墟内浮空的断柱会仰头看。
- **功能**：读者代入位；用"第一次见"的眼睛展示仙墟的规模与危险。
- **修炼轴**：炼气都未必稳固的新人，最需要"修炼变多"的成长对比位。
- **待定**：是否成为赵氏新一代的成长样本。

### 赵慎

- **身份**：改姓派的实际主事人，与监墟使有往来。
- **能力**：算得清、忍得住；能把民主式的争执引到自己已经算好的结果上。
- **私心**：主张把无归渡献上去换仙籍，认为保姓的死活是筹码。
- **与赵升**：结构性对手，家族内耗的发动机；第32、52—53章推动除名与夺权。
- **修炼轴**：劫户上层，资源比保姓好，但同样受仙籍压制。
- **待定**：第14章监墟使账上那个改姓派名字是不是他（正文未明说）。

### 赵敕

- **身份**：改姓一边的暗线人物，站在稍后位置，全程不开口。
- **辨识度**：眼睛在数席子上的遗物，从右到左一件件数，嘴唇轻轻动一下又停。
- **功能**：全书最重要的"沉默观察者"；赵升第一眼注意到的就是他，而不是赵慎。
- **私心 / 秘密**：正文未揭，属于留白型伏笔人物（第18日来访等）。
- **修炼轴**：待定，可能是改姓派真正的底牌。
- **待定**：第十世中的真实立场与归属。

## 四、体制一方

### 岑固（监墟使）

- **身份**：官方监墟使，主持劫贡点名与分配，正职带随从、持文书印。
- **能力**：随手一握便扳弯赵长庚的铁尺杖（区别于蛮力，是"层次差"的展示）。
- **行为逻辑**：不急着杀人，按文书走流程；把保姓送进丙一，把改姓另作安排，用制度吃人。
- **与赵升**：第8章强征坐标物、第10章在潮倒卷中把自己送进安全区崩塌中心（其遗物留下侵吞劫贡的账，第14章成为赵氏筹码）。
- **结局**：作为反面人物的第一次兑现，不写成大boss。
- **修炼轴**：比劫户高一到两个大层次，前十章的力量上限展示者。
- **待定**：是否还有后台追究。

### 步纲君

- **身份**：葬仙墟外围路线登记处图正，正九品；公开理由是把野路定路、发引、纳入正册。
- **能力与手段**：不靠打，靠"正册"这套合法流程收编路网；先把接口引向自家渡口，再把赵氏除名。
- **真实私心**：把路网接口改到自家渡口，做路线垄断；他不知道自己也只是让最后一段路重新可走的一环。
- **与赵升**：中段主要对手；第56章赵升把无归渡注销、挂到他名下，第61章路网判定"真正履行渡口职能的是那座歇脚棚"，反制成立。
- **结局**：第67章被放走，留下长期敌人，不做送人头反派。
- **修炼轴**：体制内修士，战力高于赵升前期，但全书不靠他打。
- **待定**：他背后是否还有更高层（路线登记处的上级）。

## 五、路网与异象

### "第一个到家的人"（第69章揭底）

- **身份**：三万年前仙天毁灭时，走在归途上的渡客之一；门前十步那双脚印的主人。
- **功能**：不是boss，是"开端异象的重新解释者"；他一直在等门开。
- **纪律**：不允许开口讲三千字设定，只能由殓单、过客册、脚印推出来。
- **待定**：他现在是什么状态、去了哪里。

### 归客（归潮群体）

- **规模**：以万计，三万年积压在路网里，一直在往家走。
- **行为**：不攻击人，只是要到渡口去；被挤下路基的既上不来也没死透，滞留在外围。
- **功能**：中段最大的"危险形态反转"；也是无归渡的永久义务来源。
- **待定**：走出去的归客去了哪（第69章赵升问出、不给答案）。

## 六、用这张卡检查"修炼太少"

- 前70章真正承担修炼爽点的只有赵升一人，且曲线是**恢复**而非**突破**：第4章≈寻常仙墟客 → 第70章高阶真仙，中间第62章才第一次"短时爆发"。
- 赵氏群像（赵长庚、赵九满、赵素、赵茂）全部是凡人／劫户层次，**没有一条可对比的成长线**：赵茂是唯一具备"新手成长位"的人，但目前只是第一次点卯。
- 体制一方（岑固、步纲君）只展示层次差，不参与修炼竞争。
- 结论与待办：如果要补修炼，最省的三个口子是
  1. 给赵茂／赵氏新一代开一条可见的低阶成长线，作为赵升"造秩序"的具体产出；
  2. 把赵升每次宙光层探索写成一次**明确的法则收获**（看到什么、改了洞天哪一处、涨了多少），而不是只写"代价明显"；
  3. 给赵敕补一个真实境界，让家族内部有一条"技术和修为都藏着"的暗线对手。
