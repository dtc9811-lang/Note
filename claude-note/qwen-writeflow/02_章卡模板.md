# 02 章卡模板

> 一章一张，写之前必须先填好。填不满就说明这章还没想清楚，不要开写。

```
# 第___章　章名：__________
档位：H / M / S
地点：__________（本章只在这里，不换地图）
在场人物：__________（写全名，人数=___）

## 节拍（按顺序，3—6条）
1. 
2. 
3. 
4. 

## 修炼节点
- 本章修为有无变化：无 / 有
- 若有：从____ → ____，代价是____，当场用出来做了什么____
- 若本章是突破章，突破戏三段：决定 → 硬扛 → 成了

## 信息变化
- 读者新知道：
- 赵升新知道：
- 其他人新知道：
- 不能让谁知道：

## 本章禁区
- 不能出现：
- 不能提前揭露：
- 不能写成的套路：

## 结尾钩子
类型：危险逼近 / 人物翻脸 / 力量暴涨 / 真相露头 / 留白
具体一句：
```

## 填写示例（第13章）

```
# 第13章　章名：半步之差
档位：H
地点：宙光残层里的长照古渡 + 现世死门下方
在场人物：赵升、赵九满、赵素、赵长庚、赵茂、追杀者共5人（现世）+ 古渡残层里的"不存在的人"

## 节拍
1. 追杀者强闯古渡，踏进尚未在现世展开的桥面
2. 赵升看懂两层显化时间差：残层已经发生了，现世还没到
3. 他不打，只退半步，让追杀者的脚落在"已经塌了"的那一段
4. 崩塌在现世展开，五个人同时消失，没有声音
5. 赵升站在原地，旧光里神魂被洗过一次（解封一重前兆）

## 修炼节点
- 有。未解封 → 解封一重·醒魂
- 代价：三日不能入睡，神魂刺痛，眼下青黑
- 当场用出：神魂外放，听见脚下崩塌"还没发生"的声音

## 信息变化
- 读者：宙级能力可以进入历史残层，但不是回到过去
- 赵升：确认残层里的结构在现世已经塌了
- 赵家三人：确认赵升不是运气好
- 不能让岑固（已死）知道任何事

## 本章禁区
- 不能让赵升出手打人
- 不能让残层里的人说话
- 不能解释轮回

## 结尾钩子
类型：真相露头
具体：崩塌之后，古渡的轮廓留在原地没有散
```
