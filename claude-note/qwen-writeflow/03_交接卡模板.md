# 03 交接卡模板

> 每章正文写完后**立刻**产出，作为下一章唯一的记忆来源。
> 控制在 300 字以内。不准写"大概""似乎""可能"。

```
【第___章交接卡】
1. 已发生的事实：
   - 
   - 
2. 各人所知：
   - 赵升知道：
   - 在场其他人知道：
   - 不知道的人：
3. 当前错误答案：
   - 众人以为：
4. 未兑现的细节：
   - 物件：
   - 伤势：
   - 承诺：
   - 伏笔：
5. 本章结束时的可见状态：
   - 地点：
   - 在场人数与姓名：
   - 每人手中关键物品：
   - 刚发生的物理变化：
6. 下一章禁区：
   - 
```

---

## 示例（第13章交接卡）

```
【第13章交接卡】
1. 已发生的事实：
   - 五名追杀者踏入古渡残层，落入现世尚未展开的崩塌，消失
   - 赵升解封一重·醒魂，神魂可以外放，代价是三日夜不能睡
   - 古渡的轮廓在崩塌后留在原地，没有散
2. 各人所知：
   - 赵升知道：残层是已死仙天的历史遗痕，不是可改变的过去
   - 赵长庚、赵九满、赵素、赵茂知道：赵升靠看懂了什么杀了人，但不知道是什么
   - 不知道的人：坊市、官方、改姓派
3. 当前错误答案：
   - 赵家三人以为：赵升手里有某种古渡的钥匙
4. 未兑现的细节：
   - 物件：赵长庚给的劫户点名印在赵升怀里、古渡灯座共七个都是空的
   - 伤势：神魂刺痛、眼下青黑、指甲下渗血未愈
   - 承诺：无
   - 伏笔：古渡门额上"长照"两个字；古渡轮廓没散
5. 本章结束时的可见状态：
   - 地点：现世死门下方、古渡残层边缘
   - 在场：赵升、赵长庚、赵九满、赵素、赵茂，共5人
   - 手中：赵升握着点名印；赵素抱着账册；赵九满扛铁钎
   - 刚发生：五名追杀者消失，古渡轮廓留在原地
6. 下一章禁区：
   - 不要让赵升连续第二次动用宙级能力（代价还没还完）
   - 不要让残层里的人出现
```
