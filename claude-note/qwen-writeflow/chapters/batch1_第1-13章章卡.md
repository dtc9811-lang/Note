# 第1章　章名：第九世结束，结算中
档位：H
地点：结算地（百世书内的结算空间）
在场人物：赵升一人（人数=1）

节拍：
1. 赵升站在结算地，第十页正在翻开
2. 他最后一次盘账：九世得到的东西、丢过的东西
3. 神话结算落定：一宙、两洪、三荒
4. 三荒合成一洪，最终一宙三洪
5. 他确认自己已是长生真仙的生命本质，却发现轮回烙印已崩

修炼节点：
- 无。开局战力≈寻常仙墟客。此处第一次给出"解封九重尚未启动"

信息变化：
- 读者新知道：他不是从零开始，也不是完好带走一切
- 赵升新知道：轮回大道烙印崩溃，断口平整、无痛无回音
- 不能让谁知道：无人在场

本章禁区：
- 不写成纯面板罗列，必须用盘账的场景带出
- 不解释轮回终局
- 不出现对话

结尾钩子：
类型：真相露头
具体：宙级权限落在门上时，门缝里漏出一段不属于任何现世的旧光

2. 岑固卯时到，先布置半个时辰，不通知赵氏
3. 文书官念债额与任务：丙一，限期三月

- 不能让岑固知道赵升看出问题

本章禁区：

类型：留白

# 第13章　章名：半步之差
档位：H
地点：长照古渡 / 现世死门下方
在场人物：赵升、赵九满、赵素、赵长庚、赵茂、追杀者5人（人数=11）

节拍：
1. 追杀者强闯古渡，踏进尚未在现世展开的桥面
2. 赵升看懂两层显化时间差
3. 他不打，只退半步，让对方的脚落在"已经塌了"的那一段
4. 崩塌在现世展开，五个人同时消失，没有声音
5. 赵升站在原地，主动把神魂推过那道坎
6. 神魂外放，他听见脚下崩塌"还没发生"的声音
7. 崩塌之后，古渡轮廓留在原地没散

修炼节点：
- 有。未解封 → 解封一重·醒魂
- 突破戏三段：决定（他知道现在不推就来不及）→ 硬扛（三日不眠的痛提前压上来）→ 成了
- 代价：三日不能入睡，神魂刺痛，眼下青黑，指甲下渗血
- 当场用出：神魂外放，听见"还没发生"的崩塌

信息变化：
- 读者：这个能力不是万能，是靠看懂结构
- 赵家四人：确认赵升不是运气，但不知道是什么
- 不能让任何人知道"

本章禁区：
- 不让赵升出手打人
- 不让残层里的人说话
- 不解释轮回
- 本章不允许再用第二次宙级能力

结尾钩子：
类型：真相露头
具体：古渡的轮廓留在原地，没有散
