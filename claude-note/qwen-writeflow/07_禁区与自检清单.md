# 07 禁区与自检清单

> 每章写完，用这个清单过一遍。发现一条就只改那一段，不要重写全章。

---

## A. 世界观禁区（全书级）

1. 不创造私人仙墟，不设"墟主"职业。
2. 不建立赵氏仙朝，不让诸修排队臣服赵升。
3. 前70章不揭露轮回终局，只呈现"缺一环"。
4. 不让宙级能力变成无代价的时间穿越或万能答案。
5. 不杀赵玄靖、鸿运子、天运子、石灵。
6. 不把经营写成独立赚钱支线，必须服务修炼。
7. 赵升不投入任何现成大道长河。
8. 仙墟＝死仙天遗迹；坊市是仙墟客利用遗迹形成的交易场所，不等于仙墟本身。

## B. 本章级禁区（每章章卡里单列）

- 不能出现的人物
- 不能提前揭露的真相
- 不能写成的套路

## C. 文风自检

- [ ] 有没有出现"嘴角勾起/眸光一凝/气息暴涨/倒吸一口凉气"类套话？
- [ ] 有没有"与此同时，在另一个地方"式切换？
- [ ] 章末有没有抒情、总结、上价值？
- [ ] 对话是不是一问一答就结束？有没有来回？
- [ ] 形容词密度是否过高？
- [ ] 情绪是不是直接写出来的（"他很愤怒"）而不是写动作？

## D. 逻辑自检

- [ ] 人数守恒：进去几个、出来几个、死了几个？
- [ ] 空间守恒：从A到B的移动过程有没有交代？
- [ ] 时间守恒：说了"三日"就真的过了三日？
- [ ] 物品守恒：和交接卡里的状态一致吗？
- [ ] 信息守恒：有没有人说了他不该知道的事？
- [ ] 规则守恒：有没有偷偷改掉前面已经公开的规则？

## E. 节拍自检

- [ ] 章卡里的每一个节拍都写到了吗？
- [ ] 修炼节点（如果有）写足了吗？有没有"代价"和"当场用出来"？
- [ ] 结尾钩子类型和章卡一致吗？
- [ ] 字数在 1800—2500 之间吗？

## F. 十种最常见的失败样例

| 失败 | 表现 | 修法 |
|---|---|---|
| 加设定 | 突然写出一门新功法、一个新门派 | 删掉，不解释 |
| 加人物 | 冒出一个没在章卡里的人，还给名字 | 改成不具名的"一个人"或删掉 |
| 提前揭秘 | 第30章就点破炉心缺归返 | 改成只呈现现象 |
| 抒情结尾 | 末尾两段写感慨 | 删掉，换成一个具体动作 |
| 心理总结 | "他明白了，这一切都是……" | 换成他做了什么 |
| 对话注水 | 两人聊三页没有新信息 | 砍到2—4轮，落回动作 |
| 战斗开挂 | 赵升越级秒杀 | 改成靠规则/靠提前布置 |
| 数字模糊 | "许多温石""无数的人" | 换成具体数字 |
| 时间跳跃 | "转眼三年过去" | 改成具体场景过渡，或删 |
| 同义替换 | 把温石写成暖玉 | 按术语表改回 |

## G. 一个合格的章节长什么样

1. 开头三句内交代地点和此刻在干什么。
2. 中段至少一场有来回的对话或一次清晰的物理危机。
3. 有一个可核对的细节在结尾起作用。
4. 修炼章要有：决定 → 硬扛 → 成了 → 当场用出来 → 代价。
5. 最后一句停在动作或画面上，不解释。
