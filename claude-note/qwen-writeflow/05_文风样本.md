# 05 文风样本

> 每次写章带 1—2 段。这是"目标文风"的锚，防止模型滑向通用网文腔。
> 样本取自旧稿中质量最高的段落，只保留写法，不保留旧情节。

---

## 样本A：观察型（用于日常、调查、推理场）

```
赵升也蹲下去。

他先看的不是石板，是缝。

石板缝里没有草。这一带的地是死的，可死了三万年也总会有几根从石头缝里钻出来的东西——葬仙墟里那种灰白色、贴着地长的枯藤，到处都是。西门里面的石阶上就有。

这条路的缝里一根也没有。

缝里也没有沙。

干净得像刚被人扫过。

赵升伸手，摸了摸石板。

凉的。

正常的凉。

他沿着路边走了三十几步，看了看路基。路基是垒的——石头一层一层码上去，码得很齐，但不精。垒的人手法很熟，只是没有用心磨。

这不是长出来的。

这是铺出来的。
```

**要点**：短段。先排除，再确认。用"不是……是……"收束。不说结论，用具象细节逼出结论。

## 样本B：冲突型（用于对峙、谈判、翻脸场）

```
"赵堂主。"他开口，"痛快点。开个价。"

赵升说："和前面一样。三条。"

"我不要一样。"窦让往前半步，"我一百四十人，七车货，一夜之内全要走。我出十万仙晶，买一条最稳的路，现在就走。"

排队的人群动了一下。

十万仙晶。整个赵氏这三千年缴出去的劫贡加起来，也换不到这个数。

赵素的笔停在半空。

赵升说："不卖。"

窦让笑了："二十万。"

"不是钱的事。"赵升把桌上那盏油灯往前推了推，让光照到桌面上那道劈痕。
```

**要点**：对话短句。报价往上加，对方不动。用"人群动了一下""笔停在半空"写压力，不写心理。主角的回答永远比对方短。

---

## 样本C：危险型（用于险地、异象、伤亡场）

```
先动的是石头。

葬仙墟这一带的天上从来浮着东西。碎砖、断柱、半截门楣，还有更多说不清是什么的块状物，三万年前从某个高处掉下来，掉到一半就不动了，从此悬在半空里，不上不下。

现在它们同时转了一下。

不是被风吹的。是像一屋子的铁屑，底下忽然有人挪了一块磁石——几千块碎石在同一瞬间调了个头，把原先朝下的那一面朝了上去。
```

**要点**：先给一个已经在场的常态，再让常态"同时"改变。用一个日常比喻（铁屑与磁石）解释，不用"恐怖的威压"。

## 反面清单：这些写法一律不许出现

- 嘴角勾起一抹弧度 / 眸光一凝 / 眼中闪过一丝精芒
- 气息暴涨 / 恐怖的威压 / 毁天灭地的力量
- 他心中一凛 / 暗道不好 / 不禁倒吸一口凉气
- 这一切，都要从……说起
- 仿佛来自九幽地狱的声音
- 赵升嘴角微微上扬，露出一抹意味深长的笑容
- 与此同时，在另一个地方……
- 随着……的落下，一场大战即将拉开帷幕

## 句式纪律

| 允许 | 禁止 |
|---|---|
| 短句，一句一个动作 | 一句里三个以上形容词 |
| "他做了X。做了Y。" | "他不仅做了X，还做了Y，更做了Z" |
| 具体数字（三步、七盏、三息） | 模糊量词（许多、无数、漫山遍野） |
| 对话用"说""问""答" | 对话用"冷笑道""淡淡道""沉声道" |
| 情绪写动作 | 情绪写形容词 |
