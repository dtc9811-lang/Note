# 第十世写作工具包·工作流总纲

> 适用模型：Qwen3 8B / Flash 类轻量模型（长程一致性弱、易漂、爱写套话）。
> 设计前提：**不依赖模型记忆，依赖每章重发的自足提示词。**
> 单次调用上下文控制在 6—9K 字，其中提示词占 3—4K，留 2.5—3K 给正文输出。

---

## 一、为什么不能用"喂整本书 + 自由发挥"

轻量模型有四个必漂点：

1. **人名/时间漂**：把赵慎写成赵升，把第30章的事记到第10章。
2. **信息漂**：让不在场的人知道场内的事，让角色说出他不该知道的词。
3. **物品漂**：铁尺杖弯了又直，殓单烧了又出现。
4. **文风漂**：三章之后自动变成"嘴角勾起一抹弧度""眸光一凝"的通用网文腔。

所以整套系统的核心不是"更强的设定表"，而是：

> **每写一章，都把该章需要的一切重新发一遍；本章之外的东西，一律靠交接卡传递。**

## 三、单章生产流程（四步）

```
① 取本章章卡 + 上一章交接卡
        ↓
② 填进「写章提示词模板」，先让模型出【分场表】（不写正文）
        ↓
③ 人工/强模型检查分场表：人数、地点、信息差、修炼节点对不对
        ↓
④ 让模型按分场表写正文，同时产出本章交接卡
```

**第②步不能省。** 轻量模型直接写正文，十有八九会跑偏；先出分场表，等于给它一次"想清楚"的机会，也给你一次拦截的机会。

## 四、章卡是什么

章卡是章纲的"可执行版"，一章一张，固定七项：

| 字段 | 作用 |
|---|---|
| 章号 / 章名 / 档位 | 标识 |
| 地点 | 防空间漂移 |
| 在场人物 | 防人数漂移 |
| 节拍（3—6条） | 本章实际发生的事，按顺序 |
| 修炼节点 | 本章修为有没有变化，变到哪，代价是什么 |
| 信息变化 | 读者/角色本章新知道什么 |
| 本章禁区 | 绝对不能出现的东西 |
| 结尾钩子类型 | 危险逼近 / 人物翻脸 / 力量暴涨 / 真相露头 / 留白 |

---

## 五、交接卡是什么

交接卡是"记忆"，固定六项，每章写完立刻产出：

1. **已经发生的事实**（只列正文确认过的）
2. **各人所知**（谁在场、谁不知道）
3. **当前错误答案**（众人暂时相信什么）
4. **未兑现的细节**（物件、伤势、承诺、伏笔）
5. **本章结束时的可见状态**（地点、在场人、关键物品、刚发生的物理变化）
6. **下一章禁区**

**下一章的提示词里，只带交接卡，不带上一章全文。** 这样上下文永远恒定，不会越写越挤。

## 六、模型参数建议

| 项 | 建议 |
|---|---|
| 温度 | 正文 0.7—0.85；分场表 0.4 |
| top_p | 0.9 |
| 单章目标字数 | 1800—2500字（轻量模型的最稳区间） |
| 上下文 | 至少 16K；若只有 8K，把文风样本压到 1 段 |
| 重试策略 | 不合格只重写不合格的段落，不要整章重来 |
| 禁止 | 不要让模型"自由发挥下一章" |

---

## 七、质量闸门（每 10 章一次）

- 连续 10 章没有一次修炼进展 → 停下来补
- 连续 10 章没有一次冲突升级 → 停下来补
- 检查人名、物品、时间是否和交接卡一致
- 检查文风是否已经滑向通用网文腔
- 检查伏笔表：哪些该埋、哪些该收
