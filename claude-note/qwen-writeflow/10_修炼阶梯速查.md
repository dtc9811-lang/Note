## 突破章的三段写法（强制）

```
第一段：决定
  他为什么必须现在突破？不突破会怎样？写他做的准备（资源、地点、时间）。

第二段：硬扛
  过程要疼、要险、要有失败的可能。写：疼在哪、撑了多久、差一点怎么死的。

第三段：成了
  写身体的变化、仙炁的数量变化、他能多做什么。
  然后立刻用出来一次——打人、救人、破局，随便，但必须用。
  最后写代价：虚几天、留什么后遗症。
```

## 修为的量化写法（必须给数字）

| 维度 | 写法 |
|---|---|
| 仙炁 | 一缕 → 三缕 → 七缕 |
| 洞天 | 从"没有"到"三里"到"十五万里" |
| 温石 | 三块、七块、一炉 |
| 持续时间 | 能撑三息、能撑半日 |
| 后遗症 | 三日不能睡、三个月不能动 |
| 战力对标 | ≈寻常仙墟客 / 普通真仙散修 / 真仙初期 / 真仙中期 |

## 禁止

- 禁止用"他闭关了一段时间，修为又有精进"带过任何一重。
- 禁止让修为增长没有代价。
- 禁止越级秒杀。赵升前期可以硬扛同级、可以越阶自保，不能越阶硬杀。
- 禁止把仙炁写成"灵气""真元""能量"。
