# 06 固定术语表

> 用途：阻止轻量模型用同义词替换专有名词。
> 规则：**不得使用右列的替代写法。**

| 正式写法 | 禁止的替代 |
|---|---|
| 温石 | 暖玉、热石、火石、仙玉 |
| 炉心 | 核心、火源、炉核、心脏 |
| 本源仙炁 | 仙气、灵气、元气、真元、能量 |
| 宙光残层 | 时空层、历史层、平行世界、幻境、幻象 |
| 无限宇空之门 | 传送门、空间门、宇空门 |
| 仙墟劫户 | 矿奴、苦役、罪户、贱籍 |
| 无归渡 | 无名渡、归墟、渡口（首次出现后固定为无归渡） |
| 保姓 / 改姓 | 主脉/旁支、正支/分家 |
| 劫户点名印 | 令牌、印章、铁印 |
| 铁尺杖 | 拐杖、铁棍、铁杖 |
| 本命五行洞天 | 丹田世界、内天地、小世界 |
| 解封九重 | 恢复境界、觉醒、解锁、升级 |
| 牧原真君 | 牧原、真君、那位大人 |
| 生死断笔 | 生死笔、轮回笔、断笔 |
| 混元仙体 | 混元体、仙体、混沌体 |
| 不朽仙魂 | 仙魂、神魂、元神 |
| 长照 | 长照渡、长昭、常照 |
| 岑固 | 监墟使（首次点明后固定用岑固） |
| 步纲君 | 图正（首次点明后固定用步纲君） |

---

## 固定量词与单位

| 用法 | 说明 |
|---|---|
| 一块温石 | 不用"一颗""一枚" |
| 一缕仙炁 / 七缕仙炁 | 修为的单位，可数 |
| 一重 / 一转 | 解封与洞天的层级单位 |
| 三里、七盏、十步、三息 | 数字要具体 |
| 十五万里 | 洞天尺度的标准写法 |
