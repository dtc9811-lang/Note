# 百世飞升 · 第十世续写

正文工作区：`F:\novel`。

## 当前目录

```text
F:\novel\
├─ AGENTS.md                     AI 开工入口
├─ README.md                     本页
└─ 百世飞升续写\
   ├─ 分章\                      正文唯一真源
   ├─ 全本.txt                   由脚本生成，不手改
   ├─ 脚本\                      正文管理、候选稿与文风体检
   ├─ 写作资料\                  四份长期资料
   ├─ 规划\                      当前人物、对手与批次索引
   └─ 重写压缩\
      ├─ 正文\                   尚未晋升分章的候选正文
      └─ 工单\条目\              只保留未完成和当前批次工单
```

## 权威顺序

1. 正文事实：`分章/`；续写候选阶段再接 DevTrace 已验收候选正文。
2. 当前任务、裁定和验收：DevTrace。
3. 固定设定：`写作资料/02_设定总表.md`。
4. 宏观方向：`写作资料/03_长期总纲.md`。

历史草稿、验收前版本和旧章副本不在工作树里重复保存，直接从 Git 历史取回。

## 标准协作

```text
规划 skill 写施工单并进 DevTrace
→ 写作 skill 逐章领取并交稿
→ 候选稿体检.py + 文风体检.py
→ 验收 skill 通过或局部退修
→ 晋升分章后生成全本并检查
```

## 常用命令

```bash
cd F:/novel/百世飞升续写
python 脚本/正文管理.py 状态
python 脚本/候选稿体检.py 重写压缩/正文/新NN_章名.md
python 脚本/文风体检.py <章号或文件>
python 脚本/正文管理.py 全本
python 脚本/正文管理.py 检查
```
