## 提交

GitHub 在国内直连会断，本仓库已配好走本地代理：

```bash
cd /f/novel
git add -A
git commit -m "写了第XXX章"
git push
```

> 代理配置在本仓库的 `.git/config`（`http.proxy = http://127.0.0.1:7897`），
> 需要 Clash 开着。换机器要改这个值。
