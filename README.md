# 百世飞升 · 第十世续写

《百世飞升》（白眉罗汉，已完本）的同人续写，第十世。

本目录既是写作工作区，也是 git 工作副本（remote: `https://github.com/dtc9811-lang/Note.git`）。

> **给 AI 的入口是 `AGENTS.md`**（目录、命令、铁律、坑都在那）。本页给人看。

## 两种正文形态

| 用途 | 文件 | 说明 |
|---|---|---|
| 改正文 | `百世飞升续写/分章/第NNN章_….md` | **唯一真源**，111 个 |
| 通读 / 喂整本 | `百世飞升续写/全本.txt` | **生成物**，由脚本合并，别手改 |

## 常用操作

```bash
cd F:/novel/百世飞升续写

python 脚本/正文管理.py 状态          # 看看写到哪了
python 脚本/正文管理.py 检查          # 全本和分章同步没
python 脚本/正文管理.py 插入 65 xx.md  # 在第65章后插一章，自动重编号
python 脚本/正文管理.py 替换 8 xx.md   # 替换第8章
python 脚本/文风体检.py 112           # 体检某一章

cd /f/novel && git add -A && git commit -m "写了第112章" && git push
```
