## 用法（四步）

```
1. 打开 分段/01_ch001-004.md
2. 复制 修改提示词.md 的模板，末尾把这份文件全文粘上去
3. 发给 Qwen（/thinking off）
4. 它输出的完整正文，保存为 修改/01_ch001-004.md
```

**一次一份，改完一份再做下一份。** 不要一次让它改好几份。

## 体检（改完一份就查）

```bash
cd "F:/novel/百世飞升续写"

```

它会输出：
- 每份是"改"还是"原"
- 总章数、总字数
- **过短的章（<500字）清单**——这些就是"像提纲"的章

## 合成一本

```bash
cp 1-105.txt "1-105.bak-$(date +%Y%m%d-%H%M%S).txt"
python 分段/合并脚本.py --write
mv 1-105.改后.txt 1-105.txt
```

合并脚本会：
1. 优先读 `修改/` 里的稿子，没有的用 `分段/` 原文补
2. 重新编号（因为可能插了补写章）
3. 先预览，加 `--write` 才写文件
