# 改稿工作流

> 目标：把 105 章逐段改好看——去掉流水账、补上冲突与情绪、把过短的章写足。
> 方法：**单遍改稿 → 脚本体检 → 定点修补**。不搞两遍法，省一半时间。

---

## 一、总流程

```
┌─ 准备：/thinking off，切到 qwen3.8-flash
│
├─ 1. 复制 修改提示词.md 的提示词，只把段号 06 换成要改的段号
├─ 2. 发给 Qwen
│     → 它自己读 分段/XX_chAAA-BBB.md（要点 + 原文）
│     → 它自己写 修改/XX_chAAA-BBB.md
├─ 3. 跑 python 分段/体检脚本.py XX
├─ 4. 按体检结果发定点修补指令（只改有问题的那几处）
└─ 5. 下一份
```

**一次一份。** 不要一次让它改两三份，也不要让它"顺便改下一段"。

### 全文如下：

它自己读、自己写，**你不用粘原文，也不用手动保存**。
写完它会回一句"已完成"并列出写入的章节号；若它没写文件，用提示词末尾的"备用版"。

## 三、每段的三道体检

改完一份，跑：

```bash
cd "F:/novel/百世飞升续写"
python 分段/体检脚本.py 06
```

它查六项：

| 项 | 查什么 | 不合格说明 |
|---|---|---|
| 章节数 | 改稿和原文的章数是否一致 | 漏章/多章 |
| 字数 | 总字数变化；逐章缩水 >15% 的列出来 | 删了事 |
| 术语 | 原文有、改稿没有的专有名词 | 被同义词替换或删了 |
| 数字 | 原文有、改稿缺的数字 | 具体细节丢了 |
| 禁用词 | 嘴角勾起、眸光一凝、淡淡道… | 网文腔 |
| 文风 | 「的，」密度、单句逗号数、引号数 | 超 4/千字、超 6 个逗号 |

**术语和数字这两项，是防"丢事件"的主力。** 它们一报警，说明它改了事实，必须修。

## 四、定点修补指令（照抄用）

| 体检结果 | 发这句 |
|---|---|
| 章节数不一致 | `你少了"第X章"，补回来，其余不动。` |
| 某章缩水 | `"第X章"比原文少了很多，检查是不是把"XXX"这件事删了。如果删了，补回来，不要改别的。` |
| 术语缺失 | `"XXX"这个词在原文里有，改稿里没了。用回原词，不要替换。` |
| 数字缺失 | `原文里的"XXX"这个数字不见了。补回去，只改这一处。` |
| 禁用词 | `把"嘴角勾起一抹弧度"改成具体动作。只改这一处。` |
| 「的，」超标 | `把"的，"连用的句子拆开，单句不超过6个逗号。只改这几句。` |
| 长逗号串句 | `把"XXX"这句拆成短句。只改这一句。` |

**核心原则：修补只改被点名的地方，不许它顺手改别的。**

## 五、判断"改好了没有"的标准

一份改稿合格，要同时满足：

1. **事件一件不少**（体检的术语/数字两项不报警）
2. **章末钩子换了类型**：不再是清一色"细节＋留白"，出现"危险逼近""人物翻脸""力量暴涨"
3. **每章至少一场有来回的对话**（引号数应比原文上升）
4. **过短的章写足了**：原文 <500 字的章，改后应 ≥1000 字
5. **没有禁用词**，「的，」≤4/千字，单句 ≤6 个逗号
6. **主角有情绪外露**至少一次（说狠话、笑、把话扔回去）

第 6 条没法用脚本查，只能人眼看。

## 六、全部改完再合并

```bash
cp 1-105.txt "1-105.bak-$(date +%Y%m%d-%H%M%S).txt"
python 分段/合并脚本.py --write
mv 1-105.改后.txt 1-105.txt
```

没改的份会自动用原文补上，所以**可以分批改、随时合并**。

## 七、和"修炼补写"的关系

**先把改稿做完，再补写修炼章。**

原因：改稿会改变文风。如果先补写，补写章的文风就和你改后的文风不一致，还得回头重写。

顺序：
```
① 19 份改稿（本流程）
② 合并，得到 1-105.txt（新文风版）
③ 再做 补写/ 里的 9 个修炼点
④ 合并，得到最终版
```
