# 修改提示词（agent 版·直接读写文件）

> 用法：把下面整个代码块复制发给 Qwen，**只改一处**——把 `06` 换成你要改的段号。
> 它自己读 `分段/06_ch033-040.md`，自己写 `修改/06_ch033-040.md`。
> 你不用粘贴原文，也不用手动保存。

---

````
改稿任务：分段 06。

第一步：读 F:/novel/百世飞升续写/分段/06_ch033-040.md
这个文件里有【本段修改要点】和【原文】两部分。全部读完再动笔。

第二步：把这一段重写得更好看，一个字的事实都不能改。

━━━━━━━━━━━━━━━━━━━━
一、绝对不许改的东西（违反了这份稿子就废了）
━━━━━━━━━━━━━━━━━━━━

1. 已经发生的事，一件不能丢。谁来了、谁走了、谁死了、谁说了什么、什么东西到手了、什么事定下来了、什么人答应了什么——全部保留。事件的先后顺序可以调整，事件本身不能动。
2. 人物生死不能改。路网认了谁、账本发了几份、伏笔埋在哪一章，全部不能动。
3. 不新增重要人物、不新增门派、不新增地名、不新增设定、不新增规则。
4. 人名、地名、物品名必须和原文完全一致，不得用同义词替换。
   （"无归渡"不能写成"归墟"；"仙体醒两成"不能写成"觉醒"；"账本"不能写成"账册"。）
5. 不得提前揭露后文的谜底。尤其"归处"这三个字只许出现、不许解释；残图断口、轮回，一个字都不许碰。
6. 正文里绝不能出现"第X章""本章""上一章""前文"这类元叙述。
7. 原有章节标题保持原样，一章都不要合并、不要拆分、不要增删。

━━━━━━━━━━━━━━━━━━━━
二、本书硬规则（不可违反）
━━━━━━━━━━━━━━━━━━━━

A. 仙墟内法力只出不进、消耗加倍。仙墟外（坊市、路网、渡口、洞天）法力正常。
   所以仙墟里的仗是"配额仗"：靠神识、符、器、阵、混元仙体、本源仙炁、规则与地利。
B. 路网只认功能，不认名字、名分、凭证。做样子也算做。
C. 三条规矩：灯不熄、门不锁、来者先医后问。
D. 修炼进度以原文为准：仙体醒两成（第70章）、两成半（第96章）、三成（第105章）。
   第70章之前，绝对不许出现"两成"或更高的醒度。
E. 洞天一直存在，他往里面放东西，但第105章之前没开过门。不要写"重开洞天"。
F. 洞天很小（不足四里），不要和陨落处的旧洞天（十五万里）搞混。

━━━━━━━━━━━━━━━━━━━━
三、文风铁律（改稿的唯一目的就是往这个方向靠）
━━━━━━━━━━━━━━━━━━━━

冷、慢、实。第三人称限知，视角贴着赵升。
句子短，段落短。少形容词，多可核对的具体物。
情绪藏在动作里，不直接写"他很愤怒"，写他做了什么。
环境细节要能承担信息：温度、声音的长短、积灰的速度、石板的缝。

硬指标：
- 每章 1000—2000 汉字。原文不足 500 字的章，必须扩写到 1000 字以上。
- 「的，」密度不超过 4/千字（不要用长逗号串句）。
- 单句不超过 6 个逗号。
- 少用空动作：不堆"看了一眼""没有说话""停了一下"。

绝对不许出现的词句：
- 嘴角勾起一抹弧度 / 眸光一凝 / 眼中闪过一丝精芒
- 气息暴涨 / 恐怖的威压 / 毁天灭地的力量
- 他心中一凛 / 暗道不好 / 不禁倒吸一口凉气
- 淡淡道 / 冷笑道 / 沉声道
- 与此同时，在另一个地方……
- 他突破了 / 修为又精进了一层
- 仿佛来自九幽地狱的声音

不许写心理总结。凡是"他明白了""他知道这一切都是……"这类句子，一律改成他做了什么。
对话用"说""问""答"，不用"喝道""嗤笑""幽幽道"。

━━━━━━━━━━━━━━━━━━━━
四、怎么改才叫"更好看"（六条手法）
━━━━━━━━━━━━━━━━━━━━

1. 流程压成一句，冲突展开成场景。
   点卯、登记、发引、注销、缴贡、分账、发牌照这类流程，一句话带过；
   人和人的拉扯，写足。
   原文里凡是"某某日，谁做了什么"这种台账句子，都要变成当场发生的事。

2. 让主角有情绪。
   他可以说一句狠话，可以笑一次，可以当着人把对方的话原样扔回去。
   原文太克制了——克制是高级的，但连续克制一百章等于没有情绪。本段至少要放一次。

3. 章末钩子换类型。
   不要每章都是"某个细节＋留白"。四类轮着用：
   危险逼近 / 人物翻脸 / 力量暴涨 / 真相露头。

4. 太短的章写足。
   原文有些章只有三四百字，像提纲。要写成一个完整的场面：
   有地点、有在场的人、有发生的事、有爆发的瞬间、有收尾的动作。

5. 每章至少一场有来回的对话，或一次清晰的物理危机。
   对话不要一问一答就结束，要有三四个来回，中途落回身体或环境。

6. 把"说过的话"变成"做过的事"。
   原文里大段的解释和说明，能改成人物当场做出来、或者被人问出来的，就改。

━━━━━━━━━━━━━━━━━━━━
五、第三步：写入文件
━━━━━━━━━━━━━━━━━━━━

把重写后的完整正文写入：
F:/novel/百世飞升续写/修改/06_ch033-040.md

写入要求：
- 用 write 工具整体写入（覆盖原内容），不要用 edit 追加
- 文件里只放正文，从第一个 `# 第33章 ...` 开始
- 保留原有章节标题，格式为 `# 第N章 标题`
- 本段全部 8 章都要写进去，一章都不能少
- 不要写"修改要点"、不要写点评、不要写总结、不要写字数统计、不要写"以下是重写后的正文"
- 写完后回复一句话：已完成，并列出你写入的章节号
````

## 常见故障处理

| 症状 | 发这句 |
|---|---|
| 只改了一两章 | `你只写了前两章。把本段剩下的章节全部补齐，写进同一个文件，覆盖它。` |
| 文件里混进了说明 | `把文件里"以下是我重写的内容"这类说明删掉，只留正文。` |
| 加了新人物地名 | `把你自己造的名字删掉，原文里没有这个人。改成"一个人""那座渡口"。其余不动。` |
| 提前解释"归处" | `删掉关于"归处"的解释。这三个字只许出现，不许解释。` |
| 字数没变、还是提纲 | `第X章你没写开。把"XXX"那一场写成完整场面：地点、在场的人、发生的事、爆发的瞬间。不要推进剧情，只加密度。只改这一章。` |
