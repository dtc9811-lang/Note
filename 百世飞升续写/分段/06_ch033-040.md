# 第33章 点灯

那天夜里，赵升没有睡。

他先叫起赵九满和赵素，三个人去了断堤。断堤靠西的一段还差一点没稳住，白天人多事杂，顾不上，只有夜里补。三个人摸黑搬石块，一块一块垫进去，垫到踩上去不再晃。赵九满的胳膊上蹭掉一块皮，他骂了一句，接着搬。

垒完之后，赵升让赵素去取灯油。西门外沿那排旧灯架一共四只，铁的，站在堤外侧，油碗旧了，赵素用布一只一只擦过，倒进新油，点上。

四点火立起来，堤外那一段路就被照出了一条边。

然后赵升站到堤上，往西边那条青石板路的方向看。

路在夜里发着一点旧光，不是灯光，是石板上那层被走出来的亮，在月色下反着，一直伸进雾里。他在堤上站了将近半个时辰，没有动。

赵素在旁边借着灯记账。记完合上账册，站在他旁边，也往那边看。“在等它转弯？”她问。

“不知道。”赵升说。

风从死区方向来，带着那股惯常的味道。四只灯架上的火烧得很稳，门额底下那七盏石灯也亮着，一夜没熄。

次日清晨，天亮之前，赵茂在西门守夜。他先是听见了一种声音——均匀的，低沉的，像有什么东西在地面上缓缓挪动，不快，但一直不停。他把耳朵贴到门板上听，声音更清楚；他推开门往外看，雾里什么都看不见。

天亮，他跑去找赵升。

路拐弯了。

从前那条笔直伸向死区方向的青石板路，最靠近无归渡的那一段，大约十几丈，轻微转了一个角度。新的方向指向无归渡的西门，而不是坊市的中央。

# 第34章 两边都得进门

路拐弯的消息传出去之后，两派都来了人。

堵路派来得早。五个人，站在西门外，没有进门，话说得很直接：这条路来历不明，现在又开始自己转向，必须关闭西门，不能让它接近有人的地方。

“我关了门，你们打算怎么把它引走？”赵升站在门里问。

五个人互相看了看。

“路走过来了，不管开不开门，它已经快到这儿了。”赵升说，“关了门，它到了门口转不进来，就往别处去。往坊市去。坊市没有堤，没有灯，没有人守着。那时候怎么办。”

五个人走了。

过了晌午，来了三个通路派的，说无归渡是这条路离得最近的渡口，路来了正好，开着门，把通路权控在自己手里，比让坊市那边抢去强。

“正在想。”赵升说。

三个人还想说，被赵九满挡在门外，只好也走了。

整个白天，陆陆续续来了四批人。每批说法不一样，有的劝开门，有的劝关门，有的只来打探，但有一件事是一样的——不管哪边，都要先走进无归渡的门，站在赵升面前说上几句，才能出去。

赵素在账台旁边把这一天来的人记了满满两页，记完把笔搁下，说了句：“路还没到门口，人先到齐了。”

午后，赵长庚从里头走出来，站在赵升旁边，看着进进出出的那些人。

“你已经接了路。”老头说，“他们都看见了。”

“嗯。”

赵长庚磕了磕杖头，没再说别的，转身进去了。

傍晚，一队打着正册旗号的人到了。六个人，走在最前头的是个中年修士，官袍正红色，腰上挂着职务牌。他在门口站定，没有跨进来，先把无归渡的门额和七盏灯打量了一圈，再看了赵升一眼，才开口。

# 第35章 图正

“这里就是申报了接管的那处废渡？”

“是。”赵升说，“待批。”

那人点点头，没有立刻进来。他往门里看了半圈——前厅里铺着草席，席上有几个还没走的伤号，廊下晾着包扎用的布；门额底下七盏石灯亮着，天色还没黑，灯就先点了。

“你们是赵氏的人。”

“是。”

他从随从手里接过一份文书，展开，隔着门槛递过来。赵升接了，低头看了一眼——官制格式，封泥，盖章的地方空着。他看完，还回去。

“我是步纲君，葬仙墟外围路线登记处图正，正九品。”

他说话不快，字咬得很清楚，说完停了一下，等对方把这个身份消化掉。

“葬仙墟外围最近出现了一条来历不明的路。”他接着说，“目前没有纳入正册，属于野路，不受官方保护，通行凭证不合法。进去的人没有准入资质，出了事没有人负责，带路的人没有正式牌照。”

他又停了一下。

“这一切问题，都可以通过一个办法解决——纳入正册，发引，组织一次有资质的探索队伍，把这条路正式登记。此后的通行就有了法理依据。”

他说完，看着赵升。赵升没有接话，往台阶上站了半步，让出门里的光。

“这个方向上，离这条路最近的是无归渡。”步纲君说，“赵氏愿不愿意出几个带路人，协助探路？”

赵升想了想。

“图正说的正册，能说得详细些吗？”

步纲君觉得这个问题在意料之内，把说辞整理了一下，准备解释。

# 第36章 正册

步纲君把正册的规矩解释了大约一个时辰。

正册是葬仙墟外围通行管理的官方系统，每一条被登记的路、每一处被登记的渡口，都在上面有条目。登记了的地方，探险队可以申请发引；有了发引，出了危险才能启动救援流程；遗物在路上出了纠纷，才有地方说理。

注销这一条，步纲君用了不到两句话带过：一处渡口如果不再运营，向路线登记处提交注销申请，批准之后从正册撤销条目，该条目可以转挂到其他渡口名下，或者空置。

赵升在这两句话后，问了第一个问题：“注销是渡口自己申请，还是上头核查以后才能注销？”

步纲君说是渡口自己申请，提交文书，盖章，走流程，一般十五日内批准。

赵升问第二个问题：“注销之后，原来这处渡口名下的路网条目，是一起注销，还是可以转到另一个名字下面？”

“可以转。转挂是标准流程，申请里写清楚转到谁名下，两方签字，盖章，走流程。”

赵升问第三个问题：“转挂之后，路还认原来那个名字，还是认新名字？”

步纲君停了一下，才说：“这个……是路认地方，不认名字。登记是一回事，路实际上怎么走是另一回事。”

赵升点了点头，没有再问。

这套东西他见过。

第四世他做过一世的家主。族里有人犯了事，把名下的产业转挂到旁支名下，等风头过了再转回来，账面上干干净净。后来他又见过一回：一个宗门被并，名先挂过去，人慢慢换，三年之后，原来那一支连自己姓什么都要想一下。

流程不会骗人。流程会把人绕进去。

他问那三个问题，不是找漏洞。他是想看看，这个做了很多年图正的人，知不知道他自己手里这套东西是干什么用的。

步纲君觉得这三个问题有点奇怪，但整体而言他认为赵升在试探漏洞或寻找拒绝的理由，接着说了注册的具体好处，说了一刻钟，收了文书，告辞。

门外，他对随从说了一句：“这批劫户，心眼多了些。”

# 第37章 招募

远征队的名单，在步纲君的文书上一共六十三个人。

步纲君的正册队三十人，带阵旗和护盾符，按正式探索队编制配备。赤铢商号出了二十人，窦让带队，每个人储物袋鼓鼓的。

临出发前他找过赵升，说这一趟的路线钱他出双倍，条件是走在队伍中段，前后都有人垫。赵升没答应，也没拒绝，只说按名单走。窦让以为那是默许。

散修那边出了十个，七拼八凑，有卫老修士，瘸着腿，身边带着十几个同行，都是吃过苦头的老仙墟客。

赵氏三个：赵升，赵九满，赵茂。

名单念完，步纲君扫了一眼赵茂那只裹着布的手，没有说话。

赵茂站在赵升旁边，没有低头，也没有辩解，把那只手搭在铁钎上，站得直。

赵九满悄声问赵升：“茂子这手能带吗？”

“能。”赵升说，“他去最外侧，走的时候伸着手。”

赵九满没再问。他知道赵升不解释的事情，问了也白问。

出发定在第二天一早。

当天夜里，赵升去了一趟库房。

库房在渡口最里面，一道旧木门，锁是他自己加的。他把锁打开，推门进去，在黑暗里摸到了油灯，点上。

棺船就在右侧石墙旁边，船身深黑色，七口棺材整齐码在舱里，棺盖上钉着的七张殓单，白纸折叠，比上次看还白了一点——旁边那些三万年风化的石头越来越深，白纸就越来越白。

他在库房里站了一刻钟，没有动，没有打开棺盖，也没有取那些殓单。

最后他把油灯吹了，锁上门，回去了。

回到账室，他没有睡。

他拿出符纸和朱砂，画符。

画符三步：选纸，调砂，落笔。

纸要用陈年的黄纸，新的不吃墨。他这一把是从坊市买的，抽出一张，对着灯看了一遍，中间有一处薄了，抽出去扔掉。

朱砂要用灵砂磨。磨到极细，兑一点水，再兑一点他自己的法力——符能不能用，就看这一点法力匀不匀。

落笔最费。

一笔下去，气要跟着走。走慢了，符就死；走快了，符就散。他画的是火符，笔画走的是火行的路子，从头到尾不能断。

第一张，断了。

第二张，前半截成了，后半截散了。

第三张，成了。

他歇了一会儿，接着画。

一晚上，画了九张，成三张：两张火符，一张困符。

剩下六张废了，朱砂也用去大半。

他把三张收进怀里。仙墟里画符，十张成三张，已经算好的。

第二天天亮，六十三个人集合，从西门出发，踏上那条青石板路。

# 第38章 出发

路走起来，和赵升预想的一样，也不一样。

一样的是安静——六十三个人走在上面，没有风声，没有正常仙墟里那种远处遗迹沉降的声音，只有脚步声，是自己的。不一样的是路面是实的，踩上去有回响，反而比他想象的更像一条普通的路。

队伍排得很长。前头是三十人的正册队，旗插在肩后；中间是赤铢商号的二十人，窦让走在队首；散修十个落在后头，卫老修士瘸着腿，走得慢；赵氏三个人被夹在中间，赵升走在靠右的位置。

走了大约半日，赵升回头看了一眼。

来路不在了。

不是视野里看不见，是它在某个时刻悄悄换了方向。他在出发前，在路面上做了一个极小的标记——一粒黑石放在路旁的石板缝里，记得从那个位置往回看应该能看见无归渡的西门一角。

现在那个方向看不见西门，看见的是另一种地貌。

路在他们走的时候悄悄转了方向。

他没有说话，继续往前走。

走了一会儿，前头有个散修停下来，弯腰看脚底下，皱着眉：

“我的脚印呢？”

他走过的那段路，石板面有一层灰，踩过去会留印子。但回头看，前面几步的石板上什么都没有，干干净净。

那散修又往前走了几步，低头盯着自己脚下，一边走一边回头。走一步，回头看一眼，看得自己都有点发慌。

步纲君的一名引首去确认了，回来报告：“整条路，从我们走过的部分开始，都没有脚印。”

队伍里有人低声议论起来。有人蹲下去用手去摸石板，摸完站起来，手心干干净净。

“脚印不留。”步纲君皱了眉，把声音放平，“继续走。”

赵升走在队里，把这件事记下来：路在擦掉他们的痕迹，擦得很干净，像不想让人知道有人来过。

# 第39章 走得越齐挪得越快

第二日，步纲君下了命令，要求队伍整齐行进。

理由是：在陌生险地松散容易失散，按正式探索队的规矩，越是险地越需要纪律。

命令传下来的时候，队伍里大部分人没有意见。走了一天多，路会转向、脚印会没有，谁都想有个东西靠一靠，整齐的队列给的就是这个。

赵升听了这个命令，没有立刻说什么。

这两天他一直在观察一件事：路的变化频率，和队伍走路的整齐程度，有没有关系。

第一天走得散，各走各的，有时候赤铢商号的人跑到最前头，有时候卫老修士的散修落在最后面。那天路的漂移，约摸每走三里漂一段，幅度小。

今天步纲君要求整齐走，三十人的正册队当先，后头跟着，队列基本对齐。路的漂移明显加快——赵升数了一下，走了不到两里，路就漂了一段。

他又数了一遍，还是不到两里。

他没有说出这个观察，只是对赵九满和赵茂说：不要跟大队走，靠着路的右边沿，走自己的步调，不要配合整齐行进。

“为什么。”赵九满问。

“整齐了它才动得快。”

赵九满没听明白，但照着走了。

走到下午，路右沿外侧两步的位置踩下去，脚下空了——不是深渊，是真正的“没有”，那种让眼睛被拽着往里倒的没有。

队伍里有两个人走散了，一个是正册队的引首，一个是赤铢商号的役夫，两个人几乎同时走到了路的最右沿，超出了路面边缘，没有声音，没有失去平衡的过程，就从路上不见了。

旁边的人叫了一声，回头看，什么都没有。

没有落地声，没有消失的动静，就是不在了。

步纲君的脸色变了一下，重新扫了一圈队伍，把命令再下了一道：

“走得更整齐一些。”

赵升抬起头，看了他一眼。

这位图正没有别的办法。他不会看路，只会看队列；队里死了人，他能想到的第一件事，是把队排得更紧。

赵升没有劝。劝不通的人在死之前，是劝不通的。

他把赵茂往身边又拉近了半步。

# 第40章 第一版

扎营之后，赵升没有睡。

他在营地边上找了块石头坐下，把这两天看到的东西在地上划了一遍：路向哪边偏、偏了多少、队伍怎么走的、死的人站在哪儿。划完，用脚抹掉，重新划。

赵素在旁边记账。赵九满蹲在对面的石头上看着。

赵升把观察整理了一遍。

路在移动，不是随机移动，是有方向的——这几天它的漂移方向，整体上一直在朝着某一个固定的地方靠近。其次，队伍越整齐，路漂得越快。

两件事放在一起，他想到了一种可能：路在寻找某个锚点，它认的是一个具体的地方，而不是泛泛的“适合停靠的地方”。队伍越像一支正式的队伍，越有人在上面活动，就越像一个有活人在运营的路网——而路网在运营的时候，它就往它的目标拉。

那个目标是什么？

他把已知信息过了一遍。路的石板材质和那块路引吻合，路引上的目的地是“长照渡”。在葬仙墟的遗迹里，按坐标推算，旧的长照渡的位置，就在无归渡现在所在的地方。

路在找长照渡。它认的是长照渡的旧印记，而这个印记，还留在无归渡的地基里。

“残天在找它自己的旧节点。”赵升说，“它认无归渡那片地基，因为那里有三万年前长照渡留下来的东西。”

赵素把这话记在了账册上。她写完，抬头问：“要记给谁看。”

“记着就行。”赵升说。

“那怎么办？”赵九满问。

“把那个印记抹掉。”赵升说，“如果路不认得那片地方了，它就不会往那边拉。”

“那它往哪儿拉？”

“到时候再看。”赵升说。

赵九满站起来，往营地那边走。走了几步又回头，问了一句：“你确定？”

“不确定。”赵升说，“所以要抹。”

“不确定你还抹。”

“抹了才知道对不对。”
