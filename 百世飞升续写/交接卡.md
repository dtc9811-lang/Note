## 二、设定底座（不能改）

- 主角赵升：九世轮回，第九世末证得**长生真仙**（混元仙体、不朽仙魂），但轮回大道烙印被道祖削掉，落进**仙墟劫户**之身，距第九世结局约三万年。
- 第十世两条主轴：**修行**（把本命五行洞天升格为仙天→金仙）+ **经营**（从被当耗材的劫户做到诸墟联盟）。
- **仙墟内法力只出不进、消耗加倍**（硬规则）。所以仙墟里的仗是"配额仗"：靠**神识**（不吃灵气）、**符/器/阵**（百艺＝战力）、**混元仙体**（自洽）、**本源仙炁**（上一世家底，用一点少一点）、**规则/地利**。仙墟外（坊市、路网）法力正常。
- 全卷总规则：**路网只认功能，不认名字/名分/凭证。**
- 三条规矩（伏笔核心）：**灯不熄、门不锁、来者先医后问。**
- 解封台阶：仙体醒两成（ch70）→ 两成半（ch96）→ 三成（ch105）。每格都有代价。
- 法宝：生死断笔（准道器，已用）；五面镜、旧洞天、雷帝辟劫令、五雷钺在"陨落处"，是中期回收目标。

## 三、写法铁律

1. **不写"第X章"这类元叙述**（正文里绝不能出现章节号）。
2. **保节奏、补清楚**：短章不强行拉长；不清楚的地方补场景、动作、反应、章间衔接。
3. **短句为主，留白为主**。把逗号串起来的长句拆开。对照"的，"密度：前 70 章约 2.6/千字，后段要往这个数靠。
4. 少用"看了一眼""没有说话""停了一下"这类空动作（需自然，不堆）。
5. 改稿阶段不写新卷、不加新情节，只优化已写正文。（现已进入续写阶段，见 `AGENTS.md`。）
6. 改正文只改 `分章/` 下的单章文件；`全本.txt` 是生成物，不要直接改。备份交给 git（`git commit`），不用手工 cp。

## 五、验收脚本

```bash
cd F:/novel/百世飞升续写
python - <<'EOF'
import re
lines=open('全本.txt',encoding='utf-8').read().split('\n')
hdrs=[(i,l) for i,l in enumerate(lines) if l.startswith('# 第')]
s1=s2=c1=c2=0; rows=[]
for k,(i,l) in enumerate(hdrs):
    n=k+1; end=hdrs[k+1][0] if k+1<len(hdrs) else len(lines)
    b='\n'.join(lines[i+1:end]); cjk=len(re.findall(r'[\u4e00-\u9fff]',b)); d=b.count('的，')
    if n<=70: s1+=d; c1+=cjk
    else: s2+=d; c2+=cjk; rows.append((n,d))
print('的， 1-70',round(s1/c1*1000,2),' 71-105',round(s2/c2*1000,2))
print('后段>=8:',[(n,d) for n,d in rows if d>=8])
EOF
```
