## 一、查出的硬矛盾（已修）

### 矛盾1：洞天尺度前后不一致

出现处：`02_章卡模板`（四里→五里）、`13_第106章提示词`（四里→八里→五里）、`章卡/batch1`（八里→五里）、`12_卷纲`（八里→五里；ch133缩到二里）。

**问题**：没有基准值，模型会自己编。

**修正后基准（全书统一）**：

| 时点 | 洞天尺度 |
|---|---|
| ch105 结束时（立基） | **四里** |
| ch106 醒四成后 | **八里** |
| ch106 代价后 | **五里**（之后逐章恢复） |
| ch133 受损后 | **二里** |

### 矛盾2：仙炁数量前后矛盾

- `11_前情摘要`：ch105 洞天"**一点本源仙炁都没有**"。
- 但 `13_第106章提示词` 写"仙炁从**七缕**增到能离体成形"；`12_卷纲` ch120 写"仙炁从**七缕**涨到二十几缕"；`05_文风样本`样本D 也写"七缕"。

**问题**：七缕在 ch105 是 0，106 章才开始炼，源头不清。

**修正后**：**ch105 = 零缕 → ch106 醒成后 = 七缕 → ch120 = 二十几缕。**
凡是写 ch106 的样本和提示词，一律改成"从无到七缕"。

### 矛盾3：醒度与阶梯名称对不上

- `10_修炼阶梯` 表里：三＝炼体、四＝开府。
- 但同文件写"ch70＝两成（**约等于炼体**）"——两成怎么会等于炼体（三成）？
- 又写"ch105＝三成（**开府前夜**）"，可另一处写"ch105 三成，洞天立基，**这就是开府**"。自相矛盾。
- 多处写"醒三成→醒四成（**开府后第一格**）"——若四成就是开府，就不该叫"开府后"。

**修正后对应**：

| 时点 | 醒度 | 阶梯名 |
|---|---|---|
| ch70 | 两成 | 纳炁 |
| ch96 | 两成半 | 纳炁（稳固） |
| ch105 | 三成 | 炼体 |
| ch106 | 四成 | **开府**（不是"开府后第一格"） |

"开府后第一格"这个说法**全部删除**。

### 矛盾4：洞天五转 与 解封九重 的关系没定义

- 解封四重（开府）写的是"**重开**本命五行洞天"。
- 可 ch105 洞天早就存在、还能收人，并且已经完成"洞天**一转·立基**"——那时只醒三成。

**问题**：两条梯子交叉，谁先谁后没写清，模型必然写乱。

**修正后定义**（写进 `10_修炼阶梯`）：

- 洞天**一直存在**（ch19 起他就往里面放东西）。
- ch105 的"**立基**"是洞天第一次**对外**承担路网节点职能，不等于能修炼。
- ch106 的"**开府**"是洞天第一次**对内**能自产一缕本源仙炁——**这才是修炼引擎的启动**。
- 洞天五转是**远期框架**，与解封九重**不是一一对应**，只在卷末进度卡里记"洞天状态"。

### 矛盾5：`05_文风样本`样本D 自带"七缕"，与矛盾2 叠加

**修正后**：样本D 改为写"从无到七缕"的过程，并标注"这是106章的写法示例，数字以章卡为准"。

## 三、第二轮复审建议（等你补写时注意）

1. **每写完一章，立刻更新 `14_写作进度台账.md`**，否则十有八九会忘。
2. **每10章检查一次醒度**：本卷应出现 106、115、124、133 四个节点，少一个就是没写。
3. **警惕"七缕"类数字漂移**：数字是唯一能防住轻量模型自编的东西，一旦前后不一致，读者立刻掉出故事。
4. **警惕模型自己给渡口、仙墟起名**：本卷新仙墟**不给名字**，只说"那座墟"。
5. **警惕"归处"被解释**：这是全书最重要的未解伏笔，ch88 和 ch105 各出现过，本卷只允许再出现一两次，一字不得解释。
