# 07 禁区与自检清单

> 每章写完过一遍。发现一条只改那一段，不要重写全章。

---

## A. 世界观禁区（全书级）

1. 仙墟内法力只出不进、消耗加倍。不得让赵升在仙墟里随便施法。
2. 路网只认功能，不认名字、名分、凭证。不得偷偷加"但路网能分辨诚意"的补丁。
3. 不创造私人仙墟，不设"墟主"职业。
4. 不建立赵氏仙朝，不让诸修排队臣服。
5. 不让宙级能力变成无代价的时间穿越。
6. 不杀赵玄靖、鸿运子、天运子、石灵。
7. 前段不揭露轮回终局，只呈现"缺一环"。
8. "归处"一栏一字不得解释。
9. 不得使用已废止方案：残灯、石灵护送、千人村、第1001人、记名供灯、五镜副本。

## B. 本章级禁区（章卡里单列）

- 不能出现的人物
- 不能提前揭露的真相
- 不能写成的套路

## C. 文风自检

- [ ] 有没有"嘴角勾起/眸光一凝/气息暴涨/倒吸一口凉气"类套话？
- [ ] 有没有"与此同时，在另一个地方"式切换？
- [ ] 章末有没有抒情、总结、上价值？
- [ ] 对话是不是一问一答就结束？
- [ ] 单句逗号是否超过6个？「的，」密度是否≤4/千字？
- [ ] 是否堆了"看了一眼""没有说话""停了一下"？

## D. 逻辑自检

- [ ] 人数守恒：进去几个、出来几个、死了几个？
- [ ] 空间守恒：从A到B的移动过程交代了吗？
- [ ] 时间守恒：说了"三日"就真的过了三日？
- [ ] 物品守恒：和交接卡里的状态一致吗？
- [ ] 信息守恒：有没有人说了他不该知道的事？
- [ ] 规则守恒：有没有偷偷改掉已公开的规则？

## E. 节拍自检

- [ ] 章卡每个节拍都写到了吗？
- [ ] 修炼节点写足五段了吗（决定→硬扛→成了→当场用出来→代价）？
- [ ] 结尾钩子类型和章卡一致吗？
- [ ] 字数在1500—2500之间吗？

## F. 十种最常见的失败

| 失败 | 表现 | 修法 |
|---|---|---|
| 加设定 | 冒出没写过的门派/功法/地名 | 直接删，不解释 |
| 加人物 | 冒出一个没在章卡里、还有名字的人 | 改成不具名的"一个人"或删 |
| 提前揭秘 | 早早点破轮回/归处 | 改成只呈现现象 |
| 抒情结尾 | 末尾写感慨 | 删掉，换成具体动作 |
| 心理总结 | "他明白了，这一切都是……" | 换成他做了什么 |
| 对话注水 | 聊三页没有新信息 | 砍到2—4轮，落回动作 |
| 修炼开挂 | 白拿修为、越级秒杀 | 补门槛、补代价；改成靠规则赢 |
| 数字模糊 | "许多温石""无数的人" | 换成具体数字 |
| 长逗号串句 | 一口气十几个逗号 | 拆成短句 |
| 同义替换 | 把"仙体醒三成"写成"觉醒" | 按术语表改回 |

## G. 不具名角色规则（防串线）

轻量模型最爱给路人起名，一起名就会在后面串线。

- **没有在章卡里写出名字的人，一律不具名**：写"一个散修""渡口的帮手""死者的家属""两个年轻人"。
- **禁止给以下类型起名**：路过的散修、商队伙计、渡口帮手、死伤者、传话的人。
- **新地名一律不给名字**：本卷的新仙墟只说"那座墟""新仙墟"，不命名。
- **已存在于前105章的地名不得改名**：无归渡、合利渡、葬仙墟、长照、古驿、正册、坊市。
- **已存在于前105章的人名不得新增同名**：苗七、祁广、谢青、窦让。
- 如果模型自己造了名字，**直接删掉换成不具名，不要保留**。

## H. 一个合格章节长什么样

1. 开头三句内交代地点和此刻在干什么。
2. 中段至少一场有来回的对话，或一次清晰的物理危机。
3. 有一个可核对的细节在结尾起作用。
4. 修炼章要有：决定 → 硬扛 → 成了 → 当场用出来 → 代价。
5. 最后一句停在动作或画面上，不解释。
