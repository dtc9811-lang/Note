# prompts/生成章卡.md

> 用途：把章纲转成可执行章卡。**用强模型做这件事，不要用轻量模型。**

---

## 提示词

```
你在为《百世飞升》第十世做写作执行准备。

给你章纲的一段（附后），请拆成逐章章卡，一章一张，严格用下面的格式。
不要写正文，不要新增设定，不要新增人物。

【章卡格式】
# 第___章　章名：__________
档位：
地点：
在场人物：（全名，人数=___）
节拍：
1.
2.
3.
（3—6条，按顺序）
世界阶：
- 界域__ → __ ／ 路网__ → __ ／ 仙籍__ → __（无变化写"无"）
- 若上阶：门槛／代价／当场用出来
修炼节点：
- 有无：
- 若有：醒__成 → 醒__成；门槛是____；代价是____；当场用出来做了什么____
信息变化：
- 读者新知道：
- 赵升新知道：
- 其他人新知道：
- 不能让谁知道：
本章禁区：
- 不能出现：
- 不能提前揭露：
结尾钩子：
类型：
具体一句：

【硬性要求】
1. 地点写死；一章最多换一次地图，换地图章在章卡里标 H 档。
2. 在场人物必须全名+人数，方便后文守恒。
3. 节拍写成"发生什么"，不要写成"要表现什么"。
4. 修炼节点没有就写"无"，有就写清楚数字和代价。
5. 本章禁区至少一条。
6. 每张章卡300字以内。
7. 只输出章卡，不输出解释。

【章纲】
（粘贴）
```

---

## 分批建议

| 批次 | 章号 |
|---|---|
| 1 | 106—118 |
| 2 | 119—132 |
| 3 | 133—146 |
| 4 | 147—160 |

每批生成后人工核对：人数有没有矛盾、修炼节点有没有漏、有没有提前揭秘。

---

## 修炼节点排布建议（从106起）

按"每8—10章一个节点"排：

| 节点章 | 醒度 | 事件 |
|---|---|---|
| 106 | 三成 → 四成 | 用三年残料＋断笔旧性 |
| 115左右 | 四成 → 四成半 | 从第一个新仙墟样本里炼出 |
| 124左右 | 四成半 → 五成 | 五行归位，洞天可储人储仙炁 |
| 133左右 | 五成 → 五成半 | 洞天第一次扛住外界法则冲击 |
| 142左右 | 五成半 → 六成 | 内循环，洞天开始真正自产 |
| 151左右 | 六成 → 六成半 | 第一次用洞天自产仙炁打一场 |
| 160左右 | 六成半 → 七成 | 抗劫，外界无灵仍存续 |

**每个节点都必须：有门槛、有代价、当场用出来、不能跳过。**

# prompts/生成交接卡.md

> 每章正文写完后产出。可用轻量模型做，只让它输出交接卡。

```
下面是第X章正文和本章章卡。请只输出【交接卡】，不要重写正文。

【交接卡格式】
【第X章交接卡】
1. 已发生的事实：
   -
2. 各人所知：
   - 赵升知道：
   - 在场其他人知道：
   - 不知道的人：
3. 当前错误答案：
   - 众人以为：
4. 未兑现的细节：
   - 物件：
   - 伤势：
   - 承诺：
   - 伏笔：
5. 本章结束时的可见状态：
   - 地点：
   - 在场人数与姓名：
   - 每人手中关键物品：
   - 刚发生的物理变化：
6. 下一章禁区：
   -

【要求】
- 只写正文里确实出现过的内容，不推测，不补充。
- 300字以内。
- 不准写"大概""似乎""可能"。

【本章章卡】
（粘贴）
【本章正文】
（粘贴）
```
