# 提示词：生成交接卡

> 每章正文写完后**立刻**做。可以让千问自己做，但要求它**只输出交接卡，不重写正文**。

---

## 提示词

```
下面是第X章正文和本章章卡。请只输出【交接卡】，不要重写正文。

【交接卡格式】
【第X章交接卡】
1. 已发生的事实：
   -
   -
2. 各人所知：
   - 赵升知道：
   - 在场其他人知道：
   - 不知道的人：
3. 当前错误答案：
   - 众人以为：
4. 未兑现的细节：
   - 物件：
   - 伤势：
   - 承诺：
   - 伏笔：
5. 本章结束时的可见状态：
   - 地点：
   - 在场人数与姓名：
   - 每人手中关键物品：
   - 刚发生的物理变化：
6. 下一章禁区：
   -

【要求】
- 只写正文里确实出现过的内容，不推测，不补充。
- 300字以内。
- 不准写"大概""似乎""可能"。
- 修炼章节必须写明：醒度从几成到几成、代价是什么、当场用出了什么。

【本章章卡】
（粘贴）

【本章正文】
（粘贴）
```

## 每 10 章追加一次：修炼进度节

追加到根目录 `旧文档/交接卡.md`（旧长程卡）里：

```
## X. 修炼进度（第XXX章更新）
- 当前仙体醒度：X成
- 本卷已完成的修炼节点：第106章（三成→四成）、第115章（四成→四成半）……
- 洞天状态：几里、能否自产仙炁、能收几个人、有无损伤
- 下一次醒成需要什么：料／样本／时间／一次真实法则冲击
- 尚未兑现的修炼伏笔：洞天壁裂纹、门额上半截名、五根柱子
- 当前不能做的事（代价未消）：
```

## 交接卡常见的三种错

| 错 | 表现 | 修法 |
|---|---|---|
| 写推测 | "赵升大概是想……" | 删掉，只留事实 |
| 写上帝视角 | 把赵升不知道的事写进"各人所知" | 按人分开写 |
| 漏物品状态 | 不写门装回去了没有、灯灭没灭 | 第5项必须写"刚发生的物理变化" |
