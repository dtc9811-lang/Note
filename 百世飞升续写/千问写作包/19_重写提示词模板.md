# 19 重写提示词模板（整章改写已有章节）

> 用途：把已有某一章**整章重写**——加修炼、去流水账、补冲突。
> 关键：给它**原文全文**，并明确哪些必须保留、哪些必须改掉。

---

```
你是《百世飞升》第十世的长篇续写执行者。不要使用任何工具，直接输出文字。
现在的任务不是写新章，而是**重写下面这一章**。

【铁律】
1. 这一章里已经发生的事，一件都不能丢：谁来了、谁走了、谁说了什么、什么东西到手了、什么事定下来了。事件顺序可以调，事件本身不能动。
2. 不新增重要人物、不新增门派、不新增设定、不新增规则。
3. 人名、地名、物品名必须与原文完全一致，不得用同义词替换。
4. 不在场的人不知道场内的事。空间与人数必须守恒。物品状态必须延续。
5. 不得提前揭露后文的谜底（尤其"归处"、残图断口、轮回）。
6. 正文里绝不能出现"第X章""本章""上一章"这类元叙述。
7. 不写"嘴角勾起一抹弧度""眸光一凝""气息暴涨"这类通用网文句。
8. 不写心理总结，写动作、对话、身体反应、环境细节。

【本书硬规则·不可违反】
A. 仙墟内法力只出不进、消耗加倍。仙墟外（坊市、路网、渡口、洞天）法力正常。
B. 路网只认功能，不认名字、名分、凭证。做样子也算做。
C. 三条规矩：灯不熄、门不锁、来者先医后问。
D. 洞天一直存在，他往里面放东西，但**ch105之前没有开过门**。不要写"重开洞天"。
E. 本世洞天很小（立基前不足四里），不要写成旧洞天的十五万里。

【文风】
冷、慢、实。第三人称限知，视角贴着赵升。
句子短，段落短，少形容词，多可核对的具体物。
情绪藏在动作里。对话要有来回。环境细节要能承担信息。
「的，」密度不超过4/千字，单句不要超过6个逗号。
少用空动作：不堆"看了一眼""没有说话""停了一下"。

────────

（粘贴原文全文）

- 本章写：仙体醒__成 → 仙体醒__成

- 能力变化（给数字）：

- 当场用出来一次
- 按五段写：决定 → 硬扛 → 成了 → 当场用出来 → 代价

类型：危险逼近 / 人物翻脸 / 力量暴涨 / 真相露头 / 留白
```

## 改写方案通过后

```
方案通过。现在输出重写后的完整正文。
要求：
- 1500—2500字
- 原文里所有已发生的事一件不少
- 不起新场景（原文没有的地点不要出现）
- 每场至少一次落回身体或环境的动作
- 对话要有来回，每2—4轮落回动作或环境
- 修炼段落必须写足五段
- 「的，」不要连用成串，单句不超过6个逗号
- 结尾停在钩子或画面上，不总结、不抒情
- 输出完整正文，不要只输出改动部分
```

## 重写前必须做的事

1. **确认改哪一章**：打开 `分章/第0NN章_章名.md`，直接改这个文件。
   `全本.txt` 是生成物，**不要直接改**。
2. **只重写一章**，改完立刻存，再动下一章。
3. 改完跑一遍：
   ```bash
   cd F:/novel/百世飞升续写
   python 脚本/正文管理.py 全本      # 把改动合并进全本.txt
   python 脚本/正文管理.py 检查      # 确认全本与分章一致
   python 脚本/文风体检.py NN       # 查「的，」密度、长逗号串句、半角引号、套话
   ```
4. 提交：`git add -A && git commit -m "重写第NN章" && git push`。
   **git 就是备份**，不用再手工 cp。
5. 若重写稿另存成了文件（如 `修改/xx.md`），也可以交给脚本接管：
   ```bash
   python 脚本/正文管理.py 替换 NN 修改/xx.md
   ```

## 哪些章适合"重写"而不是"补写"

| 类型 | 判断标准 | 举例 |
|---|---|---|
| **重写** | 修炼已经出现在原文里，但只有一句话 | ch70（两成）、ch96（两成半）、ch105（三成） |
| **重写** | 通篇是流程、没有冲突场景 | ch36（正册）、ch56（注销）、ch79（第一版） |
| **补写** | 弧与弧之间有空档，可以插入新事件 | ch18后、ch25后、ch62后、ch83后 |
