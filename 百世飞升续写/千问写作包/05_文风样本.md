# 05 文风样本

> 每次写章带 1—2 段。这是"目标文风"的锚，防止模型滑向通用网文腔。
> 样本取自 `全本.txt` 中质量最高的段落。

---

## 样本A：观察型（调查、推理、日常场）

```
赵升也蹲下去。

他先看的不是石板，是缝。

石板缝里没有草。这一带的地是死的，可死了三万年也总会有几根从石头缝里钻出来的东西——葬仙墟里那种灰白色、贴着地长的枯藤，到处都是。西门里面的石阶上就有。

这条路的缝里一根也没有。

缝里也没有沙。

干净得像刚被人扫过。

赵升伸手，摸了摸石板。

凉的。

正常的凉。
```

**要点**：短段。先排除，再确认。不说结论，用具象细节逼出结论。单段常常只有一句。

---

## 样本B：冲突型（对峙、谈判、翻脸场）

```
“赵堂主。”他开口，“痛快点。开个价。”

赵升说：“和前面一样。三条。”

“我不要一样。”窦让往前半步，“我一百四十人，七车货，一夜之内全要走。我出十万仙晶，买一条最稳的路，现在就走。”

排队的人群动了一下。

十万仙晶。整个赵氏这三千年缴出去的劫贡加起来，也换不到这个数。

赵素的笔停在半空。

赵升说：“不卖。”

窦让笑了：“二十万。”

“不是钱的事。”
```

**要点**：对话短句。报价往上加，主角不动，回答比对方短。用"人群动了一下""笔停在半空"写压力，不写心理。

---

## 样本C：异常型（危险、异象场）

```
先动的是石头。

葬仙墟这一带的天上从来浮着东西。碎砖、断柱、半截门楣，三万年前从某个高处掉下来，掉到一半就不动了，从此悬在半空里，不上不下。

现在它们同时转了一下。

不是被风吹的。是像一屋子的铁屑，底下忽然有人挪了一块磁石——几千块碎石在同一瞬间调了个头，把原先朝下的那一面朝了上去。
```

**要点**：先给一个已经在场的常态，再让常态"同时"改变。用日常比喻解释，不用"恐怖的威压"。

## 样本D：修炼型（醒成、闭关场）——**需新写，这是本书最缺的**
> 下面这段是**正本 116《四成》**的目标形态，供模仿。

```
（目标形态，供模仿）

洞天里没有风。

他坐在中央那根柱子下面。柱子是空的，什么都没托。

他把三年来攒下的料一样一样摆开。残铁十七块，碎瓷一叠，两只裂口的旧坛子，还有一堆辨不出材质的灰粉。这些是仙墟里没人要的东西，是他一块一块从别人的废物清单里挑出来的。

他开始炼。

仙炁出来得很慢。第一缕用了半夜。第二缕用了整整一天。

到第三天早上，他数了数，七缕。

不够。

他知道不够。差得还远。

他没有停。
```

**要点**：修炼场也必须"实"。写料的清单、写时间（半夜、一天、三天）、写数字、写"不够"。**不要写玄而又玄的感悟，写进度和数字。**

⚠️ **具体数字以本章章卡为准。** 本样本里的"七缕"只用于**正本第 116 章**（ch115 结束时是**零缕**，不是七缕）。

## 反面清单：一律不许出现

- 嘴角勾起一抹弧度 / 眸光一凝 / 眼中闪过一丝精芒
- 气息暴涨 / 恐怖的威压 / 毁天灭地的力量
- 他心中一凛 / 暗道不好 / 不禁倒吸一口凉气
- 这一切，都要从……说起
- 与此同时，在另一个地方……
- 他突破了 / 他的修为又精进了一层
- 仿佛来自九幽地狱的声音

## 句式纪律

| 允许 | 禁止 |
|---|---|
| 短句，一句一个动作 | 一句里三个以上形容词 |
| "他做了X。做了Y。" | 长逗号串句（单句>6个逗号） |
| 具体数字（三步、七盏、三息、七缕） | 模糊量词（许多、无数、漫山遍野） |
| 对话用"说""问""答" | 对话用"冷笑道""淡淡道""沉声道" |
| 情绪写动作 | 情绪写形容词 |
| 「的，」≤4/千字 | 「的，」成串 |
