## 一、怎么用（四步）

```
① 打开本章章卡（章卡/chXXX.md）
② 打开上一章的交接卡（写到哪带到哪）
③ 填进 04_写章提示词模板.md，整段发给千问
④ 千问先出【分场表】→ 你确认 → 它写正文 → 它出【交接卡】
```

**第②步的"分场表"不能省。** 轻量模型直接写正文必跑偏。

如果懒得自己拼，`13_第106章完整提示词.md` 是一份拼好的成品，照着改就行。

## 三、三条不可违反的硬规则

1. **仙墟内法力只出不进、消耗加倍。** 仙墟外（坊市、路网、渡口、洞天）法力正常。
2. **路网只认功能，不认名字、名分、凭证。做样子也算做。**
3. **三条规矩：灯不熄、门不锁、来者先医后问。**

外加：**正文里绝不能出现"第X章"这类元叙述。**

## 四、修炼主线怎么落

- 指标：**仙体醒X成**（现有：两成 ch70 → 两成半 ch96 → 三成 ch105）
- 引擎：**洞天自产本源仙炁**（ch105 时是零缕，还产不出；ch106 开府后才能产）
- 循环：仙墟采料（不能修炼）→ 回洞天闭关 → 醒成一格 → 下次更强
- 从 106 起：**每 8—10 章一个修炼节点**，写足五段（决定→硬扛→成了→当场用出来→代价）

详见 `10_修炼阶梯.md`。

## 六、不做什么

- 不写新卷设定，不加门派功法。
- 不使用已废止方案：残灯、石灵护送、千人村、第1001人、记名供灯、五镜副本。
- 不解释"归处"。
- 不让赵升靠力量解决主线。力量是底牌，主线仍是账本、规矩、路网。
