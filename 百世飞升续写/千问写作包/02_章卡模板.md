# 02 章卡模板

> 一章一张，写之前先填好。填不满说明这章没想清楚，不要开写。

```
# 第___章　章名：__________
档位：H / M / S
地点：__________（本章原则上只在这里）
在场人物：__________（全名，人数=___）
字数目标：1500—2500

## 节拍（按顺序，3—6条）
1.
2.
3.

## 修炼节点
- 有无：无 / 有
- 若有：醒__成 → 醒__成；门槛是____；代价是____；当场用出来做了什么____
- 若是醒成章，按五段写：决定 → 硬扛 → 成了 → 当场用出来 → 代价

## 信息变化
- 读者新知道：
- 赵升新知道：
- 其他人新知道：
- 不能让谁知道：

## 本章禁区
- 不能出现：
- 不能提前揭露：
- 不能写成的套路：

## 结尾钩子
类型：危险逼近 / 人物翻脸 / 力量暴涨 / 真相露头 / 留白
具体一句：
```

## 填写示例（106章·醒成章）

```
# 第106章　章名：四成
档位：H
地点：本命五行洞天 / 无归渡西侧小屋
在场人物：赵升一人（人数=1，洞天里有归客住户但不参与）
字数目标：2200

## 节拍
1. 他清点：三年攒下的遗物残料，能炼出多少仙炁
2. 算出不够，差一成。他决定把断笔上那点旧性也押进去
3. 洞天里点火，炼料，仙炁一丝一丝积
4. 半途洞天壁出现裂纹，他没有停
5. 醒成，他当场试了一次：单手把一根堵在西门内侧的断梁抬开
6. 代价：三日内不能再用仙炁，洞天从八里缩到五里

## 修炼节点
- 有。醒三成 → 醒四成（**开府**）
- 基准：ch105 洞天四里、零缕仙炁
- 门槛：三年攒的遗物残料 + 断笔旧性
- 代价：三日不能动用仙炁，洞天四里→八里→五里，五日内不能收人
- 当场用出：单手把一根堵在西门内侧的断梁抬开（此前需要赵九满带两个人）

## 信息变化
- 读者：洞天真的在长，而且长得有代价
- 赵升：明白了"自产"和"外供"是两回事
- 不知道的人：坊市、步纲君、苗七

## 本章禁区
- 不让任何人进洞天看他修炼
- 不解释断笔为什么能补仙炁
- 不写"他突破了"这类总结句

## 结尾钩子
类型：真相露头
具体：洞天壁那道裂纹里，露出一点不像他自己修的东西
```
