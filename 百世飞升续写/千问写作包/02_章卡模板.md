# 02 章卡模板

> ⚠️ **本文件带旧号：填写示例里的“106章”= 正本 116**（正本号 = 旧章号 + 10）。

> 一章一张，写之前先填好。填不满说明这章没想清楚，不要开写。
> 模板字段改动必须同步 `提示词/生成章卡.md`（两边一套字段）。

```

字数目标：1500—2500（**下限不低于 1200**）
场数：__（下限 2，场间用"——"分隔）

## 节拍（按顺序，3—6条）

3.

- 界域__ → __　路网__ → __　仙籍__ → __（无变化写"无"）
- 若上阶：按五段写——门槛 → 硬扛 → 上去了 → 当场用出来 → 代价
- 本阶可见物（本章能看见的 3 件物证）：__／__／__
  （如：牌子形制、路面材质、价目用哪种钱、纸的颜色、时刻表的制式）

## 本卷底线（`24_续写执行规划_116-150.md` 第 9 节）
- 大世界联动：无 ／ 有（第几发、谁传回来的消息）
- 修炼：无 ／ 有（节点 __；非升成场也算）
- 战斗：无 ／ 有（第几场；类型：打斗／天灾／硬扛）
- 三者若有其一连续 8 章为空，本批不许过
```

## 填写示例（旧号 106 → **正本 116**《四成》·醒成章）

```
# 第106章　章名：四成
档位：H
地点：本命五行洞天 / 无归渡西侧小屋
在场人物：赵升一人（人数=1，洞天里有归客住户但不参与）
字数目标：2200

## 节拍
1. 他清点：三年攒下的遗物残料，能炼出多少仙炁
2. 算出不够，差一成。他决定把断笔上那点旧性也押进去
3. 洞天里点火，炼料，仙炁一丝一丝积
4. 半途洞天壁出现裂纹，他没有停
5. 醒成，他当场试了一次：单手把一根堵在西门内侧的断梁抬开
6. 代价：三日内不能再用仙炁，洞天从八里缩到五里

## 修炼节点
- 有。醒三成 → 醒四成（**开府**）
- 基准：ch105 洞天四里、零缕仙炁
- 门槛：三年攒的遗物残料 + 断笔旧性
- 代价：三日不能动用仙炁，洞天四里→八里→五里，五日内不能收人
- 当场用出：单手把一根堵在西门内侧的断梁抬开（此前需要赵九满带两个人）

## 信息变化
- 读者：洞天真的在长，而且长得有代价
- 赵升：明白了"自产"和"外供"是两回事
- 不知道的人：坊市、步纲君、苗七

## 本章禁区
- 不让任何人进洞天看他修炼
- 不解释断笔为什么能补仙炁
- 不写"他突破了"这类总结句

## 结尾钩子
类型：真相露头
具体：洞天壁那道裂纹里，露出一点不像他自己修的东西
```
