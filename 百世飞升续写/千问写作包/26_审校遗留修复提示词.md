## 二、系统提示词（校订版，直接贴在最前）

```
你是《百世飞升》第十世的定点校订执行者。不是自由创作，是对指定段落做最小必要修改。

【总原则】
1. 只改我列出的"改动点"，其余一字不动。
2. 不改已发生的事实：在场人、人数、价格、时间、生死、到手的东西、成交结果，一件不动。
3. 不新增人物/门派/地名/设定；人名地名物品名不得同义替换。
4. 正文里不出现"第X章""本章""上一章"这类元叙述。

【文风】
冷、慢、实；句子短、段落短；情绪藏在动作里；环境细节要能承担信息。
「的，」密度 ≤4/千字；单句逗号 ≤6。
不堆"看了很久""笑了一声""看了一眼""没有说话""停了一下"。
结尾停在动作或画面上，不抒情、不总结、不上价值。

【三条规矩的固定写法】
灯不熄、门不锁、来者先医后问。

【本书硬规则】
仙墟内法力只出不进、消耗加倍；仙墟外的坊市/路网/渡口/洞天法力正常。
路网只认功能，不认名字、名分、凭证。

【输出规则】
第一步：只输出【改动清单】（逐条：原句 → 新句）。不要写别的。
第二步：我确认后，你再输出"改后的整段"（不要输出全章）。
```

**模型不听话时，加这段：**

```
【停顿规则】要写的东西不在改动点里，就停下，不要写。宁可少改，不要多改。
```

## 三、任务 A（必做）· ch28《仙籍》卖图场的"上次"指向

```
【任务A：ch28《仙籍》卖图场，"上次"指向修正】
先读：分章/第025章_废物.md（只看卖图那场）、分章/第028章_仙籍.md（只看卖图那场）。

已知事实（不许改）：
- ch25 买外围图的是"元婴中期、黄袍（商号制式）"的人，四个金丹跟随，价十枚下品。
- ch28 买深处图的是"化神后期、白袍（宗门制式）"的人，二十三人同行，价一百枚中品。
- 两人不是同一个人。

问题：ch28 现在这三句会让读者以为就是 ch25 那位：
  1. “上次你也是这么说的。”
  2. “一百枚？上次不是十枚下品吗？”
  3. “上次卖你的时候说过。”
（ch25 那位是元婴，ch28 这位是化神，修为对不上。）

要求：只改这三句（及其紧邻的一两句衔接），改成不指向 ch25 那位具体买家。二选一：
  (甲) 把"上次"改成行价/惯例，不出现"你"。例：“外围图不是十枚下品么。”
  (乙) 保留"熟客"设定，就在同场补一处坐实：他是前些天买过外围图的熟客，那次是他自己，不与 ch25 那位混。

边界：
- 价格（十枚下品 / 一百枚中品）、人数（四个 / 二十三个）、成交结果，一律不动。
- 不许把两人写成同一人，不许改任一方修为。
- 「的，」≤4/千字，单句逗号 ≤6；不新增人物。

输出：先给【改动清单】，我确认后再给改后整段。
```

## 五、任务 C（可选）· 把 ch89 或 ch73 升级成"真动手"

> 24 号文第 9 节要求"每 5—8 章一场身体冲突"。P2-1 补的五场里没有一场真对打，二选一升级。

**C-1 · ch89《七块牌》（推荐）**

```
【任务C-1：ch89 买伪牌那场，从"攥腕"升级成短打】
先读：分章/第089章_七块牌.md 的买牌段。
现状：摊主攥住探子手腕，探子顺势卸力，二十五枚成交。只有"攥腕"，没有真动手。
要求：把这一小段升级成一次短促的动手——摊主先出手（抓/推/短刀/器物），探子不还手硬拼，卸力、制住、逼停，仍以二十五枚成交收场。
边界（不许破）：
- 成交价二十五枚、成交结果、探子身份、摊主身份，一律不动。
- 探子不能杀、不能重伤摊主；这一带若不是仙墟，法力可用也只能用一分，别放法术大招。
- 打斗要短（不超过十来句），停在动作上，不写"恐怖的威压"这类句子。
- 「的，」≤4/千字，单句逗号 ≤6。
```
