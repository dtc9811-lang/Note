1. **只补世界线，不改已发生的事实**：谁死了、谁活着、什么到手了、什么定下来了，一件不动。
2. **世界阶每章必报**（界域／路网／仙籍三栏）；**上阶章写足五段**（门槛→硬扛→上去了→当场用出来→代价）。

## 1. 交接包（每次给 qwen 的固定输入，一次一章）

```
【系统】        ← 粘贴 01_系统提示词.md 全文
【术语表切片】   ← 06 里本章要用的条目 + 世界三层阶梯 + 新增名词登记表
【世界阶】       ← 本章：界域__／路网__／仙籍__（取自本文件第 4 节）
【接缝】        ← 上一章正文结尾 1 段 + 下一章正文开头 1 段
【本章任务单】   ← 从本文件第 4 节整段复制
【文风样本】     ← 05 的样本A（观察）+ 样本B（冲突）各一段
【本次任务】     ← 第一步：只输出分场表，不写正文。
```

## 5. 验收门槛（每章必过）

| 项 | 门槛 |
|---|---|
| 「的，」密度 | ≤ 4/千字 |
| 单句逗号 | ≤ 6 |
| 引号 | 全角 `“ ”`；无半角 `"` |
| 元叙述 | 无 `chNN`、"第X章" |
| 新增名词 | 已在 `06` 登记表 |
| 人数/物品/时间 | 与接缝一致 |
| 世界阶 | 三栏已填；换地图章 = H 档 |
| 章末 | 停在动作或画面，不抒情、不上价值 |
| 字数 | 1500—2500（纯补写场可短） |
