## 4. 模型使用规则（本次 qwen 审计的结论，直接照用）

1. **一次 ≤12—15 章**，每章带固定大小的交接包（`23` 号文第 1 节），上下文恒定，不要越写越带全书。
2. **强制项**：全角引号；章末不许出现模板句；不许给没登记的路人起名；不许用同义词替换术语。
3. **套话黑名单**（`文风体检.py` 已内置检测，写前把这段直接附给模型）：

   > 看了很久 / 笑了一声 / 你这个人，很有意思 / 灰得比昨天浅/深了一点 / 他能忍了 /
   > 灯还亮着。火苗很稳 / 停了一下 / 点了点头 / 没有说话 / 我不是炼气后期 /
   > "为什么？"连环追问（一节最多一次）

4. **写前先对正文**：任务单的章号/道具可能是旧的（`AGENTS` 五.5）。残图 ch75 才出现、古驿在 ch51 不是 ch50——一律按内容对位，先 grep 道具首现章。
5. **命名**：新地名/势力先登记 `06`；没登记的人一律不具名（"一个散修""渡口的帮手"）。
6. **每批结束**跑一次 `文风体检.py 全`，看跨章重复有没有回升。
