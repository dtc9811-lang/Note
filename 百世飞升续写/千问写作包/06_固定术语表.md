## 固定量词与单位

| 用法 | 说明 |
|---|---|
| 一缕仙炁 / 一丝 | 洞天自产仙炁的最小单位 |
| 一成 / 两成半 | 仙体醒度的单位 |
| 十五万里 | **旧**洞天尺度（在陨落处，未回收） |
| 四里 / 八里 / 五里 / 二里 | **本世**洞天尺度（统一基准：ch105 四里 → ch106 醒成八里 → ch106 代价五里 → ch133 受损二里） |
| 三里、七盏、十步、三息 | 数字要具体，不用"许多""无数" |

## 三条规矩的固定写法

> 灯不熄、门不锁、来者先医后问。

不得改成"灯常明""门常开""先治伤再问话"之类。
