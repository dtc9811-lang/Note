## 一、病因（数据）与设计目标

全本 144,201 字的实测：

| 本地气泡 | 次数 | 原著大世界 | 次数 | 修仙质感 | 次数 |
|---|---:|---|---:|---|---:|
| 路 | 1007 | 天柱界 | 1 | 修炼 | 2 |
| 渡 | 649 | 太乙灵界 / 太素灵界 | 0 / 0 | 闭关 | 1 |
| 账 | 478 | 先天神州 / 鸿荒 | 1 / 1 | 秘境 / 仙缘 / 拍卖 / 大会 | 0 |
| 渡口 / 路网 / 坊市 | 330 / 167 / 126 | 诸天 / 大道长河 | 2 / 2 | 宗门 / 天劫 / 仙尊 | 3 / 0 / 0 |

**病根三层**：① 方案只修修炼、没修世界；② 硬规则"仙墟内法力只出不进"把冲突锁死在固定据点；
③ 提示词铁律"不新增门派/地名""一章原则上不换地图"在机制上禁止世界扩张。

**目标**：给"世界"一个像"仙体醒X成"一样**可数、可见、每章要报数**的指标，并规定**每 20—30 章上一阶**。

## 二、世界三层阶梯（三条并行，互相咬合）

### 2.1 界域阶（主刻度：赵升活动在哪个世界层次）

| 阶 | 名称 | 生态（谁能在这层混） | 原著对应 |
|---|---|---|---|
| 0 | 下界诸天·劫户地 | 凡俗—炼气—筑基—金丹 | 天柱界 / 大椿界等下界 |
| **1** | **仙墟遗迹·坊市（当前所在）** | 墟客 / 遗民 / 监墟使 | 葬仙墟 / 垝垣墟 / 寂仙岛 |
| 2 | 坊市城（常驻修仙城） | 筑基—化神，商号、宗门分号 | — |
| 3 | 跨界路网枢纽 | 元婴—化神—返虚混居 | 路网 / 古渡 |
| 4 | 灵界外域（门户） | 返虚—合体，仙籍初现 | 太乙 / 太素灵界外缘 |
| 5 | 灵界内域（宗门 / 仙籍 / 大会） | 合体—渡劫大尊 | 太乙灵宫 / 太素锦澜灵域 |
| 6 | 仙天残域 | 大尊—真仙 | 无回天 / 鸿荒方向 |
| 7 | 虚界九天 / 仙天秩序圈 | 真仙—仙尊—道祖代理 | 虚界九天 |
| 8 | 大道长河 / 永恒天 | 道祖 | 终局只远观，不正面打 |

**上阶规则（与修炼节点同规格，写足五段）**：门槛 → 硬扛 → 上去了 → 当场用出来 → 代价。
**上阶章 = H 档**，每阶只上一次，不得连阶。

### 2.2 路网阶（赵升手里能调动的通路）

1 野路（西门外十步） → 2 单节点（无归渡被路网认） → 3 坊市级（路引/时刻表入册）
→ 4 跨渡网（"照无归渡例"十一座 → 更多） → 5 跨界路（葬仙墟→坊市城→灵界）
→ 6 古渡网（长照那类真仙古渡） → 7 诸天主干

### 2.3 仙籍阶（社会位格）

1 无籍劫户 → 2 临时引（墟客） → 3 正册渡正（步纲君体系） → 4 仙籍（化神以上）
→ 5 仙职/敕封 → 6 宗门上位/仙尊位 → 7 道祖秩序代理

### 2.4 与已有两条梯子的关系（不得混用）

| 梯子 | 管什么 | 现状 |
|---|---|---|
| 仙体醒X成 | 我能打多强 | 九成，已有 |
| 洞天五转 | 我的仙天多自足 | 五转，已有 |
| 界域阶 | 我在哪个世界 | 新增 |
| 路网阶 | 我掌握多少路 | 新增 |
| 仙籍阶 | 我是什么身份 | 新增 |

**每章章卡必须新增一栏**：`世界阶：界域_ / 路网_ / 仙籍_（有无变化、变化原因）`。
