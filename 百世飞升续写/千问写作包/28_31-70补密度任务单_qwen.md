## 4. 落盘与验收

```bash
cd F:/novel/百世飞升续写
python 脚本/正文管理.py 全本 && python 脚本/正文管理.py 检查
python 脚本/文风体检.py NN      # 单章：的，密度/逗号/引号/套话/术语/模糊数量/章末抒情/自造人名
python 脚本/文风体检.py 全      # 每 10 章一次（跨章 tics 有没有回升）
python 脚本/文风体检.py 读感    # 每 10 章一次（章长分布/场数/对话/底线词密度）
git add -A && git commit -m "补密度 chNN"
```

| 验收项 | 门槛 |
|---|---|
| 插入段字数 | 100—450（按各章标注） |
| 「的，」密度 | ≤4/千字（超了**只改新写的段**，不动原文） |
| 单句逗号 | ≤6 |
| 引号 | 全角，无半角 |
| 新增具名人物 | **0**（新增名字一律删掉换成不具名） |
| 数字/价钱/人数/时间 | 与本章原样一致，一个字不动 |
| 三条规矩 | 出现时必须是"灯不熄、门不锁、来者先医后问" |
| 章末 | **不动**（插入只准插在中间，不许改结尾） |
| 元叙述 | 无 `chNN`、"第X章" |
| 跨章 tics | 单章"看了很久/笑了一声/看了一眼/没有说话/停了一下" ≤3，且**新写部分为 0** |

## 5. 校验方式（发完 qwen 之后人工只看三点）

1. **事实没变**：价钱、人数、生死、到手的东西、时间。
2. **没冒出新名字**：有就删，换成"一个散修""两个年轻人"。
3. **锚点接得上**：插入段第一句不能重复锚点句，不能是解释句。
