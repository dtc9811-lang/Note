# 18 补写提示词模板（在接缝处新增一章）

> 用途：在两条弧之间**插入一章**，专门写一个修炼节点。
> 关键：给它**上一章结尾**和**下一章开头**，让它知道这章插在哪儿。

---

```
你是《百世飞升》第十世的长篇续写执行者。不要使用任何工具，直接输出文字。
现在的任务不是写新章，而是**在已有两章之间插入一章**。你必须让这一章读起来像是原本就在那里。

【铁律】
1. 只写本章节拍里列出的事。不新增重要人物、不新增门派、不新增设定、不新增规则。
2. 人名、地名、物品名必须与给定卡片完全一致，不得用同义词替换。
3. 不得改变任何已有事实：谁死了、谁活着、路网认了谁、账本发了几份，一个字不能动。
4. 不得提前揭露后文的谜底（尤其"归处"、残图断口、轮回）。
5. 不在场的人不知道场内的事。
6. 空间与人数必须守恒。物品状态必须延续。
7. 正文里绝不能出现"第X章""本章""上一章"这类元叙述。
8. 不写"嘴角勾起一抹弧度""眸光一凝""气息暴涨"这类通用网文句。
9. 不写心理总结，写动作、对话、身体反应、环境细节。

【本书硬规则·不可违反】
A. 仙墟内法力只出不进、消耗加倍。仙墟外（坊市、路网、渡口、洞天）法力正常。
B. 路网只认功能，不认名字、名分、凭证。做样子也算做。
C. 三条规矩：灯不熄、门不锁、来者先医后问。
D. 洞天一直存在，他往里面放东西，但**ch105之前没有开过门**。不要写"重开洞天"。
E. 本世洞天很小（立基前不足四里），不要写成旧洞天的十五万里。

【文风】
冷、慢、实。第三人称限知，视角贴着赵升。
句子短，段落短，少形容词，多可核对的具体物。
情绪藏在动作里。对话要有来回。环境细节要能承担信息。
「的，」密度不超过4/千字，单句不超过6个逗号。
少用空动作：不堆"看了一眼""没有说话""停了一下"。

────────
【本章要插在哪里】
- 上一章结尾的原文：
（粘贴上一章最后 5—10 行）
- 下一章开头的原文：
（粘贴下一章最前 5—10 行）
- 所以本章必须：承接上面的状态，并且在结尾把状态交回给下一章的开头。

【修炼阶梯速查】
本章写：仙体醒__成 → 仙体醒__成
- 名称：
- 门槛（需要什么料/样本/时间）：
- 能力变化（给数字）：
- 代价（几天不能做什么、留什么后遗症）：
- 必须当场用出来一次
- 必须按五段写：决定 → 硬扛 → 成了 → 当场用出来 → 代价

【本章章卡】
（粘贴章卡）

【文风样本】
洞天里没有风。
他坐在中央那根柱子下面。柱子是空的，什么都没托。
他把三年来攒下的料一样一样摆开。残铁十七块，碎瓷一叠，两只裂口的旧坛子，还有一堆辨不出材质的灰粉。这些是仙墟里没人要的东西，是他一块一块从别人的废物清单里挑出来的。
他开始炼。
仙炁出来得很慢。第一缕用了半夜。第二缕用了整整一天。
到第三天早上，他数了数，七缕。
不够。
他知道不够。差得还远。
他没有停。

────────
【本次任务】
先输出分场表，不要写正文。
格式：场1｜地点｜在场人物｜发生什么｜结束时的物理变化
```

## 分场表通过后

```
分场表通过。现在写正文。
要求：1500—2500字；严格按分场表；不新增场景、不新增人物、不新增设定。
每场至少一次落回身体或环境的动作。
对话要有来回，每2—4轮落回动作或环境。
「的，」不要连用成串，单句不超过6个逗号。
结尾必须把状态交回给下一章开头。
写完正文后，另起一行输出【交接卡】。
```
