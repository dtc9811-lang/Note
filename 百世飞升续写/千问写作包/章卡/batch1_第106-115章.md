# 第106章　章名：四成
档位：H
地点：本命五行洞天
在场人物：赵升一人（人数=1；洞天里有归客住户，不参与）
字数目标：2200

节拍：
1. 他清点三年攒下的遗物残料，算出能炼出多少仙炁
2. 算出不够，差一成。他决定把断笔上那点旧性也押进去
3. 洞天里点火炼料，仙炁一丝一丝积
4. 半途洞天壁出现裂纹，他没有停
5. 醒成，当场试一次：单手把一根堵在西门内侧的断梁抬开
6. 代价：三日内不能动用仙炁，洞天从八里缩到五里

修炼节点：
- 有。醒三成 → 醒四成（**开府**）
- 门槛：三年残料（残铁十七块、碎瓷一叠、两只裂口旧坛、一堆灰粉）＋断笔旧性
- 基准：ch105 洞天四里、零缕仙炁；本章醒成后洞天八里、七缕仙炁
- 代价：三日不能动仙炁，洞天缩到五里，五日不能收人
- 当场用出：单手把一根堵在西门内侧的断梁抬开（此前需赵九满带两个人）
- 五段：决定 → 硬扛 → 成了 → 当场用出来 → 代价

信息变化：
- 读者：洞天真的在长，而且长得有代价
- 赵升：明白"自产"和"外供"是两回事
- 不能让谁知道：坊市、步纲君、苗七、赵敕

本章禁区：
- 不让任何人进洞天看他修炼
- 不解释断笔为什么能补仙炁
- 不写"他突破了""修为精进"这类总结句
- 洞天不得立刻能自产大量仙炁

结尾钩子：
类型：真相露头
具体：洞天壁那道裂纹里，露出一点不像他自己修的东西

# 第111章　章名：各有各的算法　（**正本 121**）
档位：M
地点：苗七的渡口，账房
在场人物：赵升、苗七（人数=2）
字数目标：1600

> ⚠️ **本卡按 24 号文 §5 校正过**：正本 ch113《那就不是账了》里，赵升**已经**给出立场——"各自用各自算的，各自负各自的责"。
> 所以这一章**不许再"决定要不要统一"**，要写**那套判词失灵**：各自负责 = 出了事找不到负责的人。

节拍：
1. 两本账摊开对。对不上的地方很多，但不是抄错——是各有各的算法
2. 苗七把"重伤"和"轻伤"的界线往后挪了半寸。赵升问为什么挪。苗七说：我这边药不够
3. 赵升想起自己在图正面前说过的那句话：各自算各自的，各自负责
4. 当场就撞上：抄错的那一步，按这句话去追，谁也追不到——抄的人用的是他自己的算法
5. 苗七反过来问他：那就是没有人管
6. 赵升没有答。他把两本账并排放着，一页一页翻到最后

修炼节点：
- 无

信息变化：
- 读者：公开账的失败模式不是抄袭，是**没有责任人**（正应步纲君在 ch113 说的"你这套没有人担责任"）
- 赵升：他那一套判词，只在自己手里成立
- 不能让苗七知道：他还没想好怎么补这个洞

本章禁区：
- 不写辩论谁对谁错
- 不让赵升讲道理说服苗七
- **不许重演 ch104/113 的"账公开就不再是他的"**——那句已经说过了

结尾钩子：
类型：真相露头
具体：苗七问：那就是没有人管。赵升没有答

# 第112章　章名：抄给谁　（**正本 122**；原标题"不统一"）
档位：S
地点：苗七的渡口，前厅
在场人物：赵升、苗七、赵素（赵素不在场，只在信中）（人数=2）
字数目标：1500

> ⚠️ **本卡按 24 号文 §5 校正过**："要不要统一"在 ch113 已定过，本章不重演。
> 本章补的是上一步漏的那个洞：**把"哪一步出错、死了几个人"原样抄出去**，让每一本账自己带着后果。

节拍：
1. 他不规定算法，只把这一次死人的全过程写进新一版账里：哪一版、哪一步错、死几个人
2. 他强调：不写谁对谁错，只写不同算法会带来什么后果
3. 苗七在旁边看着，没有帮。他问了一句：这个也抄出去，我这边那半寸也一起抄吗
4. 赵升说：抄。你挪了半寸，也写在你的那一页上
5. 新一版写完，他抄了两份，一份留给苗七
6. 新账发出去，第一批要的人里，有步纲君的人

修炼节点：
- 无

信息变化：
- 读者：赵升处理分歧的方式——公开后果，不统一标准
- 赵升：有人在盯着他的账
- 不能让谁知道：新一版账是他亲手写的

本章禁区：
- 不写成制度设计讲座
- 不让赵升说出"联盟""生态"这类抽象词

结尾钩子：
类型：危险逼近
具体：新一版账发出去，第一批要的人里有步纲君的人
