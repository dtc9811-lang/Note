# 03 交接卡模板（与现有 `交接卡.md` 兼容）

> 每章正文写完后**立刻**产出，作为下一章唯一的记忆来源。
> 控制在 300 字内，不准写"大概""似乎""可能"。

---

## 单章交接卡格式

```
【第X章交接卡】
1. 已发生的事实：
   -
   -
2. 各人所知：
   - 赵升知道：
   - 在场其他人知道：
   - 不知道的人：
3. 当前错误答案：
   - 众人以为：
4. 未兑现的细节：
   - 物件：
   - 伤势：
   - 承诺：
   - 伏笔：
5. 本章结束时的可见状态：
   - 地点：
   - 在场人数与姓名：
   - 每人手中关键物品：
   - 刚发生的物理变化：
6. 下一章禁区：
   -
```

---

## 示例

```
【第73章交接卡】
1. 已发生的事实：
   - 西边三十里那座位渡口的主人是苗七，ch49被卫老修士推回路心的赤铢伙计
   - 他把三条规矩一字不差抄在门板上，挂牌"照无归渡例"
   - 赵升在牌前站了二三十息，没有踏进门
2. 各人所知：
   - 赵升知道：苗七是谁；那牌子是抄的
   - 赵九满知道：苗七抄了规矩，但不知道苗七是谁救的
   - 不知道的人：坊市、步纲君
3. 当前错误答案：
   - 赵九满以为：对方是来抢生意的，迟早要打
4. 未兑现的细节：
   - 物件：那扇取下来靠在门框边的门、那块新木牌
   - 伤势：无
   - 承诺：无
   - 伏笔：苗七问"我抄错了吗"
5. 本章结束时的可见状态：
   - 地点：无归渡堤上
   - 在场：赵升、赵九满、赵素、赵长庚（靠着廊柱睡着）
   - 手中：赵九满铁钎；赵素账册抱在胸前
   - 刚发生：归客仍停东侧门槛外三尺，脸朝东，未动
6. 下一章禁区：
   - 不要让苗七立刻变反派
   - 不要解释"照无归渡例"背后的动机
```

## 长程交接卡（每 10 章更新一次，追加到 `交接卡.md`）

沿用现有 `交接卡.md` 的结构，新增一节：

```
## X. 修炼进度（每10章更新）
- 当前仙体醒度：X成
- 已完成的修炼节点：第X章（事件）、第Y章（事件）
- 洞天状态：几里、能否自产仙炁、能收几个人
- 下一次醒成需要什么：料/样本/时间
- 尚未兑现的修炼伏笔：
```
