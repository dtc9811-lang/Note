# 04 写章提示词模板（实际粘贴用）

> 把 { } 替换掉，整段发给模型。
> 只带**本章章卡 + 上一章交接卡 + 文风样本 + 相关术语/人物/设定切片**，不带全书。

---

```
{粘贴 02 章卡}

────────

{粘贴 05_文风样本.md 里的 1—2 段}

格式：

场2｜……

我会确认或修改分场表，然后你再写正文。
```

---

## 第二步（分场表确认后）

```
分场表通过。现在写正文。

要求：
- 1500—2500字
- 严格按分场表，不新增场景、不新增人物、不新增设定
- 每场至少一次落回身体或环境的动作
- 对话要有来回，每2—4轮落回动作或环境
- 「的，」不要连用成串，单句不要超过6个逗号
- 少用"看了一眼""没有说话""停了一下"
- 结尾停在钩子或画面上，不总结、不抒情、不上价值
- 写完正文后，另起一行输出【交接卡】，按给定格式

如果发现分场表里有写不通的地方，先告诉我，不要自行改设定。
```

---

## 第三步·自检（可选）

```
对照 07_禁区与自检清单.md 检查你刚才写的正文，逐条列出，只列问题不要重写：
1. 有没有出现禁止词句？引用原句。
2. 人数、物品、地点有没有和交接卡冲突？
3. 有没有人说了他不该知道的事？
4. 每个节拍是否都写到了？
5. 「的，」密度是多少？单句最长多少个逗号？
```

## 常见漂移的补救提示词

| 漂移 | 补救 |
|---|---|
| 套话 | "把第X段里'嘴角勾起一抹弧度'改成具体动作，不要表情套话。只重写这一段。" |
| 信息泄露 | "第X段里A不该知道B。删掉那句，改成他问别人。" |
| 抒情结尾 | "删掉最后两段抒情，只留一个具体动作或画面作为结尾。" |
| 长逗号串句 | "把第X段拆成短句，单句不超过6个逗号。只重写这一段。" |
| 字数不足 | "把第X场展开：加一段对话来回，加一次身体反应。不推进剧情，只加密度。" |
| 修炼写成白拿 | "把醒成那一段扩成五段：决定、硬扛、成了、当场用出来、代价。写疼在哪、撑了多久。" |
| 加了新设定 | "删掉新出现的门派/功法/地名，不要用替代词，直接删。" |
