## 二、金手指：百世书

1. **一世结算**：每一世死后打分，评价从低到高大致有 丙、乙（下/上）、甲（下/上）……最高是"史诗"。
2. **继承**：根据评价，从这一世的**体质 / 天赋 / 技能**里挑一部分带到下一世。
3. **人生成就**：完成特定成就（如"先天宗师""多子多福""飞升灵界""开辟洞天"）换随机奖励，可以抽体质、天赋、技能，也可以给已有天赋升级。
4. **品级**：天赋和技能分凡级、黄级、玄级、地级……后期还有"洪级""荒级"。推测用的是千字文"天地玄黄，宇宙洪荒"那一套，具体高低顺序**（待核实）**。
5. **数据面板**：显示年龄/寿元、天赋、体质、技能。
6. **功能会成长**：比如第八世结算后，技能《宇空仙天投影轨仪》升成了洪级的《无限宇空之门》；百世书还能"记录"别人的突破（第 948 章用生死断笔在书上写下老祖宗证道）。
7. **带到下一世的法宝**：禿毛"生死断笔"（准道器），第八世结算时转到了第九世。
8. **没解开的谜**：百世书是从哪来的、到底想干什么，全书都没交代。

| 仙之上 | 金仙？ → 道祖 | 无上道祖 | 道祖在"永恒天"，把自己的仙魂烙在某条"大道长河"上；每条大道只容一位道祖 |

### 3.2 另外几套分类（设定补充）

- **大道九步**（第 512 章）：凡俗三关 → 元神三劫（金丹/元婴/化神）→ 长生三步（返虚/合体/渡劫）。
  - 赵升另外把"悟道"分成九层：初学乍练、初窥门径、登堂入室、略有小成、融会贯通、炉火纯青、登峰造极、返璞归真、亘古唯一。
- **虚界九天**：和大道九步对应的九层虚空。已知有第一天"幽暗天"、第二天"神宫天"（返虚期才能进）、第七天"遗忘天"（时间流速不正常）；其余六天没查到。成仙的一个标志是肉身能在虚界第一天里自由来去。
- **仙有五类**（第 934 章）：
  - 上位：天仙（与道合真、功德圆满，可以带着自己的洞天飞升，最正统也最难）、地仙（性命双修，要舍弃洞天，也叫散仙）
  - 下位：人仙（靠功德成仙，功德不够就卡境界）、神仙（要天庭敕封，实力被仙职限制）、鬼仙（邪魔外道，进不了仙班）
- **本源仙炁**（第 953 章）：没有属性，能转成任何大道之力，密度极高。在鸿荒大陆一缕一缕吸收炼化，可以**绕开飞升池、慢慢把肉身和法力炼成仙体**——这是赵升最后成仙走的路。
- **大道长河**（第 961–962 章）：成仙后能看到 11 条大道长河。**五行、雷、命运**等大道已经有道祖了，赵升选了"轮回"。
- **法则相关**：万物频律、大道真文（掌握越多，悟得越深）、法则丝弦、意志与法力融合、元阳灵宝 / 通天灵宝 / 准道器 / 道器 / 伪仙器。

### 3.4 家族与主要势力

- **赵氏**：全书主线就是"修仙家族"一代代经营。天柱界的南天赵氏 → 发展成天柱界第一世家、神都 → 族人往诸天散开：兴龙赵氏、十地赵氏、越空山赵氏、三圣赵氏、"神工赵氏"等分支。
- 正道宗门：丹鼎派、地藏宗、裂天剑道、太上感应宗（屡次坑赵升）、太乙灵宫、太清宗、九问仙宗
- 魔道 / 外敌：血魔宗、姹阴宗、万尸宗、地焰宫、元始魔宗（九蚩魔主）、幽神界血神、异魔（自称"仙族"）、自在天魔主

## 五、最后一世（第九世）修炼历程

### 5.1 开局（808）
- 这一世叫**赵二狗**。十岁测出灵根，被卖进**太乙灵界"三绝赵氏"**当仆役（家族中等规模：一位元婴老祖、明面上三个金丹、三十几个筑基），住在下六院最阴暗的角落。
- 资质：**五灵根**（很杂，但他身上叠了九世的底子）。
- 心态：上一世死在太张扬，这一世定下**苟住、稳扎稳打**：先在院里立威，三个月内突破炼气，稳稳修几十年到元婴，再去卧龙山脉。

### 5.2 分阶段历程

**① 金丹、元婴期（809–833）｜在三绝赵氏和海外起家**
- 809–811：结盟，进倒悬山，当上岛主
- **812：结成金丹**
- 813–817：以炼器大师身份出名；主家来人找茬（打了小的来老的）；牵出"十地赵氏"；有异魔的影子；本命法宝炼成
- 818–**819：去樾雾山、外域拓荒二十年，结成元婴**
- 820–826：天裂谷猎妖；碰到仙墟遗民，拿到真仙指骨；宝镜镇妖、收服帮手
- 827–833：在摩天崖布万里飞渡阵、盗宝；九玄城成了"大宗师"；寂仙岛上替人炼宝、挑人下界

**② 化神期（834–848）｜认祖归宗**
- 834–836：去下界避风头，准备百年后渡劫；镜界扩张、搜刮一界
- 837–843：九玄城斗宝大会，祈天老祖；寂仙岛来了个新"仙人"；青凰钟，裂谷里遇到老熟人
- 844–**847：飞升台出现 → 回到祖地亮出玉璧 → 祖荫钟一响，整个神州都惊动了 → 当众报出"姓赵名升，字冲和"**，以赵氏始祖转世的身份被家族认下
- 848：经历"历史洗礼"，天劫加身（推测化神劫或返虚劫（待核实））

**③ 返虚→合体期（849–884）｜大圣线、神州之谜**
- 849–853：被怀疑是"大能转世"，三位祖宗不知情；接下大圣的遗愿，初次见到**天运子**
- **854：讲清"万物频律"和"飞升三劫"**
- 855–861：交易仙人骨；下咒，混进太清宗，当外任观主传法，回神州
- 862–867：化蛟；参悟《混元一炁洞真经》，"一炁生阴阳"，练成混元一炁大擒拿
- **868：确认这里就是"先天神州"**
- 869–876：借九冥塔找到秘境；六欲摩天之战；师父**风风子**再次出现；再进遗忘天；得知**"寰宇诸天最大的秘密"**；大圣传法，寻访大圣岭
- 877–884：袁皇遇难，得仙法帛书；灵宝真形劫；元阳灵宝；罡煞星辰令，族老聚在先祖殿；圣猿出世；**开天辟地，洞天成，元阳劫来**

**④ 决战（885–903）｜清算万形仙君**
- 885–891：血字发威；万形突然杀到，暗算落空，赵升躲进寂仙岛；听说"秽仙箭"，各方陆续入场
- **892–898：全书"最强一战"**；驻世三仙现身；**万形仙君、罡煞星主一起陨落**；混沌之谜
- 899–903：原来"混沌"是个"狱卒"；得到天河帝君印和半部仙经；法旨下来，全族轰动；石灵认主；天运子破境称尊

**⑤ 游历诸界、准备渡劫（904–930）**
- 904–913：冥狱收人，随机飞升到神音谷；洗髓后降到离辰界 → 红海界，海神、负岳龙龟一族，龙龟产蛋、海神苏醒，立道誓做交易
- 914–923：出现"另一个赵升"（分身回归），参悟真文；见老祖宗，去沧海界；辟火仙诀，凿穿寂仙岛；凝练雷劫晶；布种诸天完成；**弟子/族人赵三月渡劫失败**；人榜出世
- 924–930：袁洪出世，天运子回归；洞天当阵法用，孕育海神；上了升仙榜，受仙尊庇护；改造洞天，本尊收徒；举星

**⑥ 渡劫大尊（931–950）**
- **931–932：九重雷劫渡过，证道大尊，尊号"混元"**（寓意统领五行阴阳）；太岳仙尊派人道贺，三十多位大尊隔空祝贺；之后入定悟法两千五百多年
- 933：二祖**赵宏运**功德圆满要飞升；老祖宗**赵玄靖**得看住失控的"混沌"，飞升不了；讲明飞升三劫＝天火、赑风、心魔
- 934：仙有五类；**自在天魔主**有九具分身（灰袍扫地老僧是其中之一），几乎杀不死
- 935–940：赵升和自在天魔主**以净光界为棋盘赌一局**：各自投一枚"棋子"（赵升这边是**张旭圣**，天魔主那边是**韩林**），千年内看谁的棋子先飞升、成为时代主角。赵升有三具分身：儒生"儒二"、赵穹天（修辟火仙诀）、洞真子（在外面跑）。想尔崖的玉璧让他看到九种互相矛盾的"未来"
- **941：花三个月渡过天火劫**；洞真子拿星主之位换到《大光明根本咒》全本
- 942–943：二祖白日飞升，门楼被天外一剑斩进来（斩仙剑、人种袋、莽古钟三件通天灵宝伏击，是邪魔想抢功德；飞升者靠光阴刀躲过——被伏击的是二祖还是天运子，两段摘要说法不一（待核实））；**命妖**（灰白雾气）再次出现
- 944–947："不要飞升仙天"的警告；参悟二祖留下的《断舍离法》（断妄念、舍执着、离无明）；渡赑风劫时魔念滋生，用断笔封魔，混沌开始躁动
- 948–950：**赵玄靖把混沌融进自身、证道**（有摘要说是金仙（待核实））；神州下坠死伤无数；自在天魔主的三十三具化身被毁；赵升用大光明佛火一关关过心魔劫

**⑦ 鸿荒大陆成仙（951–962）｜全书结局**
- 951：把道法传给两个徒弟后，赵升**没走常规飞升**，花三十年横穿星空去"无回天"的**鸿荒大陆**；带着签了"天地同寿"契约的玉麒麟**石灵**
- 952–954：发现"本源仙炁"，找到不靠飞升池的成仙路；当上通天柱守阵者，还用武力逼别的守阵者交出仙炁
- 955–959：进入第二层大陆，十万倍重力；那里有六七十位大尊各占地盘；中间的飞升古陵由三位散仙守着——卜仙**齐如仙**（道号神机子）、石蜗、剑痴；和卜仙交手，他能未卜先知，最后还是输给了道器
- 960–961：成仙在望，仙躯炼成过半，大道长河若隐若现
- **962 结局**：闭关百年，发现鸿荒大陆其实正被一个神秘"奇点"慢慢吞噬、煅烧，所以才源源不断冒出仙炁。先天五行道体炼成长生仙体，七十年后元神蜕变成不朽仙魂 → 面前有 11 条大道长河，他绕开已经有道祖的五行、雷、命运，**选了轮回大道** → 刚把仙魂烙上去，就惊动了永恒天的几位无上道祖：**他们不允许出现第二位轮回道祖**，硬把烙印崩掉 → **赵升掉进时光长河。全书完。**

## 六、烂尾点 / 没收的伏笔（续写的切入口）

1. **书名"百世"，只写到第九世**；原大纲的"轮回道祖"没写到。
2. **结局太仓促**：成仙→选大道→被道祖崩解→掉进时光长河，几段就结束了，是生是死、之后怎样全没交代。
3. **百世书的来历**：它能让人在血脉里轮回，本身就是"轮回"之力；而道祖们"不允许**第二位**轮回道祖"，说明**已经有一位轮回道祖**——百世书很可能和他有关（这是我的推测，原著没点破）。
4. **"寰宇诸天最大的秘密"**（874）、**混沌是"狱卒"**（899）——看守的是谁？
5. **鸿荒大陆的"奇点"**，为什么在吞噬、煅烧整片大陆？
6. **命妖**的真面目。
7. **想尔崖看到的九种未来**、"不要飞升仙天"的警告，都没回收。
8. **净光界赌局**（张旭圣 vs 韩林）没结果。
9. 赵氏家族、老祖宗、天运子、石灵等人的结局。
10. 读者吐槽（书友圈）：中后期节奏拖、主线模糊、为了凑字数牺牲人设、主角手段太狠、辈分混乱（老祖转世成孙辈）。

## 七、续写方向草案（等你拍板）

- **A. 直接接结局**：赵升掉进时光长河 → 被冲到过去 / 某条时间支流，百世书借机重启"第十世"，百世轮回继续，最终目标是和现任轮回道祖正面交锋。
