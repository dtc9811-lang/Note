# 第十世宏观规划规范

> 用途：供 `baishi-feisheng-planning` 在“整阶段 / 整卷”模式下使用。先决定故事往哪里走，再进入批次与单章施工。
> 本文件不替代 `写作资料/02_设定总表.md`、`03_长期总纲.md`、`05_第九世与第十世对比.md`，只定义宏观规划的方法和验收门槛。

---

## 一、两层规划模式

### A. 宏观规划模式

适用：新阶段、新卷、大地图切换、现有路线出现“越写越小/越写越像同一种题”的情况。

输出顺序固定：

1. 阶段目标
2. 3—5件大事
3. 八维规划表
4. 因果链
5. 收获与代价
6. 人物进入/退出
7. 阶段尾钩
8. 风险检查

**宏观规划未通过前，禁止拆单章。**

### B. 施工规划模式

适用：宏观方案已拍板后，拆5章批次、章节施工单、事实包和自由区。

继续沿用现有规则：事实优先、人物承载、对手梯度、20%—30%写手自由区、DevTrace回写与Gate验收。

---

# 二、宏观规划的八个必做维度

每个20—30章阶段都必须同时规划以下八个维度。不是每章都要全部出现，但阶段结束时必须形成完整变化。

## 1. 人物

至少回答：

- 本阶段赵升身边有哪些旧人物进入、哪些退出？
- 新地图至少有哪些本地人物、利益方、同行者/向导、竞争者？
- 每名重点配角自己的目标是什么？不考虑赵升时，他为什么也要行动？
- 谁会作出一次违背赵升预期的选择？
- 谁在阶段结束后留下、分路、死亡、闭关或转为远端节点？
- 回归旧角色带来的必须是“独立完成的结果”，不能只是递消息。

宏观层不先写大量姓名，允许先用功能位；首次入正文前再登记正式姓名。

## 2. 修行

每个阶段必须明确：

- 开场时赵升真实战力/仙体/洞天/仙炁状态；
- 阶段中遇到的瓶颈是什么；
- 突破靠什么：知识、资源、战斗、环境、旧物、功法、洞天结构？
- 阶段尾具体多了什么“可见能力”，不能只有“理解更深”；
- 这是恢复第九世旧能力，还是第十世新能力？二者必须区分。

原则：

**恢复旧号只能支撑前期；中后期必须逐步产生第十世独有的新体系。**

## 3. 法宝 / 资源 / 资产

法宝不是收藏清单，每件重要资产都必须承担至少两种功能：

- 战力/能力；
- 修炼资源；
- 历史证据；
- 地图钥匙；
- 势力利益核心；
- 下一阶段的入口。

旧世遗产回收必须同时给出：

1. 实质能力或资源；
2. 三万年历史证据；
3. 一个新的路线或冲突。

禁止“找回法宝，战力+1”式无后果回收。

## 4. 探险 / 副本

至少设计一个真正的未知探索过程：

**未知 → 调查 → 危险/阻碍 → 试错/判断 → 发现 → 实质收获或损失。**

探险可以是：遗迹、仙墟、古路、残界、宗门禁地、废弃洞天、奇异世界规则。

“到了地方听人解释设定”不算探险。
“直接捡到物品”不算寻宝。

规则型副本可以有，但一个20章阶段最多一个作为核心特色，避免连续“发现规则—验证规则—制度解法”。

## 5. 重大事件

每个20—30章阶段先确定3—5件“大事”，再拆卷拆章。

大事必须是：删掉以后主线会断、世界状态会变、人物关系会变、主角会得到/失去重要东西的事件。

例：

- 找回一件旧世核心遗产；
- 第一次回到三万年后的赵氏；
- 一位真正同层人物先赢赵升一次；
- 某个旧世节点已经变成别人的根基，赵升无法直接拿回；
- 洞天完成一次结构性转变；
- 确认某条历史认知长期被篡改；
- 打开一个此前无法进入的世界层级。

不得把“讨论一次制度”“核对一本账”“明白一个抽象概念”单独当作大事。

## 6. 大世界发展

每阶段必须回答：

- 赵升为什么非去这张地图不可？
- 新地图和上一张地图相比，至少哪两项真正变化：
  - 常见修为；
  - 物理/法则规则；
  - 社会形态；
  - 资源；
  - 势力层级；
  - 敌人层级；
  - 世界真相；
  - 旅行/生存方式。
- 本阶段离开以后，为什么不能继续原地解决下一问题？

原则：

**换地名不算换地图，换规则题也不等于世界变大。**

## 7. 因果链

宏观规划最核心的一栏。

必须形成：

> 上一阶段的收获 / 失败
> → 产生本阶段必须解决的问题
> → 本阶段为解决问题进入特定地图
> → 经历3—5件大事
> → 得到硬收获 / 承担硬代价
> → 收获本身强制打开下一阶段

如果“为什么来这里”和“为什么下一站必须去那里”说不清，宏观规划不通过。

## 8. 奖励密度与节奏

阶段结束时读者至少能明确指出其中4项：

- 赵升变强了什么；
- 得到了什么法宝/资源；
- 去过什么真正不同的新地方；
- 知道了什么重要真相；
- 结识/失去了谁；
- 打赢/输掉了什么；
- 建立/失去什么资产；
- 打开了什么更高层入口。

不能连续10章只有“认知加深”。

# 三、参考第九世的规划方法，不照抄剧情

优先参考 `写作资料/05_第九世与第十世对比.md`。

第九世应学习的是结构，不是复刻事件：

- 重新起家：资源、炼器、外域、斗宝；
- 认祖谋仙经：家族、宗门、道统；
- 大圣传道开洞天：知识突破转为境界突破；
- 万形杀局：仙级敌手和大战；
- 布种诸天：经营升级为跨界战略资产；
- 飞升杀局：问题从“怎么变强”升级成“世界本身有问题”；
- 鸿荒成仙：彻底换物理环境与力量层级。

抽象成一句话：

**地方生存 → 更高道统 → 知识突破 → 世界级能力 → 高层大战 → 跨界经营 → 世界真相 → 生命层级跃迁。**

第十世可以走完全不同的剧情，但阶段之间必须有类似的“层级抬升感”。

# 四、宏观规划输出模板

每次规划一个阶段，固定输出下面内容：

## 1. 阶段一句话目标

赵升必须得到/解决什么；为什么现在必须做。

## 2. 开场状态

- 人物
- 修行
- 法宝/资源
- 所在世界
- 未解问题

## 3. 3—5件大事

每件大事写：

- 发生什么；
- 为什么不可删；
- 推动哪几个维度；
- 主角得到/失去什么；
- 如何改变下一件大事。

## 4. 八维规划表

| 维度 | 开场 | 中段变化 | 阶段尾结果 |
|---|---|---|---|
| 人物 |  |  |  |
| 修行 |  |  |  |
| 法宝/资产 |  |  |  |
| 探险 |  |  |  |
| 重大事件 |  |  |  |
| 大世界 |  |  |  |
| 因果链 |  |  |  |
| 奖励密度 |  |  |  |

## 5. 阶段硬收获

至少1项实体/能力/结构性收获，不得只有情报。

## 6. 阶段硬代价

至少1项不可逆损失、责任、承诺、错失、关系变化或敌人获利。

## 7. 阶段尾钩

必须解释：

**为什么下一阶段非发生不可。**

## 8. 暂不拆章清单

明确哪些内容当前只定方向，不锁姓名、数字、具体战斗招式、逐章节拍。

# 五、宏观规划Gate

出现以下任一情况，禁止进入施工规划：

1. 说不清赵升为什么非去当前地图不可；
2. 3—5件大事里大部分只是规则讨论/谈判/手续；
3. 没有实体或能力硬收获；
4. 修行只有“仙体醒X成”而没有结构变化或新能力；
5. 法宝线只是伏笔，没有参与事件因果；
6. 探险没有完整过程；
7. 新地图只是换地名；
8. 人物全围着赵升转，没有自己的选择和退出；
9. 阶段尾无法自然强制打开下一阶段；
10. 删除整个阶段后，主线仍几乎不受影响。

通过Gate后，才允许把3—5件大事拆成分卷和5章批次。

# 六、与现有三Skill的职责边界

## 规划 Skill

负责：

- 宏观阶段规划；
- 卷级结构；
- 人物进入/退出；
- 修行节点；
- 法宝/资产路线；
- 探险与重大事件；
- 大世界发展；
- 通过宏观Gate后再做批次契约和章节施工单。

## 写手 Skill

不改职责：只执行已批准施工单，不重规划主线。

## 验收 Skill

正文验收职责不改。

若验收对象是“宏观规划”，额外检查本文件的宏观Gate，不用正文文风指标代替规划验收。
