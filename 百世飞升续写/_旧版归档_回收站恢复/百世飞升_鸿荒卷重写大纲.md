# 《百世飞升》鸿荒卷·重写大纲（草案 v1）

> 接在原著第 950 章之后（二祖已经飞升、老祖宗融合了混沌、赵升过完心魔劫，是渡劫大尊，尊号"混元"），替换原著第 951–962 章。
> 目标：给第九世一个**完整、有分量**的成仙结局，把原著没收的伏笔串起来收掉。
> 以下剧情是原创设计，不沿用原著的具体情节和文字。

## 核心设计：把散落的伏笔串成一条线

| 原著没收的伏笔 | 重写版的解释（原创） |
|---|---|
| 鸿荒大陆的"奇点" | 上古**第一位轮回道祖**陨落后留下的"道果残核"，被永恒天的道祖们钉在无回天，慢慢煅烧提炼——本源仙炁其实是轮回大道被**拆解成的原料** |
| 混沌是"狱卒" | 混沌是道祖们放在神州的看守，看守的正是轮回道果流落在诸天的碎片 |
| 百世书 | 道果残核崩出去的一页"轮回真文"。它选中赵升，是因为赵氏血脉"不绝"的特性，正好能养活它 |
| 命妖 | 道祖们的"清道夫"，专门猎杀带着轮回气息的东西；第八世、第九世两次出现，都是冲着百世书来的 |
| 想尔崖的九种未来 | 对应赵升九世里的九个分叉，其中只有一种能让他活着成仙 |
| "不要飞升仙天"的警告 | 走常规飞升会被仙天登记、打上标记，带着百世书去等于自投罗网——这也是赵升改走鸿荒大陆的真正原因 |
| 三散仙（卜仙、石蜗、剑痴） | 当年轮回道祖座下看守残核的旧部，被道祖们留在这里当"守陵人" |
| 净光界赌局 | 在第三幕作为插曲收尾，赌局结果决定自在天魔主会不会在最后关头出手 |

## 结局走向（和原著最大的不同）
原著：赵升选轮回大道 → 被道祖崩掉 → 掉进时光长河，完。
重写：赵升看破"第二位轮回道祖不被允许"是个死局，**不去抢那条旧长河**。他以九世血脉在诸天布下的族人为锚点，用百世书里九世的积累，**开出第十二条大道长河——"薪火"（血脉传承之道）**。这条道本来就不属于任何道祖，道祖们一时没法下手。他成了真仙，保住了赵氏，也给"百世"留了一个开放的尾巴。

## 分章大纲（暂定 15 章，每章约 3000–4000 字）

### 第一幕：入鸿荒（1–5）
1. **无回天**：赵升辞别老祖宗、安顿好两个徒弟，带石灵出发；三十年星空跋涉，在无回天边缘见到一片"光都会弯折"的死寂大陆
2. **万钧之地**：第一层大陆，重力、寿元流速的压迫；赵升肉身硬扛，石灵差点被压碎，他舍掉一件法宝替它护体
3. **一缕仙炁**：发现本源仙炁，第一次炼化——肉身某处的质变；百世书的页角第一次自己发烫
4. **守阵者**：通天柱下的守阵者小社会，各怀鬼胎；赵升不靠武力硬抢，而是用炼器、阵法手段换来守阵资格
5. **书页在响**：炼化到第二十几缕时，百世书在他识海里自己翻开一页空白页，浮现出一个他看不懂的轮回真文字形

### 第二幕：守陵人（6–10）
6. **第二层**：十万倍重力，六七十位大尊划地而居；赵升被当成新来的肥羊，被三位大尊联手试探
7. **剑痴**：剑痴拦路，一场以剑问道；剑痴认出赵升身上的轮回气息，不杀反放，只留一句含糊的警告
8. **石蜗的洞府**：石蜗和石灵之间有某种同源感应；赵升从洞府壁画里拼出第一位轮回道祖的陨落经过
9. **卜仙**：齐如仙早就算到他会来；他摊开九种未来，逼赵升在"交出百世书、平安成仙"和"留着书、九死一生"之间选
10. **命妖第三次降临**：命妖追进鸿荒；三散仙立场分裂，大战爆发；赵升第一次主动用百世书对敌，代价是第九世积累的一项天赋被烧掉

### 第三幕：薪火（11–15）
11. **奇点**：赵升被打进大陆核心，亲眼看到奇点——那是一颗还在跳动的"道果"，他明白了仙炁的真相
12. **棋局终了**：净光界千年赌局的结果传来（张旭圣和韩林的结局），自在天魔主据此决定站队，在关键时刻切断命妖的退路
13. **仙躯与仙魂**：在奇点旁完成最后炼化；看到大道长河时，他发现第十一条"轮回"长河早已干涸，河床上钉着道祖们的法旨
14. **第十二条河**：永恒天诸道祖的威压降下；赵升点燃诸天赵氏血脉作为薪火，百世书九页齐亮，开出"薪火长河"；道祖们一击落空，只好暂时退走
15. **归去**：成仙后回到神州祖地，见老祖宗、二祖的传讯、天运子，给石灵和族人一个交代；最后一幕，百世书翻到第十页——空白，但页角有了温度
