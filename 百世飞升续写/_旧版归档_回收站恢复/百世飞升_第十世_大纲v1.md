# 《百世飞升》第十世·大纲 v1

> 前提：第九世末，赵升开出第十二条长河「不绝」之后，被五行、雷、命运等道祖**联手镇压而死**。百世书在最后一瞬脱身，开始第十世结算。
> 写法约束（按你资料第六编、第九编）：局部连续优先、可脑补的连续镜头、少用"……"硬切、少写抽象判断、每卷至少两段"轮回小镇级"高光、每个大阶段必须有新的修炼加速器。

## 一、第九世的结算与遗产（伏笔清单）

| 东西 | 镇压之后的下落 | 用途 |
|---|---|---|
| 百世书 | 最后一瞬脱离仙魂，自行结算，仍在 | 绝对现役 |
| 生死断笔 | 被道祖连同赵升的仙魂一起钉在轮回干河的河床上 | 第十世要去取回，等于正面对上道祖 |
| 五方五行洞天镜 | 五面镜被打散，各自坠进五个不同的世界 | 第十世卷二起，一面一面找回 |
| 五行洞天 | 崩成一颗"洞天种子" | 石灵吞下保管，第十世重新养大 |
| 掌灯人的灯 | 灯芯将尽，由石灵挑着 | 第十世的"引魂/点名"工具，有燃料上限 |
| 不绝长河 | 道祖读不走，但没人看守，处于半干状态 | 第十世的根本资源与最终战场 |
| 石灵（阿灯） | 天地同寿之契本该同死，因为"赵升的名字没有死干净"而活下来 | 长期同伴，燃料问题的钥匙 |
| 鸿荒大陆 | 泵断了，道祖封了无回天，整片大陆被弃 | 第十世的开局牢笼 |
| 瓮城、千人村、净光界名碑、诸天记名者 | 名字在账上，因此没被抹掉 | 分布式"家族"，替代赵氏血脉 |

**结算奖励**：评价史诗之上，新增成就「开辟大道长河」。权限为 **一宙、两洪、一荒、二玄**。宙级权限暂不使用（留作后期），洪级用于"指定"与"赐福"，具体见卷一。

**最关键的机制变化**：道祖已经在诸天清洗、藏匿"赵"姓血脉，百世书检索血脉失败，于是第一次改用**记名**转生——名字记在账上的人，也算他的"血脉"。这是「不绝」对百世书的反哺。

## 二、第十世的开局

- 转生地：鸿荒大陆第二层，石蜗壳内的千人村。
- 身份：千人村第 **1001** 个人。村子几万年来一直是一千个人，多出来的这一个，没有自己的灯。
- 资质：结算时只用了少量权限做体质，开局很弱（与第九世的碾压开局刻意相反），换来后面自由度。
- 记忆：完整九世记忆 + 神识天生。
- 手上只有：一颗洞天种子、一头灯快灭的麒麟、一本查不到血脉的百世书。

## 三、第十世的修炼加速器阶梯（每一阶段必须写出来）

1. **千人村的老魂（学徒跳级）**：村里两百多世的老人 = 活的百艺图书馆。他用记账法把村民的前世手艺编成可传授的东西，换来第一批产能。
2. **灯与点名（低配百世书）**：灯能点亮名字。点亮一个名字，那个人就记得自己是谁、记得会什么。代价：灯烧的是"被记住的量"。
3. **洞天种子（平台复活）**：种子从一间屋子大养到一里、十里，先当作坊，再当实验室，最后才当洞天。
4. **出鸿荒（接回诸天市场）**：打通一条出口，重新接上仙墟客/恒墟坊，把封闭世界重新变成有外贸的世界。
5. **五方镜残片（器道平台重建）**：一面一面找回，每一面都在一个不同规则的世界里。
6. **分身并行**：镜界养分身，多线程经营。
7. **"被记住"作为本源资源**：真仙之后最稀缺的不是寿命，是存在感和不可被遗忘性。不绝长河把它变成了可计量、可积累、可交易的东西。
8. **取回断笔 / 动用宙级权限**：终局层面的手段，留到最后。

## 四、卷一「一千零一」（第1004–1013章，约3万字）

1004 序章·钉：道祖联手镇压；法宝散落；百世书脱身；结算面板出现，检索血脉失败，改检索记名
1005 一千零一：赵升作为第1001个人出生在千人村；村里没有他的灯；当夜，另一户的灯开始变暗
1006 灯油：他查灯，发现灯烧的不是火油，是"被记住的量"；千人村一千个人，供不起一千零一盏
1007 试灯：拿自己做实验——让村里人忘掉他三天，看灯的反应（高光段一）
1008 记账法：他把村里两百多世的手艺编成账，开第一间作坊；老魂们跳级
1009 种子：洞天种子在灶膛里第一次发芽，长成一间屋子大的空间
1010 壳裂：石蜗的壳开始塌，村子必须搬；剑痴还在古陵边上睡着
1011 瓮城旧人：阿蛮、阿陶、屠山尚在；他以一个小孩的身份，重新和老部下建立关系（不认出他，才是难点）
1012 无回天之封：他们发现出不去；灰雾没有回来，但天上多了一层看不见的盖子
1013 卷末：他在壳顶点亮了第1001盏灯，用的是瓮城三千人的记名——第一次证明"网"可以当灯油（高光段二）
