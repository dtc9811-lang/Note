## 二、第十世前提

第九世末，赵升开出第十二条大道长河「不绝」，随后遭五行、雷、命运等道祖联手镇压而死。

百世书在最后一刻脱离。

诸天赵氏血脉遭清洗、隐藏，百世书无法正常检索血脉，于是首次出现“记名转生”现象。

赵升第十世转生于鸿荒大陆第二层、石蜗壳内千人村，成为这个几万年来始终只有一千人的村子里的：

**第1001个人。**

【重要】
“记名转生”属于第十世新出现的机制，目前边界尚未完全查明。

不得自行扩大成：

**只要知道名字 / 写下名字 / 被赵升见过，就自动成为转生节点。**

必须通过后续剧情逐步验证其条件、代价与限制。

## 七、灯：目前已经确认的事实

【已实验确认】

1. 普通燃油不能增强灯火。
2. 更换普通灯芯不能增强灯火。
3. 某个人被多人持续主动想起、念名时，该人的灯会明显增强。
4. 停止后，灯火会重新衰减。
5. 第1001盏灯出现后，部分原有灯火发生衰减。

因此赵升当前建立的第一版模型是：

> **灯的燃料与“被记住”有关。**

## 八、灯：当前模型，但尚未完全证明

赵升目前推测：

* 人能够维持的清晰记忆有限；
* 千人村内部存在某种总量约束；
* 第1001个人出现后，新增消耗会从较少被想起的人那里转移；
* 外部人口的“记名”可能给千人村补充燃料。

【注意】

阿满说自己大约能清晰记住三百余人，只代表阿满个人经验，**不是已经证明的宇宙常数**。

“千人村只能支持正好一千份灯油”也只是赵升当前模型。

第1007章及以后应继续验证：

* 活人记忆和文字记录是否等价？
* 单纯反复念名字与真正记得一个人是否等价？
* 记忆深浅是否影响灯油质量？
* 假名字是否有效？
* 距离是否影响？
* 死人留下的记录是否有效？
* 一个人被遗忘后究竟失去什么？
* 灯是在利用记忆，还是把某种更高层“存在锚”表现为记忆？

不要过早把答案全部解释完。

## 九、第十世修炼加速器阶梯

当前原则：

每进入一个新阶段，先回答：

1. 正常修炼为什么太慢？
2. 上一阶段的加速器为什么开始不够用？
3. 新加速器究竟节省了哪种时间？
4. 门槛、成本、副作用是什么？

规划阶梯：

1. 千人村老魂：百艺学习与经验跳级。
2. 灯与点名：身份/技能唤醒体系。
3. 洞天种子：作坊 → 实验室 → 小世界生产平台。
4. 打通鸿荒出口：重新接入仙墟客、恒墟坊等诸天资源市场。
5. 五方镜：重建炼器、法则、洞天平台。
6. 分身并行：将研究、经营、探索并行化。
7. “被记住/存在锚”：上升为高层本源资源。
8. 取回断笔 / 宙级权限：终局层手段。

【原则】

新的加速器不是替换旧的。

成熟的旧机制应成为基础设施，层层叠加，最终形成赵升自己的修炼体系。

## 十二、文风与场景硬规则

1. 当前场景连续性优先于远距离伏笔。

关键动作要让读者知道：
人物在哪里、做了什么、碰到什么、产生什么结果。

普通走路、转身、拿东西无需逐动作流水账。

2. 少用抽象判断。

少写：
“无比诡异”
“极度恐怖”
“气氛凝重”

尽量让物体、人物和环境发生具体变化，由读者自己判断。

3. 同一连续场景少用“……”切碎。

真正的时间跳跃、地点切换、刻意留白可以使用。

4. 每卷至少保证一个真正值得记住的高光场景。

规则探索卷可以出现第二个，但不要机械凑数量。

高光不限定为悬疑：
可以是规则破解、突破、战斗、奇观、人物关系、死亡、离别或重大认知变化。

5. 规则型高光可参考原著轮回小镇的优势，但不要复制公式：

现象出现
→ 主角建立假设
→ 亲手验证
→ 假设部分正确
→ 一个不起眼的细节与模型冲突
→ 修改模型
→ 真正规则显露
→ 获得的不只是宝物，还有认知。

6. 赵升处理未知事物的默认逻辑：

**活下来 → 观察 → 记录 → 假设 → 实验 → 验证 → 利用 → 转化为长期资产。**

## 十三、设定优先级

出现冲突时：

**原著明确硬设定**

>

**已经写入续写正文的事实**

>

**最新版状态卡**

>

**当前卷大纲**

**未来卷预案**

大纲是计划，不是已经发生的历史。

如果正文自然发展与大纲细节冲突，可以调整大纲实现方式，但不得偷偷改掉已经写进正文的事实。

第十世、“不绝”、第1001人、灯油体系等属于：

**续写已经建立的新设定。**

不要误认为它们是原著正文已经存在的设定。

## 十四、状态卡维护原则

本卡不是第二份总资料库。

每卷结束时：

* 删除已经解决且以后无影响的问题；
* 把复杂规则压缩成已验证的一句话；
* 更新人物、法宝和资源位置；
* 记录最近一章最后的现场状态；
* 保留5—10条下一卷真正会用到的悬线；
* 新增“禁提前揭晓”内容。

目标：

**一个完全空白的新会话只读本卡、当前卷大纲和上一章，就可以准确接着写。**
