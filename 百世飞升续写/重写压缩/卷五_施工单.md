### 乙：新 37—38

#### 新 37　点灯（旧 114）【H 档，节点章：三成·立基】
- **开场状态**：见第三节。
- **事件**：那天夜里赵升没睡，从东侧门出去，绕外围走到西门外那十步（口径 CX 类方位）：路基外侧、堤基石头旁贴着的那些轮廓（卷三新 25 已出）——有人形，有不像的，都不动；轻的很轻，像不压地；重的很重。最近那一个的衣角，就是新 25 年轻族人认出的那个本家远亲（口径 CM）→ 回渡口：赵素账室没睡，赵茂在廊下守灯，赵九满在后院半醒 → 赵升站在前厅中间，手按胸前："那里是洞天。"（新 30 他自己进去过一回；这一年多往里放了不少东西，**一直没让谁进去过，灯也没点过**）——"**今晚，他要开门。**" → 走出西门到那十步，低声："**进来。**" → 轮廓先后离地浮起，第一个就是那个远亲，一个接一个进西门、进前厅，脸朝东，站在印记上，再往前一步——进了洞天 （以上是**决定**）→ 他从前厅中间往里迈一步（口径 CA）；格局新 30 写过，这里一句带过；门额下一排空灯座，他倒油，沿门额下一路点过去，七盏第一次亮 → 先闻：洞天里一点本源仙炁都没有。他想明白一件事——**一座仙天要活着，靠的是自己生仙炁**；他和金仙之间，隔的就是这一格 → 温残片进洞天就凉了，像一块普通的碎铜，他把它放在灯座底下、靠最中央那根柱子——找对了地方：不是这一根柱子，是**这一类**柱子。第九世那间铺子，就是五根这样的柱子撑起来的 → 数铺子里的东西：五方五行洞天镜、旧洞天十五万里、雷帝辟劫令、五雷钺……留在陨落处，锁着，"**柜台后面没有人**"，谁拿走的，他不知道，"总有一天要去拿回来" → **硬扛**（立基）：把法力"给"进洞天，身体空了一块，像被人从胸口挖走一勺；回来一丝——少了九成九，是**被洞天养过的法力**（口径 CB），"像吞一块没化完的冰，凉，硬，卡在喉咙里" → **成了**：仙体里堵着的地方松了，能装的东西大了一圈——**仙体醒三成**；"它长一寸，他厚一分" → **当场用出来**：他让温残片在洞天中间悬起来，一息——洞天有了"托"的能力 → **代价**：喂一次，歇三天；洞天自己产不出仙炁 → 他取出生死断笔，往洞天空着的门额上落一笔（上一回落笔在账室，口径 CW）：石头上留下一个很淡的印子，"**不是字。是他这一世的名，笔画不全，像被水泡过一半。**""有地方落名了。" → 灯亮那一刻，西门外最后几个轮廓也走了进来；他开了洞天的东侧门，整扇 → 路网认了洞天：脚底的震比平常厚一层 → 他顺着震往下"看"：路网从洞天底下穿过去，有一路往上走，**比脚下这些粗，粗得多**——无归渡在细的那一头，这里所有的渡口、所有的石板路，都在细的那一头 → 门额下、灯座上方，他再落一笔："**很淡的一道印子。不是字。笔尖朝上。**" → 出洞天，赵素出来等他说话；赵九满："好了？""好了。" → 赵素记："洞天立基，路网认，今日。" → 赵升要过账册，写一行："**往西。第一座渡口。对账。**"——四百三十七份账在三十七个地方抄着，抄错的、改过的、自己造出来的，都有 → "哪一天走，提前告诉你。"
- **必留**："进来。"；"一座仙天要活着，靠的是自己生仙炁。"；"柜台后面没有人。"；"仙体醒了三成。""它长一寸，他厚一分。"（各一次）；门额淡名那句；"笔尖朝上。"；"好了？""好了。"；两行账。

- **删**：旧 114"这件事不会变……往后也是"旁白；铺子清单"还有别的，账上记着"压成两句；"第七世"出处拿不准就不写。

- **事件**：灰白悬在新印上，离铺盖三步："慢慢起来。铺盖不要了。人先离印远些。"赵九满退五步，又退两步 → "它喝完了呢。""**喝完了，找留印的。**拿上能拿的，往东。走柱础那条线。" → 赵素把剩下小半锅水舀进竹筒，火折子进匣；赵九满卷铺盖卷不利索，索性整个扛上肩；"撂下。"他勒紧绳，什么都没说 → 贴着路肩往东退，专踩没印的地方；灰白喝尽新印，转身朝赵九满这边来，和人走路一个速度，隔着十几步吊在后头；赵素绊了一下，灰白近了半拍 → "它认人？""**它认印。印是你留的。**" → 头一座柱础：赵升跳上去按一点法力——石面留不住印，像水倒在刷了油的纸上 → "**上来。石面留不住印。踩柱础，踩顶面。**" → 灰白追到柱础前停住，像被拦在一道看不见的槛外头；不到十息，偏去喝旧印 → 赵素数："**八息。每一回都是八息上下。**" → 赵升说给两人听（不许写成心里盘点）："法力用了小半，这里一文回不来。池底三缕没动。它喝一个停八息。**打不死它，也杀不了它。只能喂。**喂到它趴着不动，咱们沿柱础线撤。"赵九满："你这不是打，你这是给它摆席。""就是摆席。八息一个空当，够咱们挪一段。" → 第一口席：柱础下路面按一点法力灌下去，印比试的时候大、深；数到六挪一座，数到八它抬头，又伏两息 → 第二口在第四座下 → 第三口时他额头见汗，法力出得急，一口接一口往地里去（口径 CR）→ **第二只**从密集区旧印里升起来，撇下旧印，朝新印和人来 → 赵九满一钎扫过去，钎头穿过去像从灰里穿过去，它散一散又合上；赵九满撑着柱础石棱，右手腕蹭开一道口子，血流到钎杆上，钎没撒手 → "**它碰不着咱们，咱们也碰不着它。别恋战。浇。**" → 连浇两口，第二只被勾住；赵升右小臂的白斑起了皮，汗一浸火辣辣的 → 第六座到第七座之间出事：赵素跨缝时浮土塌了，人往外栽，木匣布带断了，匣子砸在柱础侧棱上弹开，账本甩出来摊在地上，纸角压着一个旧印；第二只在两丈外伏着 → 赵九满用没伤的那只手捞人，钎撒了手；赵升跳下去抢账本，同时放出**第一缕仙炁**：托在掌上，不散，不沉进石头，不留印 → 第二只毫无知觉——"**仙炁不是它认得的字。它读不到。**" → 仙炁漫过去贴上它，它猛一缩，窜出两丈乱转 → 三人上第七座；仙炁淡了散了，池底少了一缕 → 第七座顶面西边的角缺了一块，赵升一按掉石渣（为新 43 埋笔）→ 两只都朝柱础线来（一只认赵九满的印，一只认路面的新印）→ 柱础线到头了，半个月亮 → 赵素："八息。可咱们没有下一段柱础了。" → 赵升按着第七座顶面，只说一句："法力见底了。还有两缕。"→ "最后一段，我来喂。你们两个先下去，贴着柱础根往北绕，绕进密集区边上等我。""你拿什么喂？你还有多少法力？"他不答 → **第二缕**仙炁贴着柱础顶面漫开，成一层看不见的膜，第二只一头撞进去，从没见过的僵 → 赵九满趁它僵住一钎捅过去，把它钉着推出一丈，推趴在旧印上 → 三人下到柱础根，两只都缓过来绕过来；密集区在北边两丈 → **决定**（口径 CR 补）：池底只剩最后一缕。他知道这一口咽下去，池底就空了，住户那头绑着的东西要晃；他咽了 → **硬扛**：最后一缕托住快干的法力，"**像快干的灯芯滴了一滴油**"；他把剩下的法力七八口叠着浇进北边旧印堆的空当，浇出一片密密的新印 → **成了**：浇到第四口，身体里有个地方响了——"**不是疼。开府那回是疼，是烫；这一回是让。像新夯的墙头一回吃上力，往里沉了半分，沉实了。**"四成新撑开的那片（口径 CR），在这一沉里定了型——**仙体醒四成半** → **当场用出来**：神识随着那一沉扎进地里，闭着眼知道两只在哪儿（左前方四丈一只，柱础根一只）；地里每一个印子的位置都顶在神识上，密疏新旧分得清清楚楚，"**像瞎子耳朵里的动静**" → 他听不见赵素数的数（左耳断，口径 CT），看她的手：三根手指一根一根收——他数到三，浇出最后一片，两只都扑下去喝 → "走。"三人从两只中间穿过去，进了密集区 → 绕回来，宿在第五座柱础顶面（口径 DA）→ **代价**：他往洞天里看——池底那层润没了，石头露着，"要三天，才渗得回来"；池底震了一下，前厅住户绑着的那点东西松了一瞬，又收住；法力见底，这里回不来 → 赵九满右腕用赵素的旧衣角包上，握钎握不紧，用左手捧着炒面分；炒面就凉水，一人半碗 → 赵素清点：木匣摔掉一道角，砚台裂了缝；账本被豁开一道口子，从书脊吃到纸边；柱础线那页缺了右边一条——七个点和间距在，第八点算得回来，**第九点连纸条一起没了**，风卷进旧印堆里，没人去追。
- **必留**："喝完了，找留印的。"；"它认人？""它认印。印是你留的。"；"上来。石面留不住印……"；"八息。每一回都是八息上下。"；"打不死它，也杀不了它。只能喂。"；"你这不是打……""就是摆席。"；"它碰不着咱们……浇。"；"仙炁不是它认得的字。它读不到。"（只讲一次）；"像快干的灯芯滴了一滴油。"；"不是疼……沉实了。"；"仙体醒四成半"；"像瞎子耳朵里的动静。"；"八息。可咱们没有下一段柱础了。"
- **篇幅**：H 档，可到 3,500 字。"八息"压到四五次。
- **删**："墟里加倍地抽"；第二缕时再解释一遍"读不到"；逐口席的位置流水账压一半；"它看不出前后，可它就是转了个身"（新 41 已用）。
- **口径**：CC、CO、CR、CT、DA。
- **章末**：**铁钎立在柱础边上，钎杆上一道血干了，发黑。残账压在赵素膝头，缺了边的那一页朝上，豁口一直吃到纸边。**

#### 新 43　一直有人守着（旧 125）【卷五收尾】
- **事件**：天没亮，竹筒见了底 → 分工：赵升、赵九满下坡背水，赵素留守，算第八点："**间距都在。位置算得出来。石头在不在，不知道。**" → 贴着密集区边走时赵升神识沉地两息：一只还趴在叠印那一片，一只挪到密集区边上伏着慢慢喝；他们绕开一大圈，自家的旧印一个不踩 → 出牌坊，坡底有一条溪；赵九满用左手舀了半锅，赵升灌满两只竹筒；野营地醒了一半，坡顶有人朝这边站了一阵——"他们在估咱们。""让他们估。" → 上坡，赵九满腕子渗血，赵升撕旧布冲洗、重缠 → 晌午熬稀糊糊，炒面剩不到半袋，捏三把；赵素："第八个点，在第七座正东九丈二。""下午去看看。" → 午后往东：第七座柱础——昨天西边角缺的那一块、缝上豁的那道口（新 42 已埋），**今天补上了**：新料颜色浅一层，工法对路，跟旧缝一个手法，边口还潮，指腹带黏 → "**昨天还没有这个。**"赵九满按了按，按不动："**手艺不错。**" → 第八个点：浮土**翻过**，半张车大，潮土翻上来又大致平回去，边上虚；几个浅脚印，脚跟一般深，**脚尖冲东**；赵素量了，"脚跟到脚跟，一步半"，记在缺了一条的那一页 → 赵素问："墟里那东西，干的这个？"赵九满："**那东西喝印。这是伺候。**" → 往东一道浅沟：很直，宽一尺上下，两边的土细而匀，沟底没有草筋，像有人拿一把扫帚把地扫开了一条线；赵素沿着走了十几丈，不弯，不断："**一样的宽。一笔扫出来的。**"钎杆探沟底，深浅一个样 → 赵升蹲在沟边朝东，凉碎片沉角仍冲东："**一直有人守着。**" → 没人接话；回程三人都走在沟西，谁也没跨进沟里；天黑前回到第五座 → 第二天清早赵素先看见：第五座顶面、靠赵升睡的那一侧，硬物刻了一行字：**数石头的人，到第七座为止。**石粉还新，起笔坑深，收笔尾短（口径 CS，不报字数）→ 赵九满四下看，没人；守夜没听见声音；"什么时候划的。"没人答得上 → 赵素连字形一起抄下；木匣的绑绳另一头拴在她腰上 → 牌坊那边上来四个人，排成一队：两个拿铁錾，一个肩上盘着绳，一个扛空扁担；踩着旧印过来，没事——**不用法力的人，路上留不下印**（口径 CO）；领头的穿皮坎肩，拱手 → "前几天，在这条线上数石头的，是你们。""数过。""数出几座？下一座在哪儿？""不知道。" → "营里都传遍了。你们又量又画，量了一整天。**石头谁刨出来归谁，这是坊这边的老规矩。**你们把下一座指给我们，分三成。""真不知道。数了，画了，就这些。" → 皮坎肩的目光落在赵素腰上的木匣 → 扛扁担的去勾匣绳，赵九满左手一钎磕飞扁担；拿錾子的往前送，赵升侧身让过錾尖，左手扣住他手腕往下一沉，錾子落地，当啷 → 皮坎肩看看錾子，看看北边密集区："那边前夜的动静，营里都听见了。拿上东西，走。" → 扛扁担的顺手拽走炒面袋，赵九满扑半步抢回小半袋，袋子撕开，炒面泼了一地白 → 坡下："**行，你们嘴严。石头想要的人，营里有的是。**" → 赵素拢起炒面，只剩袋底，分三份：一份今晚熬，两份收进匣子 → 赵九满查竹筒："水没动。**他们不敢抢水。**" → 赵升神识沉地：两只都还伏着 → 他再念一遍那行字；赵素："**他们是冲石头来的。这行字，也是冲石头写的。**"——一行刻在石头上，一行说在人嘴里，两行都落在同一样东西上 → 赵素把刻字那页和缺了一条的那页并排看，匣绳又紧了一道 → 天擦黑，赵升给赵九满换布条：没肿，边收着；赵九满再试钎，握住了，攥不久 → 夜里靠着柱础坐，锅底还有余温；北边没有动静；东边那道沟看不见，但三个人都知道它还在。
- **必留**："间距都在。位置算得出来。石头在不在，不知道。"；"他们在估咱们。""让他们估。"；"昨天还没有这个。""手艺不错。"；"那东西喝印。这是伺候。"（赵九满说）；"一样的宽。一笔扫出来的。"；"一直有人守着。"；刻字原文；"不用法力的人，路上留不下印。"；"石头谁刨出来归谁……"；"行，你们嘴严。石头想要的人，营里有的是。"；"他们不敢抢水。"；"他们是冲石头来的。这行字，也是冲石头写的。"

## 三、开场状态（交界处用）

**乙开写新 37 前**：新 36 末——步纲君最后一趟走了，留下"你这不是盟，是一本谁都能捡的破账"；名分方案没接，正册上无归渡仍是"步纲君渡口旗下，歇脚棚，无归"。谢青跟着走一段（匠人七个、丹药一条线、坊市东头铺子一半）。账本直接发出四百三十七份，三十七个地方在抄。赵升仙体醒**两成半**（新 34），胸口的酸早退了。温残片、凉碎片都在他身上。前厅石板上是第二次归潮归客站出来的椭圆印记。西门外十步，路基外侧、堤基石头旁，还贴着新 25 那批上不来、也没死透的轮廓，其中一个是本家远亲。劫户点名印在赵升手里。赵长庚拄弯杖；赵茂右手老了六十年、黑到小臂、裹布。
