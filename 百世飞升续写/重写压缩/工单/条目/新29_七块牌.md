#### 新 29　七块牌（旧 87、88、89）
- **事件**：路网上照着门板抄的，这半个多月又起了四五家 → 赵升想了几天："这件事现在的做法走不通，得换一种。" → 坊市外借来一间空屋（商号存货处，坐得下十几个人）：苗七、支线末端主人、另外新开的几家各一人、赵敕、两个走货商户、赵素；窦让派一个人来，坐角上不说话 → **第一件：规矩五条**（口径 AP）→ 支线末端主人问容不下怎么办："按来的顺序……**能收多少是能力问题，不能关是规矩问题，两件事。**""尽力而为和什么都不做，不是一件事。" → **第二件：牌**：编号、日期、无归渡担保，背面压劫户点名印，名单公开；一个商户问走路的人能不能拿着牌走："牌属于渡口，发给渡口，证的是那座渡口，不是证持牌人。"那人眼睛里有东西在转 → **第三件：验渡口**：定期派人看账、灯、门，不合格收牌、公告栏贴出 → 支线末端主人："那你们的渡口，谁来验。""一样的标准，随时可以来查。""不服核查结果，能去哪里说。""**现在没有。这是第一版，有问题可以说，说了我们改，改了再来。**""那先看着。" → 下午核查，赵素矮桌上对账、灯、门、帮手、归潮记录，对到一半她说："先医后问，桌上查不出来。"赵升："先这样。" → 七座全过，过一家赵茂刻一块；发到第三块，是苗七，他翻过来看背面的印，系在腰上 → 牌发出去第三天，东南新开那家（第六号）被走货商队的管事找去谈，两天后把牌卖了，商队拿着牌在路上当通行凭证 → "**第八块牌出现的时候，赵素的账上只有七块。**"探子在坊市西侧杂货摊上花二十五枚下品仙晶买回一块（"摊主动了刀，我没还手"）→ 赵素对比一刻钟，外观分不出，连背面那方印都仿了，只有名单能辨："见过真牌的人刻的。"赵升："**以后还会有。**""嗯，而且越来越难认。" → 半个月后伪牌九块（口径 AP）；探子报两家：冒第四号那家（西南岔路口）最整齐，热水真烫，账是皮面，里面只住一个腿伤者撑门面；另一家灯最亮、门扇取下、帮手练过，里面**一个没有** → 赵素："**服务比我们好，账比我们齐，灯比我们亮。因为这些东西让牌值钱，而收人让牌贬值。**" → 走货商队的管事（四十上下）带两个跟班来：队里一人腿伤送进挂"无归渡担保"牌的渡口，处置不对发炎，耽误近一个月；赵素查编号，不在名单；赵升："担保的是我们核查过的那七座。"管事："我们走货的，不是每到一个坊市都去看公告栏。我们走路，看见牌上的字，信了，仅此而已。"
- **必留**："能收多少是能力问题，不能关是规矩问题，两件事。"；"现在没有。这是第一版……"；"以后还会有。"；赵素"服务比我们好……收人让牌贬值"；管事最后那句。
- **删**：旧 87 牌出发前就刻好七块；旧 88 坊市五问五答（留"没有渡口不发""负的是核查失准的责任"两句）；旧 88 探子在杂货摊格斗（改成他回来一句转述）；旧 88 赵素"价值已脱离本体"备注。
- **口径**：AH、AP、AX。
- **章末**：管事问："**那这块牌，最后，它担的是什么责任。**"没有人回答，他走了。
