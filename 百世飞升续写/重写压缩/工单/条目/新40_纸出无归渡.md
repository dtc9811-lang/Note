#### 新 40　纸出无归渡（旧 120、121）
- **事件**：清早棚主熬了三碗糊糊；两个脚夫天不亮就走了，把话带走了——赵升在院里听见路过的人说："无归渡的人来理西线一路的纸了。" → 头一个来人：四十来岁，裤脚扎麻绳，背着纸筒；先把墙上新纸默念一遍，再摊开他抄来的账页，多一栏，底下小字"一人两文"："我在路边设了个卡子，开春起照这张纸收钱。原先灶上成天坐着一壶热水，谁要都白给。这个月起，人绕着我走，宁可多挑十里。给我赊货的上家，入秋就不给赊了。卡子上那眼灶，三天没生火了。"——"**给我换一张。换了，人是不是就回来了？**" → 晌午前第二个：五十上下，邻道宿棚当家的，不收钱，只宿店供水；死过人的话传成"贴这纸的地方要死人"，他棚里的客少了一半："我这纸是真是假……真了，你们给句准话。" → 比纸：黄纸帘纹同，裁口同，字同一路，错处同；设卡子那张纸边多"一人两文"；赵素："**帘纹同一路，裁口同一把刀。一个铺子里出来的都说不定。**"两条抄链往回捋，都散了头 → 两人吵起来（"多的就是错的""你那张才缺了东西""错纸是谁收走的"）→ 两张脸转向赵升："**纸是你们家发的。真假你们认得出来。**" → 赵升左手把揭下来的错纸展开，铺在两张中间（右手三指麻）："**谁抄谁，我也分不出来。**各自的纸，各自在背面写一行。你是谁，纸贴在哪儿，哪一天贴的。" → 棚主先在墙上新纸的下角写了自己的名字；邻道棚主写名字、棚址、日子；设卡子的没写名字，写了四个字"**纸出无归渡**"，折好收进怀里："往后谁问这张纸，打无归渡来的。"赵九满手搭上铁钎："你——""我没赖谁。纸打那儿出来，人打那儿来换，满路都知道。我说的是来路。" → 邻道棚主在自己名字底下也添了"纸出无归渡"，把纸压在案板中间："名字是我的；纸是我贴的，我认我这一份。纸的来路，也写在这儿了。" → 棚主问赵升要不要也添一行来路："那是你的纸。" → 下半天到天黑来了三拨讨水的，有人拿炭把背面那四个字描走了 → 第二天晌午前，东边来了一个汉子，裤脚带泥，背着褡裢，先数车上的货、看骡："是这辆车。"——领队的，手里半张货单："**货是初九出的铺子，该十二到。没到。我顺着往回找，找了三天。**" → 两半货单拼上，茬口对，两个姓对："**他替我跑货，这条路跑了四趟。他说跑完这趟就猫冬。**""人呢？"他到石堆前拣了两块石头添上，眼睛是干的 → 验货，八捆，货印对；车在这儿停了好些天（口径 CV）；在棚主账上"出货"那一行按了十字 → 喝水时看见案板上那张纸，念出"纸出无归渡"；问棚主当夜："**你没办错。你照纸办的。**"问新纸是谁换的——"那就是知道旧纸错在哪儿。知道错，换了纸，没说别的。" → "**错的是纸。人夜里到了门口，纸让他先问。问了一夜，人没了。这条命，记在谁头上？**"一路上都在说，换纸的就是你们 → 摆账：抚恤三十贯；"一句话的事。你说一声你是无归渡的，说这纸是你家发出来的，这三十贯就记到你家账上，路上的纸往后有个主，全齐了。不是我为难你。名分定了，往后纸再出事，人知道找谁去。这是好事。" → 赵升左耳断了几息（口径 CT），赵素转述："他说，一句话，账就齐了。" → "要是不说呢。""**不说，我只能记在纸上。纸不给钱。**你们现在走，路宽，没人拦。" → 赵九满解下钱袋，赵素拣铜子："**一贯又六十三文。**"赵升左手推过去："**这些是全部。不够三十贯。**" → 赵素抄事由：时辰、隔门问了什么、声音什么时候低下去、谁先见的人、抬到哪儿、石头几层、脚夫一人四文、今天谁凭存根认的货——一行是一行，没有一个评字："**他怎么没的，埋在哪儿，谁埋的。你捎给他家里。**" → 汉子："钱是谁的，账是谁抄的，我跟他家怎么说？三十贯我先垫。你们这个，我一并捎到。是谁的，我说不上来。"数钱，一文不落 → 院门口："**钱你们给，账你们抄，就是一个字不给。我记着你们。记着好不好，我说不上来。**" → 他想要案板那张纸，棚主："纸留这儿。来问纸的人，还得看它。" → 棚主塞三张饼给赵素："往东，有处茶棚。前头这一段，没有能用钱买饼的铺子了。" → 赵升："**这条路上的账，尽了。走。**""往哪边。""东。"
- **必留**："给我换一张。换了，人是不是就回来了？"；"帘纹同一路，裁口同一把刀。"；"谁抄谁，我也分不出来。"；"各自的纸，各自在背面写一行……"；"纸出无归渡。"；"我说的是来路。"；邻道棚主"我认我这一份"；"那是你的纸。"；领队汉子的话（找了三天、跑了四趟、你照纸办的、这条命记在谁头上、纸不给钱、我记着你们）；"一贯又六十三文。""这些是全部。不够三十贯。"；"这条路上的账，尽了。走。"
- **篇幅**：两章压一章，写满 3,300。比纸吵架略压；验货压一半。
- **删**：旧 120 棚主对讨水脚夫说"走了"（三人还在棚里）；旧 121"这话在棚里传了两天，他一路都是听着这话进的门"（越视角）；旧 121 回程骡车、背风坡、震一家挨一家的尾段（留给新 41 开头一句）；"往东两天有处茶棚"的里程。
- **口径**：CI、CT、CV。
- **章末**：出院门时，石堆上新添的两块颜色浅一层；或案板上那张纸压在粗碗底下——"头一行是名字，字写得收着；第二行是来路，无归渡三个字写得重，墨透到了纸面上。"二选一。
