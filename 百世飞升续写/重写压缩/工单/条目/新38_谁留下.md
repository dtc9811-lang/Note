#### 新 38　谁留下（旧 115、116）【节点章：四成·开府】
- **事件**：第二天一早账室，赵升问往西第一座渡口多远；赵素："谢青那张单子上，往西那一线，最近的脚程九天，最远的二十三天，过两处歇脚棚、一处废驿，都不是我们的。"（口径 CH、CK）→ 赵升："**喂一次，歇三天。这个打法撑得住渡口，撑不住路。**路上没人替我看灯，也没地方让我歇三天。洞天要自己生出仙炁。要自生，先开府。"要料："吃得住仙炁、又不吃仙炁的料。钱买不来这个。"赵素："料到了我记账。推几天，我也记。" → 午后谢青跟车送料，带着宗里那七个匠人里的两个（一年轻一年老，不起名）：河底石（退货，挂黑皮）、旧阵盘残料（巴掌大，纹磨剩半道深）、陨铁屑（半口袋）；老匠人："这盘子底烧过三遍，气路死了。""这一车，**三枚下品仙晶**。"（口径 CI）→ 赵升逐块试料：吐回九成多的是吃得住，沉进去的是吃；谢青学会了替他试，记账字比赵素快，不如赵素齐 → 挑中三小堆，挑剩的比挑中的高 → 老匠人把陨铁屑放回挑中那堆："这东西吃法力。可它沉。压底，沉的有用。""我只会摆料。重的压底，轻的浮面，老规矩。" → 当夜进洞天：廊下五根柱子；河底石沿五根柱基砌成一圈，圈径一丈出头，阵盘粉拌陨铁屑填缝，压出一个浅池，深不过三寸——"像一户人家，先立地基，再谈过日子" → **硬扛**（三天压成一段，只留三个数）：头一天压进去三百来缕，存住零，杂气过臂像吞热沙，两条小臂发红；第二天小臂起白斑，左四块右六块，不疼，麻；第三天改"压底"，法力顺着圈绕，绕到第四十圈，声音从"渗"变成"走"——"不是存，是做记号。像人天天走同一条路，路认得脚步。"中午左耳失声几息，右手拇指、食指、中指发麻 → 夜里前厅，赵九满："明天还来？""还来。" → **成了**：第四天不喂，池底自己渗出一层润；守了一整天，傍晚积够一缕——"**一缕。洞天第一次不靠他，自己有了东西。**""**窗被支开了。支进来的不是光，是深。**"——**仙体醒四成** → **当场用出来**：天黑，他托着这一缕出东侧门进死区，撤掉法力，仙炁自己撑着，撑到第十四息散了（口径 CY）——"像一滴水落在烧热的石头上，滋滋地撑着" → **代价**：双臂白斑、右手三指麻、左耳一天断两三回；四成新撑开的那片还软，像新夯的土，承不住重；更深一层：池底那层润的丝，接在前厅那些住户身上——"**他们在，池底渗。他们散，池就退。**""这笔债原先背在他身上，现在长进了池底，成了根。" → 收工具时，池底有一道两尺多的缝，缝里嵌着比洞天底子还旧、发暗的东西；他不动，不碰 → 脚底那条往上的粗脉"停了一下。一拍，又接着走" → 清早账室："**三天后，清早走。**"池底攒满三缕就不涨了（口径 CC），路上就靠这三缕 → 赵素：带三本账（一本路上用、一本回来对、一本空白），时刻表正本不走、副本不离人；把谢青那张单子抄进路上那本，"一个数都不改"；"**带不动的都是留下的。**" → 赵升路过赵素屋门，看见木匣收好了；桌子中间压着最厚那本废账——并线那年记的，前半本是她的字，后半本换了人；账室里她在教赵茂和两个帮手，他在门口听见一句"对不上，先查哪儿" → 掌灯时赵长庚拄弯杖来，先问账：灯油够几十天，谁写日账，月底谁核；正册来文书谁答话——"**我答。我不走。**族里的名在这里。并线那天没保住的那一个，往后要把名添回去。"（口径 CF、CM）赵升把劫户点名印交给他："答文书用得着。"（口径 CG）→ "洞里那个，那天没保住的那个，还在不在。""**在。脸朝东。**" → 他想进去看；赵升："门不在地上。"老人拄着弯杖往前探了一下，杖尖敲在石板上一声干响，没迈第二步（口径 CA）→ 他递出一块旧木牌的角（口径 CU）："**带进去。**"当夜赵升把牌角立在那个住户脚边，靠着鞋帮，刻痕朝外 → 第二天上午赵茂背着行李卷来："我想去。""灯谁守。"他攥了半天："你。"卸下行李，用炭在账室门边写："**守灯，赵茂。油面早晚各查一次。**" → 晌午赵九满扛着钎来："守灯的够了……走路的呢？一个没有。""你留下。""你手上的白斑还没退，三根指头还麻着，一天断两三回耳朵，走九天，你让我留下？你一个人带着账出门，路上出了事，账谁背？那就这么定了。**我走。**" → 傍晚赵敕带文书袋来：渡口该有正册正式的名义，"**名分是墙，墙立在那里，风就得绕着走。**"赵升："**灯、门、来的人。渡口认这三样，不认名字。**""墙也不认人。可风进不来。""风进不来的地方，门也关上了。"——赵敕："我留下。对外的公示、公务文书，我来答（口径 CZ）。名分的事，我往后不再提第二遍。"
