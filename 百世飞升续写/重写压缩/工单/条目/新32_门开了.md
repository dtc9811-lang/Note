#### 新 32　门开了（旧 96、97、98、99）【H 档】
- **事件**：赵升一个人出东侧门，沿归客走的那条路往东（口径 AN）：路的颜色比西边深，边角锋利，像铺好后没人踩；空气里金属、土腥、烧尽的味道 → 合利渡：规制和无归渡一样，灯比无归渡白天还高，门整扇开着 → 踩上引路第一块石板：重——"**那是积压。一条路还在把东西往这里送，这里却不再往外送。**无归渡的引路也重，但那是踩出来的重。这条不是。" → 进门：前厅站满归客，几百个，前厅到后院到堤上，全部脸朝东；衣色更深，衣角的丝线朝一个方向倒，站了少说半年 → 东侧门**关着**，推不动。不是锁；门那边是空路，顶在门上的，是这边挤着的人 → 一个三十岁不到的年轻人过来，久没睡好："我替他看着。""替谁。""祁先生。"——门是六个月前关的，"我没关，它自己关的"；推过很多次，托过路的带过两回消息，不知道到没到 → 廊下旧案上一本皮面册子：一行一个名字，来处、日期，最后一栏，栏名两个字——赵升认得这两个字（新 26）：**归处**，全空；这本是新册，照着古格式记的 → 廊下最里间一把新锁，年轻人交出钥匙：屋里码着三万年前的遗物，箱子、包袱、扁担、旧伞、旧灯；"我只管记名字。他每月初七来，带人来点一趟。""点的时候，人在哪里。""**就在这里。东西放下的地方，就是人站的地方。**" → 赵升掌心贴东侧门：一阵很深很闷的震，门框落灰，掌心一层灰白，和路面新石板缝里的灰同色；"有时候会这样。每次就一下。半个月了。" → **在后院推一次**（口径 AT）：无归渡东侧门后是路，路到合利渡，合利渡东侧门关着，路堵了；第二次归潮为什么只来三成、为什么剩下的停在门槛外三尺、为什么那一夜西边正好起了苗七的渡口——**两件事本来就是一件事的两半**。"**顶在门上的，不是锁，不是闩，是这六个月里没有被放过去的人。**" → 回渡口，他一件一件说给赵素，赵素只问一句："六个月关门，我们这边三个月才停住，差的那三个月呢。""积满要时间。" → 第二天一早赵升带赵九满去（赵素留下对账）→ 年轻人出来，没拦 → 赵升绕到东侧门外：门板比墙新，门外那段往死区去的路是空的，脚底很重 → 他站在空路上，手放上门，低声："**可以走了。**" → 门自己往外慢慢开到一半，压力像水从窄缝里涌出来；一个接一个走出去，走进黑里（第一个不提灯，口径 AS）→ 他绕回后院：里间屋的门开着，屋里空了，只剩一层细灰 → 年轻人抱着三本册子："三本。我记满了三本。""他什么时候来。""初七。"今天是初七 → 赵九满："那这道门，当初是怎么关上的。"赵升看了一眼门框内侧——闩孔是新凿的，没说话 → 合利渡的归客走空，灯还亮，两道门都开着，风直穿过去 → 傍晚回无归渡，前厅空了。赵素："下午动的，从东侧门出去，一个一个，走了两个多时辰，走完了。帐上，那一栏，今天我写什么。"
- **必留**："那是积压……"；"我替他看着。""替谁。""祁先生。"；"归处"（认出，不是发现）；"东西放下的地方，就是人站的地方。"；"顶在门上的……是这六个月里没有被放过去的人。"；"可以走了。"；"三本。我记满了三本。"
