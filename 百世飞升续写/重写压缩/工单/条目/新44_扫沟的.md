#### 新 44　扫沟的【H 档，硬节点：东边墟收口】
- **开场状态**：见第三节。
- **事件**：天亮，三人从第五座下来，直接去第八个点（第七座正东九丈二）。赵素先把第五座那行刻字和第八点的位置再对一遍，"一个数都不改" → 赵九满用**左手**使钎往下探：翻过的浮土底下，钎头碰到硬土；刨开，硬土上压着一个方方正正的印子——**方座压出来的**，边角跟柱础的方座一个尺寸；石头没了，坑又被人填回去，填土底下还掺着补柱础那种新料的渣 → 赵九满："石头搬走了。坑倒是给咱们留着。"赵素量方印，"和第七座的座一样大"，记下；赵升（说出口，不是旁白）："**他们守的是路，不是石头。**" → 赵升让两人留在第八点，自己下到浅沟里，往东走。不用法力（在这儿用就是留名、招灰白），只让神识往地里沉——沟底下的土一样厚，一样实，像一直被人踩着、又一直被人扫平 → 走出去几十丈，沟里迎面来一个人：老人，旧棉袄，手里一把短扫帚，一边走一边扫，扫过的地方连他自己的脚印都没有（口径 DG） → 两人在沟里对面站住。老人不说话，扫帚往赵升脚前一横 → **试探**：赵升往左让，老人跟着挪半步；往右，又是半步。赵升伸左手去拨扫帚杆，老人手腕一翻，扫帚杆贴着他的手背滑开，另一只手平平按在他胸口，不使劲，只是**不让** → 两人都不用法力，比的是身子；赵升右手三根指头使不上劲，左手扣不住他的腕（老人的腕子像木头，茧长在指根）；老人一步一步往前，赵升一步一步往后，被"请"回了第八点 → 赵九满提钎上来，老人看了他右腕的布条一眼，伸两根指头捏住钎头，往下一按，钎尖插进土里，他就松手——不伤人 → **三人都被挡在第八点以西** → 老人开口，问了四句："数到第几座了？""姓什么？""打哪儿来？""往哪儿去？"——赵升一句不答；每问一句，老人等一阵，赵升都只看着他身后那条沟 → 老人从怀里摸出一本小册子，蘸了唾沫翻到一页，拿一截炭当面落了一笔，册子合上，没给他看 → 他又摸出半页旧纸，**不给赵升，递给赵素**："**你手里有可对的东西。验了，我们来收话。**"（口径 DI）→ 转身顺沟往东走，一路扫，扫的是自己刚踩出的那几个脚印；人走远了，沟还是那一道，干干净净 → 赵素捧着旧纸，不敢折："三万年前的纸。三万年前的墨。旧的做不成新的。"赵九满："他说'我们'。" → 晌午收拾，三人从柱础线绕出密集区，出了牌坊。赵升一迈过牌坊，脚底那断了的震又接上了 → 野营地：赵素找到另一支东来队（不是新 41 那一支），替他们重抄一摞货签，换来半袋口粮、一小包盐；领队说他们明天一早往东北回城 → 傍晚三人在营地边上搭锅，熬了一锅稠的，吃饱了一回 → 夜里，赵升进洞天看池底：石头上又湿了一层，润回来了，还不够一缕 → 营地篝火的光里，赵素把旧纸摊在木匣盖上，一行一行看。
- **必留**："他们守的是路，不是石头。"；四问不答（四句问话原样，每句后面"那人等了一阵"一类的重复）；老人当面落一笔、不给看；"你手里有可对的东西。验了，我们来收话。"；赵素"三万年前的纸。三万年前的墨。旧的做不成新的。"；赵九满"他说'我们'。"；不用法力的人路上留不下印（只引，不重述规则）。
- **篇幅**：H 档，可到 3,500 字。四场：挖第八点 / 沟里对面 / 交纸 / 出墟换粮。挖坑和换粮各压到 500 字左右，沟里那场写足。
- **不许**：老人用法力；老人说出来历、说"守"字、说柱础是谁的；赵升拿出凉碎片对沟；写皮坎肩一伙（本章不出场）；写灰白动；写第九点。
- **口径**：DB、DD、DF、DG、DH、DI、DJ。
- **章末**：落在**物件**：篝火光里那半页旧纸，第三行那个旧体"赵"字，最后一笔压得最重。**不用"他看着"收尾。**

【开场状态】
**甲开写新 44 前**：新 43 末——三人在东边那座墟（不起名）里，夜宿第五座柱础顶面，锅摆中间；第五座顶面靠赵升睡的那一侧刻着"数石头的人，到第七座为止。"；他们前一天站到过第八个点（第七座正东九丈二：浮土翻过，脚印脚尖冲东，一步半），往东一道浅沟，宽一尺上下，笔直，沟边没有脚印，三人没跨进沟；第七座豁口被人补了新料。两只灰白伏在北边密集区深处。野营地皮坎肩一伙来抢过一回，撂话"石头想要的人，营里有的是"。赵升仙体醒**四成半**，法力见底，在墟里补不回来；池底三缕仙炁用尽，润没了，要三天渗回，还没渗回；双臂白斑左四右六，右小臂起皮、汗浸火辣辣地疼，右手拇指食指中指麻、不执笔，左耳一天断两三回。赵九满右手腕蹭开的口子包着布条，没肿，新肉红，**握得住，攥不久**，左手使钎。赵素木匣摔掉一角，绳捆着，绳另一头拴在她腰上；匣里两本账（路上那本柱础线那页缺右边一条，第九点随纸条丢了；"回来对"那本）、裂了缝的砚、炭条、火折子；第五座刻字连字形抄过。赵升怀里：生死断笔、凉碎片、错纸、样页。新 11 赵素给赵升开的那张临时引夹在木匣的账本里（前文没写，按此口径）。长照路引、过客册在无归渡账室。钱零；炒面只剩袋底，两份收在匣里；竹筒满着。洞天：七盏灯亮着，住户在前厅脸朝东，牌角立在远亲脚边、靠鞋帮、刻痕朝外，温残片靠在中央柱脚，池底缝没碰过，往上那条粗脉停过一拍。正册上无归渡是"步纲君渡口旗下，歇脚棚，无归"。
