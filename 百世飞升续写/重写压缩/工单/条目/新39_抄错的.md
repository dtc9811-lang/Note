#### 新 39　抄错的（旧 117、118、119）
- **开场状态**：见第三节。
- **事件**：天没亮透，赵茂查油，两个帮手一个抱账一个扫石板；赵素抱木匣，赵九满扛铺盖和铁钎，赵升空手——池底满着三缕，生死断笔贴在怀里 → 赵茂送到西门里，不再往前；赵长庚："族里的名册、族里的文书，我答。"赵敕："渡口对外的公示、公务文书，我答。" → 出西门，十步石板接上西边的路网，谁也没回头 → 赵素交代一句：路上用的铜钱只备了一贯多，仙晶路上换不开（口径 CI）→ 头一天：路宽了一倍，两辆车并行，脚底的震好几股混在一起；石板缝干净；路上的人都往东走（"东边有渡口"）；赵九满倒鞋里的沙："荒路才要账。" → 第三天夜里第一处歇脚棚：三面墙、草顶、土炕，棚主五十来岁："一人两文。炕热的。" → 墙上一张黄纸：**灯不熄、门不锁、来者先问后医。**赵素把三行抄进账，"先问"画了一个重圈；棚主："前些日子有人打这儿过，说如今路上都兴这个。"（口径 CL：写足这一次）→ 往后几天两句带过：西风带沙；过一座废驿（口径 CK），塌了两处，门锁锈成一坨，石板到驿门口就断了，路网的震在这里细下来，像一根绳子拉到一半忽然松了劲 → 一天后半夜，赵升手贴石板往西探：十几里外一段虚、浮，按下去没有底——"**往西，路在，没人接。**" → 走了九天，傍晚到第一座渡口（口径 CD）：和无归渡一样的格局，堤矮，门口石板上没有印记；门上一张黄纸，同样的错；七个灯座两亮五黑，灯花没剪；门框铜锁扣磨得发亮；门口半人高一只木箱，牌上四个字：**先钱后事** → 脚底的震到门槛外为止，没从门底下穿过去 → 拦门人："住店吃饭进门，先钱后事。一人一夜两文，行装另算。"赵升："无归渡。"拦门人取出一本抄账翻到补名那页，"无归渡"夹在一排渡口名中间："名字对上了。名字是名字，钱是钱。一人两文。" → 赵升没掏钱，三人退回路边；赵九满："这算渡口？"赵素："小注上算。" → 天黑透，锁落下（这一夜宿在路边）→ 第二天清早付了钱进门：前厅比无归渡小；灯两亮五黑，天亮不灭；后院有火盆、草席、水缸，**没有药** → 门外路侧一个年轻汉子，短须，袖子撕了半截，左小臂缠着黑布，离木箱三步，被挥手就退三步，又站回来——他没钱 → 主事（四十来岁，袖口磨亮）出来；赵升拿赵素那本空账换他的账借看半天："空账换旧账，你亏。""不亏。" → 赵素对账：式样全对，第四栏"事"后面多了一栏：**钱**——"账页上有这一栏，我就记……从东边一家渡口抄来的，他那本也是抄来的。"补名页至少三种笔迹，"无归渡"写得最歪 → 主事算账：两盏灯是油钱；门落锁是被翻墙抢过；先收钱是被赖过账——"**规矩是好规矩。我抄了，没抄错。就是渡口要活，样样得钱。**"——"有人来求医呢。""往东送。镇上有药铺（口径 CJ）。夜里进不来门的，就在门外搭个草席。" → 赵升不争，让赵素记下三条差异；赵素描下带钱栏的那一页做样页 → 傍晚火盆边有人闲话：再往西三天一家棚，前几日一个走货人夜里到，棚里照规矩"先问"，隔门问到天亮，人不行了。"他又没做错，他照规矩办的。"赵九满放下碗 → 夜里厢房，赵九满："账是咱们家发出去的。四百三十七份。发的时候知道在三十七个地方有人抄。现在抄到第几手，谁也不知道。路上出了事，算不算咱们的。"赵升没答："明天清早动身，往西。三天，到那家棚。" → 动身前，赵素出门给墙根下那汉子剪开黑布：伤口沤了，边缘发白，清水冲，上药粉，白布缠紧；"三日换一回布。""多少钱。""不要钱。" → 三天路两三句：赵升替赵素抄一行，字歪，钩散成两岔，此后不再碰笔；一路上又见了两张黄纸，错在同一处 → 到那家棚：三间板房，灶披一口大锅；棚外一辆货车，棚后一头瘦骡；门板齐腰高一片抓痕——坐着抓的，木茬发白；棚东头一堆新垒的石头，插着半截树枝；板壁上同一张错纸 → 棚主（五十多岁，灶灰手）："宿店？"赵升问石堆——"**人。**" → "**纸上写的是先问后医。我就问。他答不清。答不清的人，夜里我不敢开门。**前年西边一家棚，夜里开了门，天亮连锅都没了。""**开门的时候，人就贴着门板。坐着，已经凉了。我探了探鼻子，探了两回。**"货单汗洇了，只剩两个姓，夹在账里；两个脚夫抬的人，一人四文；货没动 → 纸的来路："一个过客让贴的……这规矩打一个叫什么无归渡的地方出来的，纸是那家发出来的。" → 赵九满掏钱付宿时顺口说了一句"打无归渡来"（信息纪律）→ 赵升要黄纸、熬糨糊；赵素在灶披的案板上写"灯不熄，门不锁，来者先医后问"十二个字；赵升覆上新纸，掌根压实，揭下旧纸折三折收进怀里——"**纸是好纸，字是认真的字，错的那两个字写得比别的字都周正。**" → 天擦黑，脚夫来讨水，棚主："纸换了。无归渡的人来换的。往后纸错了，人家会来给咱们换。" → 赵九满："在渡口，你报了渡口，没认那张纸。现在换纸了。"赵升拨着灶膛："**纸是咱们家发出去的。**" → 赵素账上四栏放不下这件事，她在页背写："出门十三日，棚，一人。没了。货车一辆，骡一头，仍在棚外，无主。"
