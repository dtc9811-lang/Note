#### 新 34　十四座（旧 105）【H 档，节点章：两成半】
- **事件**：子时之前潮声先到，灯稳；赵氏各就各位，不用人说 → 提灭灯的领头从西门进（和每一次一样），走到东侧门——**这一次没有停，走过去了**，一批又一批，"像水从一段管道里过"——写足这一刻（前两次都停过，这一次穿过去，渡里每一个人都看见了）→ 同时路网里有另一种更低更乱的声音，从四面八方来 → 赵升神识先到：西边堤外十几个人往渡口来，练过的走法，手里提着东西——"**乱夜里，最亮的地方最好抢。**"（口径 AV，不提别处）→ 让赵九满把人往里收、伤号往后院、不许堵门，"我在这儿" → 高个子穿甲片："就你一个。"一刀带法力劈来 → 赵升掌心黑、青、赤三色缠在一起撞上去（口径 AW），底下垫着一点仙炁：刀没断，刀上的法力散了，刀飞到堤下 → 进半步，一掌按在胸口——九世时一门擒拿最浅的一式，当年能把山头按进地里，现在只有一分力——高个子跪下 → "你们进去，今晚能抢一批。抢完了，这儿就不是渡口了，明天你们连落脚的地方都没有。**要么走，要么进来，按规矩来。伤的先进。**" → 那队人走了 → 赵升的手在抖：撞散那一刀的是底下那点仙炁，胸口空了一小片——"**仙体醒两成二分，能出一掌。第二掌，要拿命填。**" → 归潮将近三个时辰，最后一批过东侧门，路网安静，像洗过一遍 → **节点五段**：决定（那一掌逼得仙体开了一道缝，不趁势引气它就合上，他坐到堤上）→ 硬扛（缝是被撕开的，像从裂口里抽丝，胸口空→热→胀，胀到肩胛骨缝，后背抵着堤石，指甲掐进石缝）→ 成了（胀退成酸，三色法力多了一线，是质的变化，"像新长出来的骨头比旧的密"——**仙体醒两成半**）→ 当场用出来（指尖在堤石上划一道：比新 26 那道深半分，**窄了一半**——多出来的不是力气，是精度）→ 代价（胸口酸三天，三天内不能动法力；再引一次就会过）→ 天快亮，探子挤回来，只报了两座（口径 AV）：北边那家，锁断了，门开了，归客穿过去，灯仍灭着，里头没人出来；西侧一座结阵的，"不是它自己走的，是那片地方移走了"，里头的人还以为阵护着没事 → 赵素在"十四"底下画了两个记号 → 天边发灰，赵升出东侧门往东，走一个多时辰到合利渡：引路十几步，踩上去脚底什么都没有，是死石头 → 渡口原址**空了**：石板、门、堤、廊全没，只剩一片夯实的深色地，没有碎石残垣，"**像那座渡口从来不曾存在过**" → 怀里温残片热了一下（比新 25 在账室读渡档那回重）；取出两块，一温一凉，同时在动，偏的方向一样：东边，死区更深处；凉的那块在骨头里响，像远雷 → "一块是他九世的洞天，一块是他九世的雷器。两样都在东边。"他没往东走——**现在还不是时候** → 祁广站在那片地中间，手里攥着一根门闩，瘦了一圈，脸朝东（口径 AU）
- **必留**："这一次，没有停。走过去了。"；"乱夜里，最亮的地方最好抢。"；"要么走，要么进来，按规矩来。伤的先进。"；"第二掌，要拿命填。"；"两成半"；"像那座渡口从来不曾存在过。"；"现在还不是时候。"
- **篇幅**：H 档，可到 3,500 字。扩写放在：穿过东侧门那一刻、节点五段、合利渡原址（踩死石头、蹲下摸那片地、和祁广之间的沉默）。
- **删**：旧 105 赵升"立刻明白"北边撞开西边移走、"这一夜路网在拆渡口"（口径 AV）；"唯一亮灯开门的渡口"；"混元一炁大擒拿""真元"。
- **口径**：AV、AW、AU、BG（赵素在账室推开窗停笔）。
- **章末**：**他站在引路末端，看着祁广，看了一会儿，转身，往回走了。**
