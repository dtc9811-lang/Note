#### 新 50　引不动【甲段收尾】
- **事件**：夜里赵升进洞天，把新 47 捻来的那撮补料渣，按在廊下柱础的缝上——**对上了**：颜色、颗粒、干了以后的硬度，都是一路料 → 一段九世记忆接回来：一双手往很大的柱础缝里抹灰，用的就是这一路料（**只给这一个画面**，不点名谁的手、哪座洞天，话不说全） → 他说给赵素的只有一句："**柱础、廊柱、旧路基，是一套手艺。**"推论到此为止 → 第二天，他想从城外那段旧路基上起一块础石回来，跟廊下柱础比一比 → 三人出城到那段路基，赵九满左手把钎插进石缝撬，撬起一角 → 城门司的巡差从官道上过来："**官道路基是公物。动土，拿人。**" → 赵升不动手（城里城外都不许大打，也不必打），把事揽到自己身上；巡差把赵九满的**铁钎**收走，念单子："凭保人来结，结清了领回。"（口径 DV）→ 远处坡上站着一个人，扫帚靠在腿边——扫沟的人，不过来，不帮，也不解释，看了一阵走了 → 回城，赵素在账上把这条路记死：**此路不通。**另记一笔：保人那边又欠一笔 → 夜里赵九满坐在院墙边，右手搭在膝盖上，左手习惯性往旁边一摸，摸了个空。
- **必留**："柱础、廊柱、旧路基，是一套手艺。"；"官道路基是公物。动土，拿人。"；"凭保人来结，结清了领回。"；"此路不通。"
- **篇幅**：2,800—3,300。三场：洞天对料 / 城外撬石被扣 / 夜里。
- **不许**：失败的原因写成打不过（必须是秩序）；丢断笔、凉碎片、名册抄件；旧洞天的实物出现；碰池底缝；老人说话。
- **口径**：DG、DH、DS、DV、EA。
- **章末**：落在**空**：院墙角原来立铁钎的地方空着，墙上留着钎头靠出来的一道白印。
