#### 新 33　反咬（旧 100、101、102、103、104）
- **开场状态**：见第三节。
- **事件**：坊市公告栏在东侧进口旁一堵石墙上。赵升陪赵素去贴新抄的账本（口径 AU），七八个人站着 → 身后有人故意放声："又来贴了。""三天一贴，勤快。""**勤快到刚好把你要知道的那部分贴出来，把不让你知道的留在后头。**他不贴，你不知道归潮什么时候来，你得求他。他贴出来，你以为你知道了，其实你知道的是他让你知道的那些。**你只是以为你在自己走。**"——坊市跑消息的人事后告诉他们，说话的叫**祁广**，合利渡是他的；他清点了六个月的一批货，前些日子一夜之间化成了灰 → 话三天传遍坊市：时刻表在他们手里，账本是钩子，"两条路，都是你们赢，他们输" → 赵升问赵素："他说的那些，有没有说错的地方。""**时刻表那段，说的是对的。**他没有说错。其余说的是将来的。将来的谁也证不了。" → 五天后，公告栏上新贴的几份被人揭下，在旁边小石炉里烧了 → 赵素第二天去补贴（赵升在十步外看着）：几个跟祁广有来往的走货人拦她，"账本别贴了"——"有意思，我的账我贴，撕了补，补了撕，都是自己的事。"其中一人推她肩膀，她右膝半跪在石板上 → 窦让（左袖空半截）走过来，叫她"赵记账"："一笔账，亏的敢放进去，就说明那些账是真的。**他的账本，亏的那段在哪里？**那几个人推你，我看见了。不是路过，是等在那里的，祁广让等的。" → 赵升先问："膝盖怎么样。"再问："那一批被撕的，你还有底稿吗。""有。""补抄三十份。" → 夜里赵升坐堤上，神识先到：三个人从坊市方向贴着堤外阴影来，停在外沿四只铁灯架的光外 → 中间那个发一道白光，一枚白色灵器针；赵升两指夹住，捏碎——烧了一丝仙炁，指根麻了半夜 → 他从堤上走下去（口径 AW，不缩地）：最前头是筑基，修过身法；左边那个攥着一张符，右边那个腰上挂一块坊市铜牌 → "你腰上那块牌，摘下来，放地上。"没动 → "三个人，一件灵器，一张符，一块坊市牌。你们不是来杀人的，是来打听的。""赵堂主。""嗯。""我们走了。" → 三十份抄了四天，赵素自己在首页加了两行（"步骤本身即是答案，不需要来问我们"；"亏损记录在第几页，不曾删去，仍在"），赵升看见"多加了几行"，没问，帮她打绳扣 → 三更，赵九满来报：苗七的帮手连夜来取了一份，"苗七说他知道今天坊市发生什么事了" → 过了一场夜雨，苗七自己走来，上堤："时刻表，准不准。""准，误差几天以内。"赵升报了下一次归潮的时段、最晚的日子 → "你那边粮药，够不够撑到最晚那天。""不够。""差多少。""**差两个月，按现在减量之后的用法，再剪一刀，还差一个月。再剪，就是重伤不管，那个我不做。**""按时刻表，你那边撑不到下一次。""我知道。"——苗七说了一句不相干的：并线那天路上有个腿伤的，他接的，后来留下帮他，养了三个月走了，上个月来信说还好。"我回去再算一遍，算了再说。" → 归潮前，赵素拟通知：归潮时刻、推算范围、浮动上限，最后一行"**这是我们这边发出的最后一封通知，之后各自决定，我们不再发了。**"一共十七封，随探子和商队发出 → 回来三封：路网北段一家（口径 BH，不是北边那家）派帮手来问注意什么；苗七写在布条上三行"灯点好了，门开着，药备了，东侧门今天全开，祝顺利"；支线末端那家说备好了 → 赵素在账上写"三"和"十四"，中间一道线 → 归潮那天，今天正是推算的最早日子，和赵素自己推的差不到一天："准了。" → 这是第三次，准备没人问：赵九满给库房门的合页抹油，赵茂先加东侧廊那盏的油，两个年轻族人在后院靠堤角落多留一条过道 → 深夜脚底的震越来越近。
