#### 新 28　撑不住的先死（旧 83、84、85、86）
- **事件**：半个多月里，探子报回三家（赵升在场听）：东侧那家（坊市走货散修开的，规矩是从苗七一个帮手那里传过去的，账还没有）；北边那家（帮手五六个、进退有度、不说来历，账不让看）；支线末端那家（主人亲自接，账主动借给探子带回）→ 赵素看支线末端的账："不是从我们这边描的，是从一个已经描过的版本再描的。偏了两层。""那一层一定存在，而且他把格式传出去至少两份。" → 赵升："北边那家，白天我自己去。" → 天没亮他步行到北边：灯灭，灯座里油面还高——是天亮时专门吹灭的；门挂铜锁，锁面朝外，锁旁小牌两个字：**不锁** → 在门外等了将近一个时辰，没有伤者来；主干上两个人路过，一个慢下来看了看，还是走了 → 他走引路全程，蹲下按石板：有震，活的，**路网认它** → 回渡口，赵九满问了三句，赵升三句"嗯"；赵九满低一个调："**那我们收人，图什么。**"赵升不答 → 过几天赵敕来算账（赵素在，赵九满靠门框）：真收人每月要人手四个两班、三种药、粮；做样子只要灯油、一块牌、一个人——"**一个是另一个的十一倍。**往少里算。" → 东侧那家亏了、主人借过钱；又过几天，东侧那家主人收留的一个腿伤者养好后半夜卷走几袋粮和账册，主人追出去，被打断左臂，关了门（口径 AO）→ 赵九满转了两圈铁钎："咱们灯不熄，门不锁，来者先医后问。然后**撑不住的先死，做好事的先出事**。" → 赵长庚在廊下，拄着弯杖："东侧那家那个人，打他的那个，腿是他接的，用的是他自己的药。""我没说他做错了，我就是说了一遍这件事。"——赵升问他怎么看，他讲当年劫户入墟被当探路队用："我那时候也这么问过……后来我发现我问的不是这件事，我问的是我们这支还值不值得撑下去。""问出答案了吗。""没有，我就撑下去了，然后答案就有了。" → 赵升去苗七那里：灯白天亮着；药箱几格减量，轻伤药换成便宜的，**重伤的没动**："重伤不能省，省了会出事。"帮手走了一个（去镇上扛货了，那边工钱高），剩六个 → 说起东侧那家主人被打，苗七："**我知道这是可能发生的事。并线那天在路上，把我推回去的人，他也知道把自己推出去是可能发生的事。**" → 赵升："账本，下个月我让人送一份新的来，你那边自己核一遍。"
- **必留**："不锁"二字小牌；"路网认它"；"那我们收人，图什么"；赵敕"十一倍"；"撑不住的先死，做好事的先出事"；苗七那句"我知道这是可能发生的事……"原句。
- **删**：旧 83 末探子先报一遍北边"天亮灭"（只留赵升亲眼看这一遍）；旧 86 坊市四种舆论压成一句"没有一种说该接着收"；旧 85 赵九满"那五个字值钱"（留给新 29 赵素讲）。
- **口径**：AH、AL、AO、AY。
- **章末**：苗七那句话之后，赵升回到渡口，对赵素低声转述那半句；或落在苗七药箱里没动的那几格重伤药。二选一。
