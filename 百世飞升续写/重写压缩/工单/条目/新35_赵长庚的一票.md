#### 新 35　赵长庚的一票（旧 106、107、108、109、110）
- **事件**：天亮赵升回来，胸口还酸，赵素端的热水他用左手接（接新 34 代价）："归潮过了。""嗯。""合利渡。""没了。" → 来取账本的人，各自说了自家那一夜，赵素一边听一边在"十四"底下画记号（口径 AV）：头一个是南边支线一家的帮手（"十四座"之一），不认错，要账本，只抄时刻表那段也行；赵素给一整份："**不用抄。这份完整，时刻表在里头，全拿去。**" → 第二个是一家渡口主人亲自来，早先附和过祁广，不提昨夜，只要一份；走到外院回头："昨夜，我们那边归潮过来了。有几个归客伤的，我们接了，先医后问，账上记着。" → 第三个是谢青（口径 BA）：腰上不挂牌了，瘦了，眼下青；"支线末端那家，是我管的。回信是那边主人发的，发完我把人调回宗里盘点——就那一晚。"他自己摘了铁牌，挂回原来那块木牌；"**宗里那份写得比你的漂亮。可宗里那份，是给人看的。你这份，是给路看的。**"临走问："那七盏灯，点了多久了。""从接手那天起。""一晚上没灭过？""没有。" → 苗七另来一趟，堤上并站："昨夜，我们那边三批归客，全部过了，没有停。""撑到了？""撑到了。重伤的没省。" → 到傍晚十一家，十一份（补抄一直没停，口径 AZ），赵素手里还剩一叠；"十四"底下的记号也画齐了：八座没事，四座门被走开，一座移走，一座抹平 → 最后一个走后，一个帮手折回，单独问："**那我们，算你的人吗。**" → 赵升："**不算。**" → 赵敕从后院进来："白救。你给了，回头他们好了，想起昨天没回信的那件事，不用承担任何东西。"他拿起赵素的账册翻了翻，搁回去，没摔。赵素："他没有摔。"赵升："他一会儿还要用。" → 三天后，一个坊市里谁都认识的中人来传话：步纲君想来坐一坐，后天到 → 步纲君卯时一个人来（口径 BB，不按初见写），目光停在印记上："**七十四天。**那就是第二次归潮的痕迹。"——"我这次来，代表我自己，不代表正册。但我说的事，是在正册职权范围内可以做的事。**但我可以给你们名分。**"两份封泥文书：无归渡在正册上改为渡口，归赵氏所有；设"渡正"一职，由赵升任，核查沿线渡口、发合规证明、不合规的通报除名 → 赵升不伸手 → "税率可以谈，职权范围可以谈。"到门口："还有一件事，不说也罢。说了，你就知道我为什么急。"——挂在他名下的歇脚棚交上去的遗物，比他自己的渡口还多，上头问了两回 → 赵素让探子去问那十一家，步纲君的方案他们怎么看 → 第二天回信九封到：七家在考虑，两家不接（一家："名分在正册，正册在步纲君手里，**名分和麻烦是同一件东西**"；一家只两个字"不接"），两家没回 → 傍晚族会，廊下就着七盏灯：赵升把方案原样说一遍；赵九满："**他给的，他就能收，收了跟没有一样。**"（"给的人能收"全章只讲这一遍）；赵敕："这七家想的不是便宜，不是怕步纲君，是算清楚了——这个名分有用。**这不是软，是算清楚了。**"赵素："我先看条款。"赵茂："歇脚棚改成渡口，挺好的。" → 都等赵长庚。他看着灯："**我投赞成。**"赵九满把嘴闭上 → "我带着往东走的，二十三个（口径 BD）。带出来是运气。做渡口做到今天，死人、亏钱、被除名、被人说成钩子、被推倒、被烧账本，都扛了。但我老了。这件事，步纲君能给。他愿意给。我想要。我知道。他给的，他能收。**名分是可以失去的。但没有名分，你本来就没有。那不是失去，是从来没有过。我宁愿有过。**" → 没人说话，散了，没有结论 → 赵长庚留在廊下，赵升坐到他旁边（口径 BC）："坳里，有没有人叫宏运。""祠堂牌位上有个宏运公，就这三个字。"赵升把抄的两行给他看；老人没接，看了两遍，手在弯杖上收了收："宏运。"推回纸，起身走两步 → 赵升把一温一凉两块放在膝上 → 赵长庚又出来，弯腰指温的那块："这一块，坳里有一样的。""在哪。""祠堂。香案底下垫着一块，巴掌大。"
