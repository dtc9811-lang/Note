#### 新 41　寻墟（旧 122、123）
- **事件**：原路往东（口径 CN），几句带过：背风坡宿；饼掰成三份；过第一座渡口是夜里，门锁着，里头两盏灯；两处岔口都没拐 → 一天后半夜赵升守夜，怀里凉碎片沉了一下，凉的底下那一线东西又出来了，"很远，隔着一层又一层，像山那边的雷" → 他用拇指、无名指夹着碎片进洞天：七盏灯亮着，住户脸朝东，牌角立在那个远亲脚边；温残片靠柱脚，凉着，纹丝不动 → **凉碎片在洞天里，沉角冲着温残片**——绕到哪边，跟到哪边；举高放低，不变；放在灯座石沿上，也转向柱脚；温残片毫无反应（口径 CQ）→ 出洞天，赵素铺纸画线，碎片搁纸上又冲外头的东；再进一回，一样 → 赵素记："洞外，凉碎片偏东，试三回，同。洞内，偏温的那块，温的那块没动，试两回，同。""两个地方两个指法，听哪个的？""**都作数。里外各试各的，回回一样。**" → 又一夜，赵升手贴石板往深探：上层的震一天比一天密；沉过上层，**底下另有一股**——深、慢、沉，间隔匀得出奇，数三十下不差半拍，贴着地底往东不断，"**像按在一根埋进河沙的梁上**"；换一块石板、往东十几步再探，一样；跟西边那段不一样，这段按得到底 → 赵素贴手摸不着，记："上层震底下另有一股，深，实，一直往东。" → 饼省着吃，后几天只剩沟里的雨水 → 傍晚，**无归渡的堤**出现在前头，灯一排小黄点 → "不进去？""不进。""灯——""**有人守。**"贴着堤根绕到东侧，门开着，门洞里漏光，没有人影；洞天里那批人这会儿也脸朝东，和他一个方向 → 赵素记："过渡口，未入。"（不写日子）→ 出东侧门就是死区外缘（口径 CN），法力只出不进，赵升一丝法力都不动；走归客走的那条路，一个多时辰过合利渡原址——一片深色的光地，没有人，引路十几步到边上就断了 → 再往东十几里，上层的震发虚、发浮，没有节点接它，路从它身上穿过去；石板缝里长了草，草尖一律朝一个方向倒——"**这条路就只是一条路了。**" → 上坡前灌满锅 → 缓坡上一片野营地，三支队伍，油布树枝篷、石灶，口音、货色、计价都不同：薄石片当筹码，一片抵两文，平铺不串；"打东边来的。走的路，小注上没有。" → 赵素替一支重抄乱了的货签，换半袋炒面、一把干豆；一面货签木牌的产地栏刻着两个字：**大椿**——赵素把这两个字描下来（口径 CP）→ "这儿能捡什么？""捡货。**这座墟会往外吐东西。**坡下土里半埋着。""进去过吗？""**进去过两个。都没回来。**" → 坡顶土坎下半截旧石牌坊，斜埋，半根柱、一段断梁，字被磨平了——磨圆，挂着包浆："**字要磨圆，得一年一年地磨；要砸掉，一天就够。两种痕迹不一样。**" → 过坊一步，**脚底的震断了**；退回坊外一步，虚震还在；再跨进去，只有土石的硬 → "震断了。在身后。""还回得去吗？""**路还在。**" → 没有关防，没有名册，没有拦门人 → 宿在背风土坎下；赵升照老规矩抽一缕法力试（口径 CO）：离体不散，往下沉，被路面接过去，留下巴掌大一个浅印，守到天黑不淡；指甲刮下来是土末，印没动——"**在这儿，用法力，是留名。**" → 第二天清早赵九满不信，按了半缕，第二个印小一圈 → "往后走路，绕着自己的印子走。"往东，路面渐渐有前人的旧印，绕成了习惯（"走个路跟伺候人似的"）→ 晌午前，几十步外一个旧印上悬着一点**灰白**，拳头大，看不出头尾，悬得极低；旧印从边上往里淡尽，它挪到下一个 → 赵九满要上，赵升把他拽回路肩；它喝尽第三个印，看不出前后，可它就是**转了个身**，朝宿处那两个最新的印去——"它冲新印子去的。退。" → 三人退到旧印密集的那片边上，灰白半路被旧印勾住，顾不过来 → 密集区南边上一排**柱础**（口径 DA）：方座、圆台、腰上一道浅槽；赵升左手拇指摸缝——和洞天廊下五根柱子的础，同料，同工 → 往东数，一座比一座沉，数到**第七座**，前头只剩平地；七座同制式，一行冲正东 → 捆绳量：间距**九丈二**（第六到第七"九丈二挂零"）；凉碎片搁在头一座上，沉角冲正东 → 赵素画线，照间距推出第八、第九两个点，第九点快挨着纸边；碎片那页、深震那页、柱础线那页，三条线平行往东 → "**第八座，走得去吗。**""**纸上走得去。**" → 回宿处，那点灰白已经在了，悬在赵九满那半缕新印上，印淡了一半多，离铺盖三步 → 赵九满伸手去摸铁钎，赵升按住钎杆。
