# 卷七施工单：四会渡·寻回旧迹（新64—83）

> **卷级目标**：赵升沿雷器碎片与闻野旧路进入四会渡，确认第九世旧物“雷帝辟劫令”的残体已经成为跨界旧路的一部分；在不让现存路网随强取而崩塌的前提下，接回残体核心部位，并取得指向太乙灵界的不可替代证据。
>
> **规划原则**：本卷不再以“命债能否转手”作为主轴。倒果渡、欠命坊、裴燎、韩缄全部保留，但服务于“追旧物—入遗迹—争遗产—保路取物—去太乙”的主因果。
>
> **卷末硬收获**：雷帝辟劫令残体核心部位 + 洞天抗劫雏形经验 + 九世遗产被人为拆分的实体证据 + 太乙路线。

# 一、开场事实

- 已验收候选正文到新63《出城》。赵升与闻野刚离开客安城，走上去四会渡的路；赵素、赵九满、赵敕、谢青均不同行。
- 赵升当前按最新候选连续性执行：混元仙体约六成；本命五行洞天已能自生本源仙炁；具体储量、伤势与十三石状态以新63正文和 DevTrace 最新裁定为准，施工时不得凭旧表反推。
- 雷器碎片为凉性旧物线索；五行残片为温性。卷七主追雷器线，不同时回收五方镜、旧洞天、五雷钺。
- 闻野守四会渡外无名残渡，掌握一条旧路；其修为与真正上限仍不补设定，只通过行动证明识路、承压与选择能力。
- 四会渡是跨界路网枢纽。新地图必须实际出现不同界域来客、货物、修炼资源、脚户、生存方式与路线竞争，不得只换地名。
- 已登记人物：裴燎、韩缄、姚絮、戚武、宁拙。未登记新具名人物不得直接入正文；如施工必须新增，先登记。

# 三、批次A：新64—68「世界打开，锁定旧物」

## 批次目标

把四会渡真正写成跨界世界，同时把“旧物在前方”从模糊伏笔变成可验证事实。

## 五章功能位

### 新64：入四会

必须完成：
- 进入四会渡外层/前置路段；
- 至少通过三种可见细节表现跨界生态不同于客安城，例如货物、来客、修为、脚户方式、跨界损耗、路线价格；
- 闻野展示一次“识路”价值，但不能像导游一样连续讲设定；
- 雷器碎片第一次出现明确但尚不能定位的异常反应。

不可逆结果：赵升确认雷器线索确实与四会渡旧路有关。

自由区：具体场景入口、来客样貌、货物、声响、局部小冲突可由写手发挥。

### 新65：先到的伤

必须完成：
- 姚絮或等价已登记角色带出“结果先到”的具体伤害；
- 赵升以神识/医理/百艺观察伤痕，不能靠旁白解释倒果原理；
- 雷器碎片对伤痕或旧路残留产生第二次可重复响应；
- 闻野必须独立承担一次风险，不由赵升兜底。

不可逆结果：赵升得到第二份证据——雷器异常、伤痕与旧路是同一条因果链上的东西。

### 新66：旧路被夺【Gate 1】

必须完成：
- 裴燎正式以行动出手；
- 他抢走一段关键旧路、安全窗口、锚点控制权或等价通行条件；
- 闻野必须在“保旧路”和“把代价转给旁人”之间作出自己的选择，且拒绝让无关过路者替残渡承担后果；
- 赵升和闻野都不能把这次失败解释为布局。

不可逆结果：闻野暂时无法按原路回残渡；裴燎先进入旧物所在方向。

Gate 1 验收：
1. 闻野三项承载——识路、承压、独立选择——是否都由行动证明；
2. 裴燎是否真的先赢一次；
3. 四会渡是否已经有“大世界打开”的读感；
4. 旧物追索是否已经成为比命债讨论更强的主目标。

### 新67：倒果渡边缘

必须完成：
- 赵升第一次进入倒果渡或其边缘危险区；
- 规则只展示可观察现象；
- 赵升做一次小规模验证，发现异常并非完全自然，而在某个旧锚附近显著增强；
- 韩缄/欠命坊可在本章或下一章进入，但不得把本章变成手续争论。

不可逆结果：锁定“受损旧锚”这一实体目标。

### 新68：一缕仙炁，换一个坐标【Gate 2】

必须完成：
- 赵升用洞天/本源仙炁做一次有限隔离或承压实验；
- 必须付真实代价，可消耗一缕仙炁或产生等价损耗，具体以当前连续性为准；
- 不破解倒果渡，只取得一段可验证坐标/方向/旧锚识别法；
- 批次末明确：旧锚后面还有更深的实体结构，裴燎已经领先。

不可逆结果：从“知道旧物在四会渡”升级为“知道从哪里进旧路遗迹”。

## 批次A必须兑现

- 世界：跨界生态真正出现；
- 人物：闻野、姚絮、裴燎至少三人产生独立选择；
- 探索：旧锚目标被锁定；
- 修行/资源：至少一次真实仙炁或洞天代价；
- 战斗/敌对：裴燎先赢；
- 收获：入口坐标或等价实体识别成果。

# 四、批次B：新69—73「入旧路，第一次接触遗产本体」

## 批次目标

真正进入四会渡旧路下层/废弃段，完成一场完整遗迹探索，并第一次确认受损旧锚与雷帝辟劫令残体直接相连。

## 五章功能位

### 新69：旧路下层

- 进入非日常跨界区域；
- 新环境至少改变两项：法力/神识使用方式、空间结构、修为门槛、危险来源、资源形态等；
- 赵升必须用九世百艺之一解决第一个实体障碍。

结果：确认这里不是普通渡路，而是被长期修补过的旧设施。

### 新70：拆过一次

- 找到人为拆解、重铸、改接的痕迹；
- 赵升通过炼器/阵法判断这些痕迹年代久远且并非天然破损；
- 不直接说“有人拆了雷帝辟劫令”，只能先确认“高阶旧器被拆后接入路网”。

结果：三万年历史线第一次拿到物证。

### 新71：旧锚反噬

- 遗迹发生真实危险，不能只靠推理；
- 可由倒果外溢、路段错位、劫压、空间撕裂等已允许机制构成；
- 赵升至少一次判断错误或付出代价；
- 戚武/姚絮等本地人展示低阶人在这种环境里如何活，不当解说员。

结果：赵升确认强行深入会让旧路进一步恶化。

### 新72：第一次碰到它

- 赵升第一次直接接触雷帝辟劫令残体的外围/附属部件/核心投影；
- 旧物应有明确的九世识别反应，但不能全部恢复记忆和功能；
- 他发现残体已经成为路网结构的一部分，强取会立刻影响通行。

结果：目标从“找遗物”变成“如何拿回已经成为别人根基的遗物”。

### 新73：抢不到的自己的东西【Gate 3】

- 裴燎利用外围锚点继续抽取或转嫁，制造一次真实争夺；
- 赵升即使有能力碰到残体，也因为会导致过路者/路段承压而主动停手；
- 必须拿到第一份可带走实体证据：碎屑、断纹、旧铭痕、功能残片等，具体形态施工时定，但不能只是纸面情报。

不可逆结果：赵升第一次“找到自己的东西却不能直接拿走”。

Gate 3 验收：
1. 是否完成了完整探险链，而不是到地方听设定；
2. 百艺是否至少两项真正推动剧情；
3. 是否出现实体证据；
4. “遗产已成为后世根基”是否由事实成立。

# 五、批次C：新74—78「遗产已经成为别人的根基」

## 批次目标

把法宝回收从“所有权”问题升级为“替代结构”问题：赵升必须先让路网有别的承重方式，才能拿回残体。

## 五章功能位

### 新74：欠命坊不是衙门

- 韩缄正式进入主线；
- 欠命坊要用一场真实交易证明它为什么存在：有人靠债换来生路，也有人因此承担长期代价；
- 韩缄可拒绝赵升、提高代价或冻结某段通路，但原因必须是现实风险而非官僚刁难。

结果：赵升获得旧路历史成本/材料来源/替代结构所需资源中的一项关键条件。

### 新75：不能拔

- 赵升确认若直接拔走残体，某一现实路段会崩；
- 至少一个本地人物明确反对赵升立即取物，且理由成立；
- 赵升不靠身份压人，承认这个约束。

结果：强取方案被正式废弃。

### 新76：百艺重开

- 赵升开始设计替代结构；
- 必须真正调用第九世的炼器/阵法/材料判断等能力，不写成抽象“他算了算”；
- 第十世洞天提供一个第九世没有的变量，使方案不是单纯复刻旧技术。

结果：形成可试验的替代结构原型。

### 新77：各走各的

- 闻野、宁拙、姚絮、戚武至少三人各自作一个与自身利益有关的决定；
- 其中至少一人的选择不符合赵升最优方案；
- 不要求他们理解赵升全部历史。

结果：人物线从“跟着赵升做任务”变成各自承担后果。

### 新78：替上去【Gate 4】

- 替代结构第一次接上旧路；
- 能短时承载，但不能宣布成功；
- 暴露一个只有真正外压才能验证的缺陷；
- 裴燎察觉赵升将要摆脱旧锚控制，准备最后争夺。

不可逆结果：赵升第一次真正创造出“第九世百艺 + 第十世洞天”的混合结构。

Gate 4 验收：
1. 韩缄是否仍是有逻辑的利益方；
2. 替代结构是否真实依赖百艺和洞天，而非一句话解决；
3. 人物是否各有自主选择；
4. 是否已经自然准备好最后五章的大险局。

# 六、批次D：新79—83「夺回核心，太乙门开」

## 批次目标

让旧路真正承压，验证替代结构，完成卷七最大险局；赵升先保路再夺回残体核心，并从其转移痕迹中得到太乙灵界方向。

## 五章功能位

### 新79：路先塌

- 裴燎发动最后一轮抽取/争夺；
- 旧路出现真实崩坏，必须有人受困/货损/路线断裂等可见后果；
- 替代结构被迫提前上阵。

结果：最终争夺从“抢法宝”升级为“先保住路”。

### 新80：先保人

- 赵升优先维持路网与过路者生存，不立即追裴燎；
- 洞天承受第一次真正外部劫压/异常结果冲击；
- 必须留下损耗，不能无伤。

结果：洞天出现“抗劫雏形”的第一份实证，但明确不是洞天第三转完成。

### 新81：收果人的底

- 真正战斗/追逐进入高潮；
- 赵升利用此前已验证的旧锚规律反制裴燎；
- 裴燎的能力边界被揭示一部分：其强处依赖旧锚网络，而非无限转嫁。

结果：裴燎失去继续掌控四会渡旧锚的核心条件。

### 新82：雷令归手

- 赵升接回雷帝辟劫令残体核心部位；
- 不能完整恢复成全盛法宝；
- 现场必须兑现至少两项：实质能力/结构参考、旧史物证、路线钥匙；
- 同时确认这只是被拆散遗产的一部分。

结果：本卷实体硬收获到账。

### 新83：太乙方向【卷七总Gate】

- 通过残体断口、旧锚接法、转移痕迹或等价物证，确认更重要的一批旧世遗产曾流向太乙灵界；
- 可把赵氏/太清线第一次重新提到前台，但不要直接安排旧人出来接驾；
- 闻野决定留在四会渡/残渡处理自己的路；宁拙、姚絮、戚武、韩缄各回本地生态；
- 赵升轻装离开。

卷末不可逆结果：**赵升非去太乙关不可。**

卷七总Gate：
1. 是否真正拿回雷帝辟劫令残体核心，而非又只拿情报；
2. 是否形成了洞天“抗劫雏形”但未越级完成第三转；
3. 是否给出九世遗产被人为拆分的实体证据；
4. 是否自然清掉四会渡本地班底；
5. 是否让太乙成为因果必然，而不是总纲指定地点；
6. 卷内是否至少完成一次完整探险、一次真实战斗、一次百艺发挥、一次实体收获、一次人物自主分路。

# 八、修行与法宝约束

- 卷七不再用“仙体醒X成”作为主要爽点；如有醒度变化只能作为险局后果之一，不替代结构成长。
- 本卷真正修行推进是：**洞天第一次获得抗劫结构经验**。
- “抗劫雏形”≠“洞天第三转抗劫完成”。真正第三转留给更高层地图再次验证。
- 雷帝辟劫令残体必须是残损状态；不得一回收就恢复全盛仙器威能。
- 残体至少承担两种功能：洞天结构参考 + 三万年历史证据；若自然可行，可再承担下一地图钥匙。
- 不在卷七同时回收五方五行洞天镜、十五万里旧洞天或五雷钺。

# 九、统一禁区

- 不再把公开账、正册、发保、资格冻结写成整卷胜负手。
- 倒果渡最多承担一个核心副本段，不连续十几章“发现规则—验证规则—反证规则”。
- 不让任何人物充当全知规则说明书。
- 不补闻野隐藏境界、仙器、血脉或与赵升同层证明。
- 不让裴燎靠嘴赢；所有胜负落到路、锚、伤、物、通行和真实损失上。
- 不把韩缄写成愚蠢恶吏；他的秩序必须真实救过人。
- 不让赵升以“这是我的法宝”为理由直接拿走残体而无视后世依赖。
- 不让卷末只得到纸面情报。
- 不提前解释三万年幕后主使、道祖全貌或雷帝辟劫令完整历史。
- 未登记的新具名人物、地名、势力、法宝先登记再入正文。

# 十、写手自由区

每章保留约20%—30%真实自由度。写手可自行决定：

- 场景从哪里切入；
- 同一组节拍如何排序；
- 无名来客/脚户的临场反应；
- 已有地点中的普通器物、声响、天气与生活细节；
- 对话攻防与人物沉默；
- 不形成长期剧情债的小失败、小误会和场内闭环。

施工单锁定的是：**本章因果功能、选择者、代价、不可逆结果、下一章接口**。只要这五项不变，写手可以用更自然的等效场景完成。
