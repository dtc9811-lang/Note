# 可迭代配角检查

可迭代配角不是长期跟班，也不是隔卷回来递一次消息的人。角色离开赵升视野后，仍要沿自己的目标生活；再次出现时，身份、能力、信念、关系、代价五项中至少两项已经改变。

## 一、登记卡

| 项目 | 必须回答 |
|---|---|
| 初始位置 | 他第一次进入主线时拥有什么身份、资源和限制？ |
| 私人目标 | 不考虑赵升，他想守住、得到、证明或摆脱什么？ |
| 第一选择 | 第一次违背赵升预期或拒绝赵升安排的决定是什么？ |
| 离场任务 | 离开镜头后，他具体去做什么，而非笼统“发展势力”？ |
| 异地结果 | 下次出现前，他成功、失败或付出了什么代价？ |
| 第二状态 | 身份、能力、信念、关系、代价中哪两项发生变化？ |
| 回归冲突 | 新状态为何会帮助赵升一部分，同时妨碍赵升另一部分？ |
| 最终选择 | 终局时他以自己的立场作何选择；是否允许拒绝赵升？ |
| 寿元边界 | 他能否活到下一次回归；不能时由谁、何物或哪项制度承接？ |

## 二、一次有效迭代

一次完整迭代遵循：

1. 在场时种下私人目标与未解矛盾；
2. 作出一次自主选择后离场；
3. 离场期间产生可验证的成功、失败和代价；
4. 带着改变后的身份或立场回归；
5. 回归后制造新的关系，不重复第一次的功能；
6. 再次离场或完成终局选择。

只增加修为、职位或装备不算有效迭代。必须同时改变至少一项关系或信念。

## 三、数量与频率

- 全书同一阶段维护的活跃迭代配角不超过 8 人。
- 每卷重点推进 2 人，允许 1 名旧角色短暂回归；其余只留后果，不抢主线。
- 同一角色两次有效出场之间原则上间隔 10 章以上，除非正处于其主场卷。
- 每次回归必须完成一件当前状态才做得到的事，并暴露一个新限制。
- 连续两次不能以递消息、送资源、替赵升背书作为主要功能。

## 四、与长生主角的边界

- 低阶人物通过职责、制度、后继者和远端节点迭代，不靠赵升提升资质追赶。
- 时间跨度超过寿元时，必须写衰老、死亡、传承中断或接棒，不让人物冻结年龄。
- 赵升可以改变人物的起点，不能替人物完成离场期间的成长。
- 配角最终可以拒绝接入轮回、只答应一部分或选择不同路径；其价值不以服从赵升衡量。

## 五、验收红线

出现以下任一情况，视为伪迭代：

- 换了职位，仍只做原来的记账、顶嘴、递话或解释工作；
- 离场后没有独立事件，回归时能力凭空增加；
- 每次回归都立刻认同赵升；
- 为保留熟人临时补高资质、隐藏血脉或无代价延寿；
- 人物失败没有损失，成功没有带来新的责任；
- 新角色只是旧角色的同功能替身。
