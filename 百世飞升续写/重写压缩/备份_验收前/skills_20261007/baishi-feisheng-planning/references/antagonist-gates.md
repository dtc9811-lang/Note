# 对手梯度检查

规划反派、竞争者、制度对手或规则环境时使用。目标是让每个阶段迫使赵升展示新的能力，并让上一阶段的人物按时退出。

## 一、登记卡

每个主要对手首次登记时必须回答：

| 项 | 必须写清 |
|---|---|
| 所属地图 | 此人为什么只在这里成立？ |
| 敌对类型 | 主动害人的敌人、利益竞争者、制度执行者，三者不可混写 |
| 修为/权限 | 凭什么能威胁当前赵升？ |
| 私欲 | 不考虑赵升，此人本来要什么？ |
| 第一胜 | 登场后先从赵升手里夺走、封住或破坏什么？ |
| 旧解法失效 | 为什么对账、立规矩、躲进洞天或纯武力不能直接解决？ |
| 逼出的成长 | 赵升必须新增或真正兑现哪项能力？ |
| 硬限制 | 对手有什么不能越过的边界，避免无限加码？ |
| 不可逆结局 | 死亡、失去权位/锚点/资源、主动分路或赢走一项东西，必须选定一种 |
| 遗留后果 | 人退出后留下什么变化？不能让本人继续追图 |

缺少“第一胜”“逼出的成长”“不可逆结局”任一项，不得担任一卷主对手。

## 二、三层对抗

每个主要地图分别设置：

1. **敌对者**：明知会伤人仍主动出手，承担真实战斗和失败风险。
2. **利益对手**：逻辑可以成立，但目标与赵升冲突；可以谈，也必须让赵升付代价。
3. **规则环境**：仙墟、归潮、因果、法则压力、世界残缺等没有人格的危险。

三层不能由同一个“讲道理的官”包办。只有制度争论而没有敌对者，读感会继续停在办文书。

## 三、轮换与退出

- 一个主对手原则上只负责一个主要地图，活跃期 8—15 章。
- 离开地图时必须结清其个人冲突。制度或后果可以延续，本人不尾随。
- 旧对手跨卷回归最多一场，并且必须带来身份、力量或代价变化；不得降级成重复找茬的小头目。
- 已死人物不复活；已失去权位的人不能换个衙门继续同一套阻拦。
- 长线终局敌人必须提前以痕迹、代理人或损失播种，不能在最后一卷凭空出现。

## 四、成长核对

每击败或越过一个主对手，读者必须能指出赵升与此前相比多了什么：

- 新的可见能力或控制精度；
- 新的世界权限或路网层级；
- 一次只有九世经验才能完成的判断；
- 一项永久损失、责任或承诺；
- 一次真正失败后改变的方法。

若只是在新地点再次查账、公开规则、让围观者认同赵升，不算完成对手梯度。
