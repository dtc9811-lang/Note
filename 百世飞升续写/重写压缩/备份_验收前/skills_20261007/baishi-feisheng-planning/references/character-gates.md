# 人物承载与轮换检查

在决定角色继续同行、暂离、回归或退场前，逐项查证。答案必须来自正文、当前设定或已拍板的 DevTrace decision；“以后可以补”不算依据。

## 一、事实卡

| 项目 | 必须回答 |
|---|---|
| 身份与阶段 | 此人现在是谁，处于哪一段人生/职责？ |
| 修为与资质 | 明示境界、资质、特殊能力是什么？没有写明就写“未知”，不可默认很强。 |
| 寿元与时间 | 下一段剧情跨度是多少？此人能否自然活到？ |
| 环境耐受 | 下一地图的常态风险是否超出其承受上限？ |
| 私欲 | 不考虑赵升，此人最想得到或守住什么？ |
| 筹码 | 没有赵升时，此人靠什么生存、交易和行动？ |
| 自主选择 | 本卷会作出哪一个赵升没有替他决定的选择？ |
| 关系变化 | 与赵升的关系会因何改变，而非只维持“忠诚/帮忙”？ |
| 退出方式 | 在哪一阶段因何留下、分路、死亡、闭关或转远端？ |
| 回归条件 | 回归时带来什么独立完成的结果？只递消息不算。 |

## 二、继续同行判定

只有同时满足下列条件，才能安排长期近身同行：

1. **活得了**：修为、寿元和环境耐受有明确依据。
2. **跟得上**：移动方式、战斗风险和界域规则不会让主角长期背负保护成本。
3. **有自己的事**：其目标与下一地图存在直接联系，不是“主角去哪我去哪”。
4. **不可替代但不过度便利**：能提供具体筹码，同时不能沦为解释、记账、递话工具。
5. **会发生变化**：同行将迫使其作选择、付代价或改变关系。
6. **已经安排退出点**：默认同行不超过 25 章或一个半卷；超过需有新的、已成立的理由。

任何一项失败，都优先设计合理退出。短程护送要写清起点、终点和代价，不得自动续期。

## 三、新地图人物预算

- 前 5 章至少 3 名新具名角色：本地人、利益对手、同行/向导各一，功能不能重叠。
- 离开地图时，近身班底至少退出一半。
- 连续 5 章不能总是同一组三人处理同一类问题。
- 老人物回归必须带来在别处形成的结果、立场或代价。
- 新人物登记时就写私欲、筹码、自主选择、退出方式；没有这四项，只能作为无名场景角色。

## 四、长生主角专项检查

赵升具有长生真仙底蕴。凡人或低阶修士与他长期同行时，必须额外回答：

- 为何当前阶段赵升确实需要此人的近身价值？
- 这种价值为何不能由本地角色或远端节点承担？
- 赵升为保护此人承担了什么可见成本？
- 境界拉开后此人何时退出？
- 时间跨越后，衰老、寿尽和死亡怎样真实发生？

答不出时，让人物留在其最能产生后果的地方。留守、衰老和死亡都可以完成角色价值，不必把熟人带到终局。

## 五、反便利设定

下列理由不能单独支撑长期同行：

- 会记账、熟悉主角、读者已经认识
- 主角可以随手保护
- 放进洞天就没有危险
- 临时发现隐藏血脉或特殊体质
- 被真仙点化后短期跨越多个大境界
- 作者以后可能用得上

若确需改变人物资质或命运，必须把它设计成有前置、代价、失败可能和长期后果的独立剧情，先经用户/DevTrace decision 拍板。
