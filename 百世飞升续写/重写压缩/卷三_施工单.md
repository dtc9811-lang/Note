## 二、逐章施工单

### 乙：新 13—19

#### 新 13　来路（旧 31、32、33）
- **事件**：西门外十步起一条青石板路，缝里没草没沙，中间一道被走出来的亮；路基是**铺**的，垒得熟但不精 → 十几双泥脚印全朝里，最前面一双两脚并拢停在十步外，有一双很小；赵升拉绳圈起来"绳内禁入"，让赵茂守夜 → 第二天多了三里零七丈（赵素量），坊市量出三里零九丈，两栏并排都留着 → 午后接缝处石板顶上来，赵九满拖回一个量接缝的散修，手背擦破，先医后问 → 坊市分堵路派、通路派 → 堵路派连夜挖掉三丈，第二天被**重新铺**了一遍（新补那段颜色浅一层）→ 第二夜换手法（撬、搬、码、掏、接、倒、搭、压），第二天连他们搬走的石板也一并收走。
- **必留**："挖一丈，它铺一百五十丈"；"挖的人手会累，铺的不会"；"比的是谁更耐心"；第一批私自沿路进去的人还没回来。
- **章末**：私自进去的那批人还没回来。

#### 新 14　从外往里（旧 34、35、36、37）
- **事件**：那十七个人背着死区深处的遗物回来，绝品价从三百崩到九十，赵氏一天只做成两单 → 赵升改规矩：只收无人认领、无法鉴定之物 → 走过这条路的人**走路靠右**（上过路四人全偏，没上过的三人偏两个，"半里就偏"），坊市两家摊子挪到右边 → 翻废物：卫老那三块里有一块**路引**，背面刻"持此引者，无归路准通，长照收"，石料与路面同一种（口径 AC）；另一箱里有一块**温**的残片 → 纸上推温残片，它往东沉，沉出纸外 → 赵升单独去坊市：太清宗外门铺子里一个二十出头的青袍（先看人的手，再看手边的东西），两人隔门槛看了一息，不知其名；一个杂货摊上买到一块**凉**的雷器碎片（纹是雷帝辟劫令上的纹）；一个商号的人要试赵氏斤两，赵升隔着神识看出对方右肩旧伤，指点赵九满闪左、铁钎撞膝弯 → 赵升在卖水的老摊子旁当众说："**那条路上的脚印，是从外面往里走的。**"通路派当晚撤回三支队伍 → 夜里凉碎片也往东沉，偏南半寸，两个点连成线，线尽头写"东"。
- **必留**：凉碎片物貌原句（旧 37："不长，拇指大，黑里透青，边上有一道烧过的痕。……凉的底下有一线东西在动，像很远的雷声"——意思必须一致，文字可重写）；两块碎片分开装，一温一凉。
- **篇幅**：本章事件最多，崩价一段压到 400 字，靠右一段 500 字，坊市一段写足。
- **口径**：AC、AF。
- **章末**：纸上两个点连成的线，尽头一个"东"字。

#### 新 15　图正（旧 38、39、40、41）
- **事件**：赵升让西门外四只铁灯架夜里也点着，坊市来人问"是不是不按规矩收灯"，"出事我担"→ 走路时数出二百三十七步处一道缝宽半指、底下摸不着 → 天亮路**拐弯**，最近那十几丈转向无归渡西门 → 堵路派带着火油来要关门，通路派来要开门，四批人都得先进无归渡的门 → 赵长庚："接了路的人，就没有中立这一说" → 傍晚步纲君到（葬仙墟外围路线登记处图正，正九品），不进废渡的门，隔门槛谈：纳入正册、发引、组远征队（登记处三十、赤铢二十、散修十、赵氏三）→ 随从木牌四格，赵素用绳量了一遍对上 → 正册规矩，赵升问三个问题：**注销是自己申请还是上头核查？注销后名下路网条目能不能转挂？转挂后路认原来的名字还是新名字？**（"路认地方，不认名字"）→ 步纲君临走："这一本往上，还有册子……仙籍，仙职。我这本正册是最下一格。"
- **必留**：三个问题原样；"正册管的是人……管谁有资格走在上面"；"灯倒是真的在点"。
- **口径**：AF、AG。
- **章末**：步纲君用袖子抹了一把灯架，"灯倒是真的在点。"

#### 新 16　走得越齐（旧 42、43、44、45）
- **事件**：名单六十三人（口径 X），赵氏三个：赵升、赵九满、赵茂；赵素不占名额随队；窦让出双倍钱要走中段，赵升"按名单走"；卫老修士拄木杖来说"靠右是错的，两条路并到一起时，走在最边上的人先下去"，见过三回（活两个、一个、零个）→ 出发前夜赵升去库房看了一刻钟棺船，没开棺；夜里画符九张成三张：两火一困，都在他怀里 → 出发：路不留脚印；来路悄悄换了方向（木尺为证）→ 步纲君下令整齐走；赵升数出漂移频率：散着走三里一漂，齐着走不到两里一漂 → 正册队右起第三个、商队右起第五个，压齐时脚下带出半步，人没了，旗杆倒在石板上，袋子留在路上 → 步纲君："走得更整齐一些"；赵升："刚才那两个人，是对齐死的。" → 赵升在走动中把神魂贴进路面，听出路的**呼吸**：吸时实，呼时松，隔三息；数到第四个"松"时把赵茂往路心拉了半步（口径 V，不写数字）→ 代价：眼睛干到睁不开，湿布敷一夜。
- **必留**："越整齐，它动得越快"；步纲君在两个名字底下注"路上失踪"。
- **章末**：赵升闭着眼数营地里的脚步，数到五十停下。

#### 新 17　我原先想错了（旧 46、47、48、49）
- **事件**：三天记录（偏四回、七回、九回），三条线交在无归渡地基 → 第一版模型："残天在找它自己的旧节点，它认无归渡那片地基，因为那里有长照留下来的东西"→ 连夜折返，赵长庚守灯，西侧墙根下挖出巴掌大的青石（旧法阵核心），打碎分丢 → 回营，路停两天 → 第三天坊市方向地面裂开，路从坊市中心广场顶上来，更乱更急，有人圈绳收过路钱、有人拿尺量 → 赵升回营当众说：**"我原先想错了。"** 它认的不是地方，是运营的状态 → 第二版："路网在找一个还在履行渡口职能的地方——有灯，有门，有人在收，有人在送。它看不见名字，看不见册子。" **"路不认正册。"** → 能走的三十八人、走不动的二十三人（合计六十一），窦让把带不走的货压在平石上（"压两块"）→ 赵升带赵九满、赵茂往路的深处走，找它从哪来。
- **必留**："我原先想错了"原句；"路不认正册"原句。
- **章末**：赵茂走在最外侧，那只手伸在外面。

#### 新 18　古驿（旧 50、51、52、53）
- **事件**：路接上第一个节点——古驿，没有人，碗里的水一直热（焐着它的是这座驿里剩下的一点本源仙炁）；过客册；铺位不吃力、床脚有灯槽、灯柱卡的是法器灯座——这不是驿站，是真仙时代的渡口，这种路叫**古渡网** → 二十九人住下（正册队十一、赤铢十二、散修六），卫老没住下 → 第二天住下的人名字出现在过客册上，去处有的写家、有的写"无归渡"——"路会优先把他们送往册子上写的地方" → 步纲君选宿营地有规律：他想把接口引到自家渡口 → 支线洼地里一团吃法力的东西，赵九满铁钎穿过去手白了，赵升用掉一张火符，它不上路 → 挤：看不见的东西擦肩而过，左边空出来没人敢走，夜里正册队引首和散修为落脚地动手，一掌把散修推得半只脚悬在路沿外 → 左边灰积得比右边深一倍。
- **必留**："古渡网"；"这二十九个名字，往后盯"；赵茂那只手褐斑蔓进小臂。
- **篇幅**：古驿和过客册合写，写足；洼地一段不超过 600 字。
- **章末**："左边空着，明天还空着吗。""空着。它要走左边，就让它走。"

#### 新 19　并线（旧 54）【H 档，扩写】
- **事件**：天亮路面嵌进另一种灰白石板，短、厚、凿边——"有第二条路接上来了"→ 半个时辰后，脚步声穿过队伍：赵九满停了，声音没停 → 赵茂那只手伸向右半边："一直在过。数不清。" → 步纲君下令**结阵**，赵升喊"撤阵！靠右！让开路心！"被阵光压下去一半 → 阵旗罩住的那块青石连同上面十九个人一息之内**换**成了灰白石板，旗还立着 → "阵不是护身，阵是**占路**……它们不绕，它们把挡路的东西换掉" → 赵九满拽人、打掉抓阵旗的手 → "三个人一排，贴右边，前后隔两步，不许并排！"
- **必留**：阵旗立在新石板上、底下什么都没有的画面；"路只有那么宽。"
- **章末**："路只有那么宽。"（原句，一字不改）

### 丙：新 20—26

#### 新 20　折损（旧 55、56）【H 档】
- **开场状态**：见第三节。
- **事件**：六个时辰，死四十三个（口径 X）。三种死法：抱着阵不撤的（法力早空了，宁可抱着阵死）；飞起来的（离开路面就没了——路两边没有"下面"）；被挤出去的（最多）→ 窦让伸手够被挤到路沿外的七八个储物袋，袋子回来了，**左小臂没回来**，断口齐整不流血 → 卫老修士松开赵九满，把一个赤铢伙计推回路心，自己的脚在路沿上磨了半息："**账我记着了。**" → 酉时并线尾，路窄回来，活下来十九个 → 赵九满："我就照这三条做的……火把不许灭，灯不熄嘛；不许结阵不许罩，门不锁嘛；谁掉出去先拉回来，先医后问嘛。"那个被卫老推回来的伙计："按无归渡的规矩来。" → 赵升坐在路沿，法力空了，仙炁也用过（顶住一块要换走的路面保住三人）；用神魂贴路，回声像针，仙体被撑开——**一成八分**；当场探出前方接缝两处虚的（左离路心三步，右离路沿两步）；代价：耳朵里嗡，三天，听人说话隔一层水。
- **必留**："账我记着了。""按无归渡的规矩来。"
- **章末**：赵茂摊开黑到小臂的那只手，手心一道新白印；"把袖子扎紧。"

#### 新 21　除名（旧 57、58、59、60、61）
- **事件**：数另一批脚印（脚掌压得比脚跟深，三指半宽），两个算法差一成，留小的那个数，不说出来；脚尖全朝前 → 问方向：赵茂"朝前"；窦让说并线时脸贴地看见路基底下有脚在走；那些东西在往**渡口**去，不是攻击，是赶路 → 路边摆五块石头做记号 → 步纲君带三个引首连夜回自家渡口，定路发引，坊市公告"主干接口设于图正步纲君渡口"，存档编号空着 → 第二天除名文书：无归渡"待批"期间带路资质不在正册覆盖范围 → 带路一栏空了六天，定钱和图钱分开记 → 族里吵，赵敕说去找图正谈，赵长庚不说话，赵升不进屋："他们自己吵，吵出来的才是他们的" → 断堤上坐一下午，傍晚："**把灯都点上。**"所有灯，一盏也不许灭。
- **必留**："等它们走到，就有了。"（步纲君问哪个渡口时的回答）；赵长庚隔门板那句"例不当饭吃，人还要姓赵。"
- **篇幅**：五章压一章，脚印一段 500 字、除名一段 700 字、点灯一段写足。
- **口径**：U。
- **章末**：赵升把账册翻回三条规矩那一页，看完放回去。

#### 新 22　注销（旧 62、63、64）
- **事件**：收人第一天（口径 Y）：步纲君渡口方向来了十一个，手里捏着他发的正册路引，"他那边现在没有灯"；廊下有人把铺盖摊在过道上，赵素一句"廊下是过道，不是铺位"→ 赵升写注销文书三段（第三段"地址、设施、人员维持现状"是赵素校对时指出要加的）→ 步纲君接过看了两遍，手指压在第三段："这一段，多余。""不多余。注销的是待批资格，不是地方。"盖印，"步纲君渡口旗下，歇脚棚，无归" → 赵升问"上头的册，谁在管？"步纲君不答 → 歇脚棚四项义务 → "赵堂主，你现在在正册上，什么也不是了。" → 改姓派要夺权、要合并；"撑到撑不住" → 傍晚，路网深处第一声潮响：低沉、均匀、带节奏，像成千上万只脚。
- **必留**：注销文书三段；"什么也不是了"原句。
- **章末**：赵升在堤上站起来。

#### 新 23　归潮（旧 65、66、67）【H 档】
- **事件**：三天，门开着收人，渡里越来越满（口径 Y）→ 前厅让出一丈宽的道，西门到东侧门一百四十七步，三级台阶搭门板 → 西门推到贴墙（一丈三尺），东侧门也开（九尺），赵长庚抽了东侧门门栓 → 改姓派有人要关西门，赵九满"谁关门，从这儿过" → 子时三刻，脚步声到主干，雾开：第一排七八个，衣裳旧，有人挑担子，一个年轻人扶着老妇人，**最前面那个提着一盏灭了的灯**——赵升认出来：宙光残层里桥上错身而过的就是这一队 → 那些脸上没有恨，没有饿，只是在**赶路** → 走到西门外三十丈的岔口，全部**拐向右边**，往三十里外步纲君的渡口去 → 赵素："步纲君那边，门是锁的。"
- **必留**："路只有那么宽。三十里外，有一扇锁着的门。"
- **章末**：上面这句。

#### 新 24　敲门（旧 68、69、70）【H 档】
- **事件**：寅时赵敕要关门，赵长庚站到门槛上："三千年前我赌过一回……这回我认……要关门，从我这儿过。"赵敕退开，带改姓两班去后院抬水抬人 → 卯时，岔口右边那条新路被一块块**拆**开，往左边铺，一直铺到西门外**十步** → 堤开始往下坐，赵升双手按门框，用仙体托住三万年的旧堤，鼻血滴在门框上（口径 W）→ 归客从七盏灯下一排排穿过前厅，从东侧门走进死区；提灯的那个抬头看了一眼门额、一眼灯 → 过完，赵升靠着门框，神魂贴进门框补空了的仙体："一成八分稳住了"（口径 V），探出门框左侧第三块石头暗裂、右侧门楣榫头松——还有底下那种"什么都没有的空"，方向东 → 巳时，窦让（左袖空了半截）和步纲君（身边只剩一个引首）等十三人从被拆空的黄土沟里走回来 → 赵九满要关门，赵升让开："进来" → 步纲君看见前厅地上躺着那十一个（口径 Z）→ "按册子上的规矩，这儿是我的地方。""按册子上的规矩，是……所以你来自己的地方，还站在门外做什么？" → 步纲君迈过门槛；"先医后问……记账。" → 窦让（口径 AA）最后一个进门，挽起右袖帮着按住伤者的腿。
- **必留**："所以你来自己的地方，还站在门外做什么？"原句。
- **篇幅**：三段各 1000 字左右。
- **章末**：窦让两手压下去，按住那个伤者的腿。

#### 新 25　残图（旧 71、72、73、74、75）
- **事件**：一千三百多人挤在四百人的地方，有人喊关门 → 赵升拆前厅中间两丈隔墙，打通西门到东侧门；三个壮汉占着位置不让，撬棍砸在赵九满铁钎上，钎头顿在对方脚前三寸；"路是用来走人的，不是用来住人的" → 东侧门取下门扇，第一批人自己排队从东侧门走出去 → 赵茂在堤基外侧发现**贴在石头上的东西**：被挤下路基、上不来也没死透；一个年轻族人认出其中一团的衣角——本家远亲 → 残图（口径 AB）：十几个节点，多数虚线，东端"长照"一圈被**实线重描过**，"有人记着它，而且不是三万年前记的" → 步纲君用路线登记处三万年前的运营档案抄本换出路；三天后两匣二十四卷送到 → 长照条目：历任渡正，最后一行姓赵、单名、"天倾，渡毁，人佚"；渡毁后的接办记录，另一种墨：**"赵氏遣人来取渡档副本，留名二人：玄靖。宏运。"** → 怀里温残片烫了一下 → 夜里以路引为坐标推门：看见一条活的街，石屋挂灯，街口木牌"长照"，案后有人在写过客册，看不见脸；代价：指尖麻、甲下渗血。
- **删**：旧 76 七个名字对过客册（口径 AD，挪到新 26）。
- **必留**："玄靖。宏运。"原字；"他倒下之前，长照还是活的。"
- **章末**：他只确定一件事：他倒下之前，长照还是活的。

#### 新 26　不能关门（旧 76、77、78）【H 档】
- **事件**：账室桌上摆四样：七张殓单、过客册、残图、旧路引（口径 AE）→ 第一件：七个名字全在过客册第三百一十七到三百二十页，同一天登记，去处都是"长照"；过客册三百二十页往后整册空白 → 第二件：殓单是远行人自备的，死期一栏活着时该空着——七张都填了，同一天 → 第三件：名姓籍贯去处七种笔迹，**死期一栏是同一只手** → 残图东端长照那一点重描过；"三万年里这条路没往这边长过一寸，为什么是现在？"赵素："**因为灯。**" → 十步外那双脚印三个月没被踩乱："第一个到家的人……他在等门口那十步。"赵素："那走出去的人，是去哪了？""不知道。" → 三天后族会：赵敕算账"这是一份没有数的债"；赵升不改三条，要走的给路引、按人头分东西；改姓派九人走、二十一人留（口径 AG），赵敕留下 → 赵升看三样文书**最后一格**：路引、过客册、殓单，栏名都是"**归处**"，三万年没人填过；拿生死断笔往过客册"归处"落笔，纸上什么也没留下——他连自己的名都没地方落 → 问遍渡里一千多人，二十几个地方都有这一栏，没人填过 → 残图十几个节点旁都画着同一个记号：一个圈，右上角没封口 → 傍晚，赵升搬第一块石板，把西门外那十步铺上；赵九满、赵茂（胸口顶着石板）、赵素、赵长庚、赵敕、窦让单手，天黑铺完，缝不齐，接上了 → 夜里堤上：法力从仙体底下抽成一线，掌心化出水、木、火三色——**混元仙体醒两成**；一线法力按进堤石，裂一道不到一分的细纹：够接一件筑基的灵器，不够动一个金丹 → 门额是一片空石面，赵九满问要不要刻回"长照"："我还不知道那两个字是谁刻的，也不知道他答不答应。"
- **必留**："归处"二字；"因为灯。"；"第一个到家的人"；棺船留在堤上没拆。
- **篇幅**：本章是卷三收尾，可到 3,500 字上限。
- **章末**：赵升跨过门槛，没有关门。

## 三、开场状态（交界处用）

**乙开写新 13 前**：新 12 末——潮在后半夜从渡口前三里分两股绕过去；渡口一夜点了三百多盏灯；东边死区深处亮了一下又灭了；赵升从棺船取来一张殓单，看过，折好收进怀里；天没亮，赵茂拍门报"西门外多了一条路"。窦让一行一百四十人当夜宿在渡口东边空地，天亮后拿着路引离开。赵茂右手裹布（卷一口径 M）。劫户点名印在赵升手里。赵升此时一成半，三天内不能再引仙炁。

**丙开写新 20 前**：新 19 末——并线正在进行，阵旗罩住的那块路面连同十九人被换走，赵升喊出"三个人一排，贴右边"，脚步声不停，"路只有那么宽"。此时路上活人：六十一人减去被换走的十九人，余四十二人，另加随队的赵素（不在名单）。赵升怀里还剩一张火符、一张困符（另一张火符已在古驿洼地用掉）。赵茂右手褐斑已蔓进小臂。卫老修士由赵九满搀着走。窦让双臂完好。
