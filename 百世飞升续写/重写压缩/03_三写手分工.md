## 每个写手开工前必读（按顺序）

1. `01_写手总规则.md`（硬规则、黑名单、验收追加）
2. `正文/新01`—`新05`（样章与已验收稿）
3. 自己那一段的施工单，含全部【口径修正】（卷一口径 A—M 对所有人有效）
4. 自己本章对应的全部旧章 `分章/第NNN章_*.md`

## 每章流程

1. 读施工单本章条目 + 对应旧章全文。
2. 写正文，存 `正文/新NN_章名.md`，第二行 `<!-- 对应旧章：… -->`。
3. 自检：字数、黑名单、必留清单逐条打勾、口径逐条对。
4. DevTrace 在**自己的 Task** 下记 `change`：新章号 / 对应旧章 / 字数 / 必留打勾 / 未决矛盾。更新自己 Task 的 next_step 为下一章。
5. 下一章。

## 不许做的事

- 不改别人负责的章。
- 不自行裁定施工单没写到的旧稿矛盾——写进 change 的"未决矛盾"一栏，照旧稿较晚的那一处先写，等 Claude 裁定。
- 不新增具名人物、地名、势力、法宝。
