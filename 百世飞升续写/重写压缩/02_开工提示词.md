# 开工提示词

DevTrace 已支持工单。给任何 agent 只需一句话：

> **执行 DevTrace 任务 c7e7418b**（写手甲）
> **执行 DevTrace 任务 9c44eca3**（写手乙）
> **执行 DevTrace 任务 1efe9849**（写手丙）

agent 会调用 `start_work` 拿到完整工作包（岗位规则、写手总规则全文、样章路径、本章施工单与口径、旧章清单、输出路径），写完调用 `submit_work`。遇到验收关口会自动停下。

支持 MCP Prompt 的客户端也可以直接选 `execute_task` 并填任务号。

如果某个客户端还没重启、看不到 `start_work`：先重启它的 DevTrace MCP。
