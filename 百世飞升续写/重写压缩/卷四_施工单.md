## 二、逐章施工单

### 甲：新 27—32

#### 新 27　照无归渡例（旧 79、80、81、82）
- **开场状态**：见第三节。
- **事件**：赵素用潮声的节拍、堤下石缝积灰、七盏灯火头的偏向算出"今夜，归潮至"，把夹页递给赵升 → 这一回备了三天：廊下旧箱子搬进库房，西门到东侧门一条直道，药分轻伤、重伤、烫伤三格；赵茂守灯（左手添油，右手裹布垂在身侧）；赵九满交代两个年轻族人"进来的时候靠边。不要挡，不要问，不要摸" → 子时前潮声到，提灭灯的那个第一个从西门进，前厅、后院、堤上全填满 → 最前面那个走到**东侧门门槛外三尺**停住，脸朝东；后面一层层停下 → 一个时辰后探子（口径 AM）挤进来："往西二十里，一夜之间起了一座渡口。"新切石、灯白天不灭、门不落锁，门口木牌五个字：**照无归渡例** → 天没亮赵升步行去（一个多时辰），天亮到：规制对得上，门取下靠在门框旁，木牌墨写，一笔一划，下笔重；他在牌前站了一会儿，**没进门**，往回走 → 回来路上，迎面碰上一串往西去的归客 → 进门，前厅空了一半，另一半还停在东侧门槛外。赵素："卯时动的。这一次到无归渡的人，是上一次的三成。"赵升："不要去动。" → 第二回赵升带赵素去，赵九满留守 → 门板上三行字，字重、墨浸得匀 → 苗七出来（口径 AL）：二十出头，手上是搬货的茧 → "赵堂主。""你认识我。""路网里，你怎么会不认识的。"——赵升认出他就是并线那天说"按无归渡的规矩来"的伙计 → 苗七："那天在路上，活下来的人是照这个来的。不结阵，不放罩，让路，先医后问。我就把它抄在这里了，一个字没改。"账册格式是走过无归渡的人描给他的 → 他问："**我抄错了吗？**" → 赵升在三行字前站了一息（口径 AK：这三条他也是抄来的）："**没抄错。**" → "够，算上我七个，能转起来。"赵素指出账册两处格式问题 → 回渡口，赵九满在西门口骂了几句："凭什么抄规矩。""活下来是因为规矩，不是因为他苗七。" → 赵素把一本贴着"结档"纸签的旧账摊在赵升面前，指着一行，一句不评："他来过。"
- **必留**："照无归渡例"；"我抄错了吗？""没抄错。"；旧账那一行（口径 AL）；赵素"这一次到无归渡的人，是上一次的三成"。
- **删**：旧 79 赶路写景；旧 80 一整天"别扭"的空转（赵敕交易、商户说话一笔带过）；旧 82 赵九满在苗七门外等着（他留守，没去）。
- **口径**：AH、AJ、AK、AL、AM、AN。
- **章末**：赵升看完那一行，把旧账合上；或落在归客那一栏的注"停于东侧门槛外三尺"。二选一。

#### 新 28　撑不住的先死（旧 83、84、85、86）
- **事件**：半个多月里，探子报回三家（赵升在场听）：东侧那家（坊市走货散修开的，规矩是从苗七一个帮手那里传过去的，账还没有）；北边那家（帮手五六个、进退有度、不说来历，账不让看）；支线末端那家（主人亲自接，账主动借给探子带回）→ 赵素看支线末端的账："不是从我们这边描的，是从一个已经描过的版本再描的。偏了两层。""那一层一定存在，而且他把格式传出去至少两份。" → 赵升："北边那家，白天我自己去。" → 天没亮他步行到北边：灯灭，灯座里油面还高——是天亮时专门吹灭的；门挂铜锁，锁面朝外，锁旁小牌两个字：**不锁** → 在门外等了将近一个时辰，没有伤者来；主干上两个人路过，一个慢下来看了看，还是走了 → 他走引路全程，蹲下按石板：有震，活的，**路网认它** → 回渡口，赵九满问了三句，赵升三句"嗯"；赵九满低一个调："**那我们收人，图什么。**"赵升不答 → 过几天赵敕来算账（赵素在，赵九满靠门框）：真收人每月要人手四个两班、三种药、粮；做样子只要灯油、一块牌、一个人——"**一个是另一个的十一倍。**往少里算。" → 东侧那家亏了、主人借过钱；又过几天，东侧那家主人收留的一个腿伤者养好后半夜卷走几袋粮和账册，主人追出去，被打断左臂，关了门（口径 AO）→ 赵九满转了两圈铁钎："咱们灯不熄，门不锁，来者先医后问。然后**撑不住的先死，做好事的先出事**。" → 赵长庚在廊下，拄着弯杖："东侧那家那个人，打他的那个，腿是他接的，用的是他自己的药。""我没说他做错了，我就是说了一遍这件事。"——赵升问他怎么看，他讲当年劫户入墟被当探路队用："我那时候也这么问过……后来我发现我问的不是这件事，我问的是我们这支还值不值得撑下去。""问出答案了吗。""没有，我就撑下去了，然后答案就有了。" → 赵升去苗七那里：灯白天亮着；药箱几格减量，轻伤药换成便宜的，**重伤的没动**："重伤不能省，省了会出事。"帮手走了一个（去镇上扛货了，那边工钱高），剩六个 → 说起东侧那家主人被打，苗七："**我知道这是可能发生的事。并线那天在路上，把我推回去的人，他也知道把自己推出去是可能发生的事。**" → 赵升："账本，下个月我让人送一份新的来，你那边自己核一遍。"

- **事件**：三天后步纲君第二次来，两手捧一只小木匣，放在廊下矮桌上；赵升叫了赵素、赵敕 → 赵素开匣念：**第一条**，渡正由路网正册任命，任期三年，三年后可续任，续任须经正册复核——赵素手指点在"复核"两个字下面 → **第二条**，渡正发出的核查报告、账目公示，须在发出前向正册备案，备案期十日；赵敕："如果正册有异议，然后协商不成，最后谁说了算。""正册。在争议解决前，那份报告不能发出。" → **第三条**：**归潮时刻推算表列为路网官方资料，由渡正整理，纳入正册管理。**赵素念了两遍 → 步纲君：路网安全涉公共利益，统一渠道、避免版本矛盾 → 赵素把纸放回木匣，盖上："**那就不是账了。**账是记的。记什么是我们的事，怎么发是我们的事，什么时候发是我们的事。"步纲君：纳入正册不等于失控，有程序。赵素："**规矩是谁定的。**"步纲君不答，看赵升 → 赵升："**第一条和第二条，可以谈，第三条，谈不了。**" → 步纲君拿回木匣："给你们三天。" → 赵敕："第三条他不会撤的。""嗯。""那就是死局。""嗯。" → 三天里：赵升回来看见赵素把第三条单独抄了一张，贴在账室墙上平视的高度 → 他问："说说。你怎么想的。"赵素取下那张纸：正册第二年改一个推算系数，用新旧数的渡口时刻差几天，有人提前关门——"归潮来了。关着的那家，门被撞开了。**不是因为它改了，是因为它可以被改。**我们的账本，第一批四十份发出去那天，就再也没有主人了。时刻表进正册，从那一天起，它就回来了，回到某个人手里了。" → 三天后步纲君来（口径 BE，这是最后一趟）："商量出来了吗。"赵升："第三条，没有办法接。不是谈判，是没有办法。正册的时刻表是准的，是正册说它准。不是走过来、活着的人说它准。核查机制，核查的是结果——结果出来的时候，人已经没了。""那你觉得，时刻表应该怎么管。""**不管。谁算的谁负责。**对不上，把推算步骤拿出来一步步比。""你这套没人担责任。""有。算错了就负责。各自负各自的责，没有人能拿别人当挡箭牌。" → 步纲君："你们这个，现在路网里一共有多少家在用？""说不准。""账本发出去多少份了。"赵素在账室门口（口径 AZ）："**四百三十七份，直接发出去的。转抄的，算不了。我们知道的，有三十七个地方在抄。**" → "盟主是谁。""没有。""盟，在哪儿登记。""没有登记。""靠什么约束你们的成员。""没有成员。有人用账本，有人不用。" → 斜光在石板上缩 → "那我禁了账本。""禁不了。你知道禁不了。发出去之前，禁得了。发出去了，禁不了。"——"那三十七个地方，我可以让他们停。""停了新的，旧的还在传。" → "你是故意不建组织的。"赵升不答 → 步纲君换手提文书袋："你这个东西，哪天真要上册，正册装不下它。""正册管谁能走。它不管路。"（口径 AR）"所以名分不在我这里。这种名分，要报上去。""报到哪儿？""该报的那一层。" → "**你这不是盟，是一本谁都能捡的破账。**"出西门走了 → 赵升站了一会儿："**够了。**" → 谢青在廊下，进来之前就在，听完了；夹着刚在账室抄的一份账本，页边自己添了小注：挂过太清牌的那几家现在的样子（哪家灯灭、门锁、换了账的式样）→ "宗里那套我不用了。可宗里的东西还在。匠人有七个，丹药有一条线，坊市东头那间铺子，宗里给了我一半。""你想要什么。""我不想要什么。**我想跟着走一段。**不是投你。是——你这条路我暂时看不懂，我想看看它走到哪儿。""看得懂的时候呢。""看得懂的时候，我再决定是跟着走，还是另修一条。"赵升："那你就跟着。账上记着你来过，不用你入什么。" → 他另外把一张单子留给赵素：宗里抄来的，往西那一线的几家渡口，脚程、歇脚棚、废驿都记着（卷五要用） → 谢青说"报上去"他知道一点（口径 BF）：宗里旧文书，头页正册，第二页仙籍，中间一道线，线以上叫上格，线以下叫下格；赵升："步纲君说过，他那本是最下一格。""上格你见过吗？""没见过。宗里见过的人，一个都不在了。" → 谢青出西门，回头看了看七盏灯。
