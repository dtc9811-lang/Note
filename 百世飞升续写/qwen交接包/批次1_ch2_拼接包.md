# 第3章 身世

赵升睁开眼的时候，看见的是一根房梁。

房梁是木头的，旧了，上面有烟熏的痕迹。他躺了一会儿，等这具身体的感觉回来。

身体很小。手脚短，力气薄，骨头还没长开。他试着动了动手指，手指听话，但慢。

这具身体今年十六岁。

赵升在心里算了一下：从结算地到睁开眼，中间隔了多久？他不知道。结算地里没有时间，白光淹上来到现在，可能是一瞬，也可能是十年。

## 样本A：观察型（调查、推理、日常场）

```
赵升也蹲下去。

他先看的不是石板，是缝。

石板缝里没有草。这一带的地是死的，可死了三万年也总会有几根从石头缝里钻出来的东西——葬仙墟里那种灰白色、贴着地长的枯藤，到处都是。西门里面的石阶上就有。

这条路的缝里一根也没有。

缝里也没有沙。

干净得像刚被人扫过。

赵升伸手，摸了摸石板。

凉的。

正常的凉。
```

**要点**：短段。先排除，再确认。不说结论，用具象细节逼出结论。单段常常只有一句。

## 样本B：冲突型（对峙、谈判、翻脸场）

```
“赵堂主。”他开口，“痛快点。开个价。”

赵升说：“和前面一样。三条。”

“我不要一样。”窦让往前半步，“我一百四十人，七车货，一夜之内全要走。我出十万仙晶，买一条最稳的路，现在就走。”

排队的人群动了一下。

窦让笑了：“二十万。”

“不是钱的事。”
```
