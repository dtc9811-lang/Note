# 第64章 注销

文书是他自己写的，写了两遍，第一遍写错了一行，第二遍写完，拿给赵素校对了一遍，没有问题。

文书的内容分三段。

第一段：申请方无归渡，申报人赵升，申请注销无归渡的正册待批资格，理由是渡口暂时无力承担正式带路业务的相关义务。

第二段：申请将无归渡名下现有的路网接收资质（待批状态）转挂至步纲君渡口名下，登记为步纲君渡口旗下的一处歇脚棚，由步纲君渡口承担相应的日常维护义务。

第三段：注销完成后，无归渡原有的地址、设施和运营人员维持现状，不作更改。

第三段是他写第二遍时才加上的。第一遍没有，赵素校对的时候指出来：没有这一段，注销之后地址也跟着没了，那地方就成了无主的。

他带着这份文书去了步纲君那里。

步纲君在自己的渡口接待了他。渡口里空着，引首散在廊下，桌上摊着图。他接过文书，从头到尾看了两遍，把文书翻过来，对着光又看了一遍。

廊下有九个人，坐的坐，蹲的蹲，谁也不说话。有人鞋底上还带着干土。

桌上摊着一张新图，图角压着一枚铜镇。图上那条新路画得比旁的路粗，接口那一处点了一个红点。

赵升看了一眼那个红点，把文书递过去。

他知道这里面有东西。他是图正，做了很多年路线登记，这份文书在法律层面没有任何问题，每一条都合规，每一条都是标准措辞。

他在第三段上看了很久。

“这一段，”他说，“多余。”

“不多余。”赵升说，“注销的是待批资格，不是地方。”

步纲君看着他看了一会儿，没有再说。他把自己的印取出来，在印泥上按了按，盖在文书上，推了回来。

印盖得端正，四个角都碰到了纸。

“盖好了。”他说，“步纲君渡口旗下，歇脚棚，无归。”

文书拿到手里。

这一手他熟。把实的挂到虚的名下，名给对方，实留自己，等对方拿这个名去要东西的时候，名下什么都没有。他在九世里用过一回，那一回赢得很干净。

他没有解释。

把文书收进怀里之前，他问了一句。

“上头的册，谁在管？”

步纲君收印的手停了。

他没有答。过了一会儿，他把印收回袖子里，站起来，送客。

赵升也没有再问。

赵升把文书收起来，站起来，往外走。

步纲君在他背后说了一句：“赵堂主，你现在在正册上，什么也不是了。”

赵升没有回头，走出去了。

门外，他站在步纲君渡口的堤上，往自己那边看了一眼。隔着三十里，看不见无归渡，但他知道那七盏灯还亮着。

他把文书从怀里摸出来，对着光照了一下那个印，又收回去。
