# 第31章 灯

潮在后半夜到的，比赵升算的早了半个时辰。

这一次它没有倒卷，规规矩矩从西往东推。断堤上的人都能看见那道灰亮的线，贴着地划过来，划到无归渡前面三里的地方，分成两股，绕了过去。

绕过去的原因，写在赵素的账上：这一片，三万年前塌干净了。

渡口里挤了四百多个人。

伤的躺在前厅，赵茂带着几个小辈端水换布——他那只六十岁的手裹着布，干这个反倒稳。没伤的蹲在院子里，谁也不敢睡。窦让带着他的一百四十人占了东边那片空地，七车货堆成一座小山，他本人靠着车辕坐着，睁着眼。

外面还有人没进来。

赵九满从堤上跑回来：“西边那道梁上还有火把，大概二三十个，过不来了。”

赵升站起来。

“把灯全点上。”

赵长庚立刻拦住他：“七盏已经够了。”

“不够。”

“赵升。”老头压低声音——这是他第一次在外人面前直呼这个名字，“这一带的规矩，是天黑收灯。招来什么你担得起？”

“外头那二三十个人担不起。”赵升说。

“他们又不是赵家的人！”

“今天不是，明天就是。”赵升说，“老祖宗，你想想我们这三千年。每一次入墟，前头永远有一支队伍在探路，死完了，后头的才知道该往哪走。我们就是前头那一支。”

他停了停。

“我不想再做那一支了。我想做后头那盏灯。”

赵长庚的手在杖头上收紧了，指节发白。

半晌，他把杖往旁边一挪。

“点。”

——

那一夜无归渡点了三百多盏灯。

石灯、油碗、火把、照明符、甚至有人把自家的照路珠挂到堤边。整座渡口从上到下亮起来，亮得从三里外都能看见。

但真正让人看住的，是门额下面那七盏。

它们不是最亮的，也不是最高的。可它们是嵌在石头里的，三万年前有人凿出来，三万年里一直空着，今晚第一次同时有火。

赵升站在堤上，看着那七点火。

火苗很稳。稳得不像有风的地方。

就在七盏同时燃起来的那一息，他觉得脚底下有一点不对。

不是震。是堤下的石缝里，浮起来一线灰。

很细的一线，浮起来半尺，又落回去了。

像有人在下面，轻轻磕了一下。

赵升低头看了一眼那道石缝。

什么也没有。

他直起身，往西边那道梁上看——火把已经动起来了，二三十点火顺着梁往这边下，走得很快。他们看见灯了。

这三百多盏不是一起点起来的。赵茂带着四个小辈架了两架梯子，从堤下往上一盏一盏点。赵素把库房里的油全搬到门里，谁空了手就来舀一勺。照明符二十七道是前些天跟坊市赊来的，照路珠九粒出自院子里那些人，挂上堤边之后还回头找了一回。点到三更半，最后一盏是墙根下那只缺口的油碗。

赵升在堤上数了一遍，数到二百八十几就不数了。

赵九满在底下喊：“来了来了！开侧门！”

赵升没下去。

他转过身，朝另一个方向看。

东边，是死区。

那片地三万年前塌到底，塌得连渣都不剩，是墟图上大片大片的空白，连朱砂都懒得标。没有人往那边去，也没有什么能从那边过来。

赵升看着那片黑。

黑里亮了一下。

——

很远。远得像隔了几万里。

很短。短得他后来反复回想，也说不准是不是自己眼花。

它亮起来的样子，不像火，也不像法器的光。

它亮得很小，很低，很孤单。

像一盏灯。

然后它熄了。

赵升站在堤上，一动没动。

风从东边过来，带着尘土、金属，和某种烧过很久、烧到连烟都不剩的味道。

赵素爬上堤来找他，手里还抱着账册：“堂主，西边那批人进来了，二十六个，三个重伤——你看什么呢？”

赵升收回目光。

“没什么。”

他往回走了两步，又停住。

“赵素。”

“在。”

“把库房里那条船上的单子，取一张给我。”

赵素愣了一下。

那条船是十几天前漂到断堤上的。舱里七口空棺，每口棺盖钉着一张旧殓单，写着一个名字、一个死期。七个死期，全是同一天——三万年前的同一天。名字谁也不认得。赵升那天把船拖上岸，锁进空库房，一个字没解释。

“……现在？”

“现在。”

她去了，回来的时候手里拿着一张。纸很脆，字用墨写，笔画很老。

赵升接过来，借着堤上的灯看了一眼。

看了很久。

赵素在旁边等着，等他说点什么。

他没说。

他把那张单子折好，收进怀里，转身下堤：“睡吧。天亮还有活。”

——

天没亮，赵茂来拍门。

拍得很急，拍到第三下的时候声音就抖了。

“堂主——”

赵升已经起来了。

“西门外。”赵茂隔着门说，“西门外……多了一条路。”
