# 第47章 第一版

扎营之后，赵升没有睡。

他在营地边上找了块石头坐下，把这两天看到的东西在地上划了一遍：路向哪边偏、偏了多少、队伍怎么走的、死的人站在哪儿。划完，用脚抹掉，重新划。

赵素在旁边记账。赵九满蹲在对面的石头上看着。

他先让赵素做了三天的记录：头一天，路偏了四回，方向是东北；第二天，偏了七回，还是东北；第三天，偏了九回，方向偏北了半指。

三条线画在一张纸上，延长出去，都从同一片地方上头过。

赵素把纸转过来看：“三条线凑到一处了。”

赵升拿过笔，把三条线的交点圈起来。圈出来的地方，就是无归渡的地基。

他把笔放下。

赵升把观察整理了一遍。

路在移动，不是随机移动，是有方向的——这几天它的漂移方向，整体上一直在朝着某一个固定的地方靠近。其次，队伍越整齐，路漂得越快。

两件事放在一起，他想到了一种可能：路在寻找某个锚点，它认的是一个具体的地方，而不是泛泛的“适合停靠的地方”。队伍越像一支正式的队伍，越有人在上面活动，就越像一个有活人在运营的路网——而路网在运营的时候，它就往它的目标拉。

那个目标是什么？

他把已知信息过了一遍。路的石板材质和那块路引吻合，路引上的目的地是“长照”。在葬仙墟的遗迹里，按坐标推算，旧的长照的位置，就在无归渡现在所在的地方。

路在找长照。它认的是长照的旧印记，而这个印记，还留在无归渡的地基里。

“残天在找它自己的旧节点。”赵升说，“它认无归渡那片地基，因为那里有三万年前长照留下来的东西。”

赵素把这话记在了账册上。她写完，抬头问：“要记给谁看。”

“记着就行。”赵升说。

“那怎么办？”赵九满问。

“把那个印记抹掉。”赵升说，“如果路不认得那片地方了，它就不会往那边拉。”

“那它往哪儿拉？”

“到时候再看。”赵升说。

赵九满站起来，往营地那边走。走了几步又回头，问了一句：“你确定？”

“不确定。”赵升说，“所以要抹。”

“不确定你还抹。”

“抹了才知道对不对。”
