## 用法

1. 把对应的提示词整段发给千问
2. 在提示词末尾加一句：

```
把写好的正文写入 F:/novel/百世飞升续写/补写/01_ch18后_一成.md 的【正文】一节。
不要把章卡写进去。写完后再在【交接卡】一节写入交接卡。
```

3. 千问写完，你打开文件验收：
   - 事件有没有漏
   - 醒度数字对不对
   - 有没有自造的人名地名
   - 「的，」密度、单句逗号数

4. 全部补写做完后，跑 `合并脚本.py` 统一插入并重新编号

---

## 合并脚本怎么跑

```bash
cd "F:/novel/百世飞升续写"
cp 1-105.txt "1-105.bak-$(date +%Y%m%d-%H%M%S).txt"
python 补写/合并脚本.py
```

脚本只做三件事：
1. 读每个补写文件的【正文】一节
2. 插到指定章号之后
3. 重新编号全部章节标题

**重写类（ch70 / ch96）不是插入，是替换**，脚本会单独处理。

## 铁律

- 不改已有事实、不改人物生死、不改伏笔进度
- 不新增设定、不新增人物、不新增地名
- 不解释"归处"
- ch70 之前不许出现"两成"
- 每改一章先备份
