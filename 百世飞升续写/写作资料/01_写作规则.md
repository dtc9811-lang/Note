# 01 写作规则

这份文件只管**怎么规划、怎么写、怎么验收**。当前章节状态去 DevTrace 看；设定去 `02_设定总表.md` 看。

## 一、角色分工

### DeepSeek Flash：编剧 / 调度

每次只正式规划下一章，输出施工单：

```text
【第___章施工单】
章节目标：
必须延续：
本章节拍（3—6条）：
世界阶：界域 / 路网 / 仙籍（有无变化）
本卷底线：大世界 / 修炼 / 战斗（本章兑现哪一项）
不能出现：
不能提前揭露：
章末钩子：
验收条件：
```

规划前必须：
1. 读 DevTrace current_conclusion/current_risk/next_step；
2. 读上一章正文；
3. 只取本章相关人物、术语、伏笔；
4. 旧总纲只做宏观参考，若与正文冲突按正文修正。

规划完成写 DevTrace：`event_type=note`。

规划时还必须检查当前 Task 的**批次契约**与**剧情债**：本章不是只要“自己合理”，还要服务 10—15 章的整体波形。每完成 3 章做一次宏观复审，必要时强制下一章换类型。

### Qwen 3.8 Max：正文执行

只执行最新施工单，不擅自重规划主线。

正文完成后 DevTrace `change` 至少记录：
- 实际发生了什么；
- 与施工单一致的部分；
- 临场新增了什么；
- 偏离计划的地方；
- 章节结束时人物/物件/地点的可见状态。

正文全文不塞进 DevTrace。

### Flash 复审

只审四件事：
1. 是否完成施工单目标；
2. 是否违反正文事实或固定设定；
3. 是否产生了必须登记的新事实；
4. 下一章规划是否需要调整。

通过记 `test`；不通过只列局部修改项，不整章推倒重来。

## 二、全书硬规则

1. **仙墟内法力只出不进、消耗加倍。** 墟内战斗靠神识、符/器/阵、混元仙体、本源仙炁、规则与地利。
2. 仙墟外（坊市、路网、渡口、洞天）法力正常。
3. **路网只认功能，不认名字、名分、凭证。做样子也算做。**
4. 三条规矩固定写法：**灯不熄、门不锁、来者先医后问。**
5. “归处”只能出现，**不得解释**。
6. 不杀赵玄靖、鸿运子、天运子、石灵。
7. 不使用废止方案：残灯、石灵护送、千人村、第1001人、记名供灯、五镜副本、私人仙墟、墟主职业、赵氏仙朝。
8. 正文不得出现“第X章”“本章”“上一章”等元叙述。
9. 没有登记的人物一律不具名；新地名/势力先登记再写。

## 三、文风

目标：**冷、慢、实；第三人称限知，视角贴赵升。**

- 短句、短段；一句一个动作。
- 少形容词，多可核对的物理细节。
- 情绪写动作，不写总结。
- 对话必须有来回，避免一问一答结束。
- 环境细节承担信息：温度、声音长短、灰、石缝、油面、距离、人数。
- 数量尽量具体，不用“许多、无数、很多”。
- 对话标签优先“说/问/答”，少用“冷笑道/淡淡道/沉声道”。
- 新写/重写章：「的，」≤4/千字；单句逗号≤6。
- 章末停在动作、物件或画面上，不总结、不抒情、不上价值。

禁用套话示例：
- 嘴角勾起一抹弧度
- 眸光一凝 / 眼中闪过精芒
- 气息暴涨 / 恐怖威压
- 心中一凛 / 暗道不好 / 倒吸凉气
- 与此同时，在另一个地方
- 他突破了 / 修为又精进一层

常见跨章口头禅要控制：看了很久、笑了一声、看了一眼、没有说话、停了一下、点了点头。

## 四、场景写法锚点

### 观察场

先看可验证的细节，再逼出结论。例如：先看石板缝里有没有草和沙，再判断这条路是否“刚被扫过”。不要先给结论再补说明。

### 对峙场

对方说得越长，赵升越短。压力落到旁人的动作：笔停、手收紧、人群挪动，而不是写“众人震惊”。

### 异常场

先建立常态，再让常态同时变化。用日常物理比喻解释异常，不写“恐怖威压”。

### 修炼场

必须“实”：料、时间、数量、失败、门槛都可数。修炼节点固定五段：

```text
决定 → 硬扛 → 成了 → 当场用出来 → 代价
```

禁止“闭关一段时间，修为精进”一笔带过。

## 五、长篇节奏：六类剧情脉冲

单章只需要重点打 1—2 类，但每个 10—15 章批次必须形成明显波形，不能连续十几章都是同一种“对账/讨论/守渡口”。

六类脉冲：

1. **世界**：新地图、新势力、新层级、新生态或上层秩序真实介入。
2. **修炼**：境界/洞天/控制精度的可见成长。
3. **战斗**：外部冲突；必须有对手或敌意环境、目标冲突、战术选择、失败风险、结果/代价。
4. **探索**：进入未知空间/遗迹/规则环境，经历调查与不确定性。
5. **收获**：获得法宝、材料、机缘、关键线索、资源或能力收益。
6. **人物**：私人关系、生活、选择、承诺、代价，不只是任务讨论。

### 严格认定

以下**不算世界推进**：
- 别人送来外界材料；
- 听说一个远方地名；
- 对话里提到宗门/大人物；
- 换了一个渡口名字，但人物生态和玩法完全没变。

真正的世界推进至少满足一项：
- 主角实际进入新地图/新生态；
- 新势力直接参与当前事件；
- 上层秩序对当前剧情产生可见后果；
- 新货币、修为层级、社会结构、规则环境真正进入场景；
- 当前小地方发生的事被更高层世界反馈回来。

以下**不算真实战斗**：
- 闭关疼痛；
- 单纯硬扛修炼；
- 身体承压但没有外部敌意与目标冲突。

这些只能记作“修炼危机”。真正战斗至少有：对手/敌意环境 + 目标冲突 + 战术选择 + 失败风险 + 结果或代价。

真正的探索/寻宝应尽量具备：

```text
未知 → 调查 → 危险/阻碍 → 发现 → 收获/新问题
```

只“捡到一块东西”不算完整寻宝。

### 剧情债

Flash 每次验收后都要维护 DevTrace 当前 Task 的“剧情债”：
- 世界还欠什么；
- 修炼还欠什么；
- 真实战斗还欠什么；
- 探索还欠什么；
- 收获还欠什么；
- 人物还欠什么。

如果连续 3 章：
- 还在同一个地点；或
- 使用同一种冲突；或
- 只有讨论/记账/安排；

下一章优先强制换类型，除非批次契约明确允许。

### 三章宏观复审

每完成 3 章，Flash 额外做一次宏观复审（可记 `test` 或 `finding`）：

1. 主角在同一地点待多久了？
2. 最近 3 章是否连续用同一种冲突？
3. 六类脉冲哪些太久没出现？
4. 批次原定的大节点有没有被局部细节挤掉？
5. 下一 3 章是否需要强制换地图/冲突/玩法？

### 地图时钟

一个主要地图/生态最多承担约 20—30 章主舞台。到点后必须发生真正玩法变化：换城、换界、换势力圈、换生态或换规则环境。换名字不算换地图。

## 六、逻辑自检

写完逐项看：

- 人数守恒：进、出、死、留的人对得上吗？
- 空间守恒：从 A 到 B 的移动交代了吗？
- 时间守恒：三日就是三日吗？
- 物品守恒：上一章拿在谁手里，这章有没有凭空重拿？
- 信息守恒：角色有没有知道不该知道的东西？
- 规则守恒：有没有为了剧情偷改公开规则？
- 新名字是否已登记？
- 本章节拍是否全部兑现？
- 章末是否停在具体动作或画面？
