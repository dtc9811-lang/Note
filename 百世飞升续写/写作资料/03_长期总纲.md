## 二、当前卷三条硬进度

### 修炼

- 115 四成·开府：单人身体极限型。
- 124 四成半：逆境实战型。
- 133 五成·归位：对外结算型。
- 142 五成半：救灾/抗冲击型。

代价不能四次都写成“身体伤 + N 日不能动”。至少两次是社会/承诺/洞天结构上的代价。

### 世界

当前基准（114结束）：界域1 / 路网3 / 仙籍2。

当前卷目标：
- 界域：1→2，约在 129 客安城；
- 路网：3→4，约在 142—143；
- 仙籍：2→3，约在 148。

### 战斗与危机

至少保持：
- 123—124：新仙墟遭遇战；
- 125—126：旧人/守护机制试探冲突；
- 129：客安城摩擦，不可城内大打出手；
- 142：法则/归潮式天灾战；
- 144：拔刀对峙；
- 145—147：旧账与上层秩序的短促冲突。

主线仍靠账、规则、路网解，战斗只负责证明变强、制造危机、露世界层次。

## 三、已经拍板的长期决策

1. 当前世界基准：114结束 = **界域1 / 路网3 / 仙籍2**。
2. 赵氏旧人 = 三万年前留在仙天的一脉守候者，不是赵玄靖本人。
3. 赵敕路线：认为名分能保护人，最终可以进入验渡人体系；与赵升路线相左但不为私利。
4. 陨落处本卷只推进到“引动 / 接住一段记忆”，五面镜、旧洞天、雷帝辟劫令、五雷钺等实物留更后面。
5. “归处”永远不解释，只呈现现象。
6. 当前未合并的旧版重写稿放 `待处理/`，不在当前卷写作期合并。

这些以后若要推翻，必须先在 DevTrace 记录 `decision` 的替代决策，不得模型自行改口径。

## 四、当前卷之后（只锁方向，不锁死章号）

当前卷结束后按世界层次逐步走出去：

1. **欠命坊 / 倒果渡**：跨渡网，规则历练；世界从单一坊市城走向多界路网。
2. **万法回潮 / 法则压力台**：灵界门户前的法则压力，测试洞天抗劫。
3. **宗门大会 / 仙职 / 旧人重逢**：进入灵界内域，赵玄靖/鸿运子线开始真正接触。
4. **一人天 / 问天庙**：进入仙天残域，洞天与“活着的天地”正面对照。
5. **无丧城 / 轮回缺环**：发现只有生化、没有死后归返的结构性缺失。
6. **虚界九天 / 诸天主干**：秩序圈与终局准备。
7. **终局**：打开轮回道，赵升归零进入第十一世。
